WORK ON+
WORK ON+ 소개이용 약관

개인정보 처리방침

WORK ON+는 사용자 본인의 업무 정리에 필요한 범위에서만 개인정보와 Google 사용자 데이터를 처리합니다. 판매하거나 광고에 쓰지 않습니다.

시행일: 2026년 11월 24일 (이전 판: 2026년 11월 20일)

1. WORK ON+는 어떤 서비스인가요

WORK ON+는 각자 쓰는 개인 업무 관리 앱입니다. 한 사람이 자기 작업공간 하나를 쓰고, 작업공간의 내용은 그 사람만 볼 수 있습니다. 다른 사람의 작업공간을 보거나 함께 쓰는 화면은 없습니다.

2. 처리하는 정보

  • 로그인 정보: Google 로그인으로 받는 계정 식별자, 이메일 주소, 이름·프로필 사진(Google 기본 정보). Google 비밀번호는 받지도 저장하지도 않습니다.
  • 프로필: 사용자가 설정에 직접 넣은 소속 이름(조직), 부서명, 이름, 직책.
  • 사용자가 WORK ON+에 직접 쓴 기록: 일정, 할 일, 프로젝트, 회의 기록, 메모, 올린 자료, 폰 앱으로 녹음한 회의 녹음.
  • 사용 기록: 가입일, 마지막 사용 시각, AI 기능 사용량(쓴 양과 비용을 세는 숫자).
  • Google 연결 정보: 사용자가 연결에 동의한 경우 연결을 유지하기 위한 접근·갱신 토큰과 연결한 Google 계정 이메일.
  • Google에서 가져온 데이터: 아래 3절의 권한으로 읽은 일정·할 일·Drive 파일 정보.
  • 폰 앱 알림 정보: WORK ON+ 폰 앱에서 알림을 켠 경우, 그 기기로 알림을 보내기 위한 기기 알림 주소(푸시 토큰)와 알림 설정.
  • 의견 보내기: 메뉴의 '의견 보내기'로 보낸 경우에만, 보낸 사람(이메일주소), 쓴 글, 붙인 사진(3장까지), 그때 보던 화면 이름·기기 종류(폰·폴드·PC)·앱 또는 브라우저·WORK ON+ 판 번호. 운영팀만 보고 WORK ON+를 고치는 데만 씁니다. 답장은 보내지 않고, 고친 것은 '업데이트 소식'으로 알립니다. 작업공간의 다른 기록은 함께 보내지 않습니다.

2-1. 저장하지 않는 정보

  • Google 비밀번호와 2단계 인증 정보는 받지도 저장하지도 않습니다.
  • Drive 사진·동영상의 원본은 WORK ON+ 서버에 저장하지 않습니다. 사진 화면은 고른 폴더와 목록만 둡니다.
  • WORK ON+에 올린 파일의 원본은 WORK ON+ 서버가 아니라 사용자 본인의 Google Drive에 저장됩니다.
  • 광고 식별자, 위치 기록, 연락처 목록은 수집하지 않습니다.

2-2. 폰 앱이 쓰는 권한

WORK ON+ 폰 앱(안드로이드)이 요청하는 권한 전부입니다. 인터넷을 뺀 권한은 그 기능을 처음 쓸 때 묻거나, 사용자가 폰 설정에서 직접 켜야 합니다.

권한무엇에 쓰나요
INTERNETWORK ON+ 서버와 Google에 연결합니다.
READ_MEDIA_IMAGES, READ_MEDIA_VIDEO, READ_MEDIA_VISUAL_USER_SELECTED, READ_EXTERNAL_STORAGE사진 메뉴의 '폰 사진'에서 [사진 접근 허용]을 누를 때만 묻습니다. 폰의 사진·동영상 목록과 그림은 폰 안에서만 보여 주고 서버로 올리지 않습니다. '고른 사진만' 허용도 됩니다.
ACCESS_MEDIA_LOCATION사진 정보 보기·고치기에서 사진에 기록된 촬영 위치를 읽고 고칠 때 씁니다.
MANAGE_MEDIA사진 폴더에서 사진을 옮기거나 지울 때 매번 확인 창을 띄우지 않게 합니다. 사용자가 폰 설정에서 '미디어 관리 허용'을 켠 경우에만 쓰입니다.
MANAGE_EXTERNAL_STORAGE[파일] 화면의 '이 폰' 저장 공간을 보고 정리합니다. 사용자가 폰 설정에서 '모든 파일 접근'을 직접 켜야 하며, 시스템·다른 앱 전용 칸은 열지 않습니다. 파일 목록과 파일은 서버로 보내지 않습니다.
REQUEST_INSTALL_PACKAGES, UPDATE_PACKAGES_WITHOUT_USER_ACTIONWORK ON+ 앱 자신의 새 판(같은 서명)만 설치합니다. 다른 앱은 설치하지 않습니다.
RECORD_AUDIO, FOREGROUND_SERVICE, FOREGROUND_SERVICE_MICROPHONE회의 [녹음]을 누를 때만 마이크를 씁니다. 화면을 꺼도 녹음이 이어지도록 알림을 띄운 채 동작합니다.
POST_NOTIFICATIONS녹음 중 표시와, 사진·자료를 올리는 중 표시, 사용자가 켠 WORK ON+ 알림을 보여 줍니다.
FOREGROUND_SERVICE_DATA_SYNC사용자가 고른 사진·자료를 앱을 나가거나 화면을 꺼도 끝까지 올리도록, '올리는 중' 알림을 띄운 채 동작합니다. 올리는 곳은 사용자 본인의 WORK ON+ 자료실뿐입니다.

Google Play 스토어에서 받은 WORK ON+에는 모든 파일 접근('이 폰' 저장 공간 보기)과 앱 스스로 새 판 설치 권한이 없습니다. 새 판은 Play 스토어가 설치합니다.

2-3. 기기에 저장하는 것

  • WORK ON+ 화면 코드는 쿠키를 만들지 않습니다. 광고·방문 분석 추적 도구를 넣지 않습니다.
  • 브라우저(또는 폰 앱)의 저장 공간에 로그인 상태, 화면 설정, 일정·할 일을 빨리 보여 주기 위한 사본, 사진 미리보기 그림을 둡니다. 로그아웃하거나 다른 계정으로 로그인하면 앞 계정의 일정·할 일 사본은 지웁니다.
  • 원본 기록은 기기가 아니라 서버(4절)와 본인 Google 계정에 있습니다.

2-4. 운영자가 보는 정보

내가 기록한 내용은 운영자가 볼 수 없습니다.

  • 운영자에게 제공되는 정보: 이메일주소, 가입일, 마지막 사용 시각
  • 제공되지 않는 정보: 유저가 기록·업로드 한 정보

장애가 나도 기록 내용은 열지 않고 개수·있는지 여부만 확인합니다. 자세한 약속은 이용 약관 4절에 있습니다.

3. 요청하는 Google 권한과 쓰는 곳

캘린더·할 일·Drive 권한은 사용자가 WORK ON+ 안에서 직접 '연결'을 눌러 동의할 때만 요청합니다.

권한무엇에 쓰나요
openid, email, profile로그인과 본인 확인, 연결한 Google 계정 표시
https://www.googleapis.com/auth/calendar.calendarlist.readonly내 캘린더 목록을 읽어, WORK ON+ 달력에 보여 줄 캘린더를 고르게 합니다(읽기만).
https://www.googleapis.com/auth/calendar.events고른 캘린더의 일정을 WORK ON+ 달력에 보여 주고, 사용자가 WORK ON+에서 만들거나 고치거나 지운 일정을 Google 캘린더에 반영합니다.
https://www.googleapis.com/auth/tasks내 Google 할 일 목록을 WORK ON+에서 보여 주고, 사용자가 WORK ON+에서 한 추가·완료·수정·삭제를 Google 할 일에 반영합니다.
https://www.googleapis.com/auth/drive.file사용자가 WORK ON+ 자료실·메모·회의에 올린 파일을 내 Drive에 저장하고, WORK ON+가 만든 그 파일·폴더만 다시 읽거나 지웁니다. WORK ON+를 쓰는 모든 사용자에게 요청하는 Drive 권한은 이것 하나입니다(내 Drive의 다른 파일은 볼 수 없습니다).

위 목적 밖으로 Google 데이터를 쓰지 않습니다. 사람이 Google 데이터를 직접 열어 보지 않으며, 예외는 사용자가 동의한 경우, 보안 문제 조사, 법적 의무 이행뿐입니다.

4. 저장 위치와 보관

  • 정보는 사용자 본인 작업공간에만 저장되며, 데이터베이스가 작업공간 주인만 읽고 쓸 수 있게 막습니다.
  • 저장소는 WORK ON+가 쓰는 클라우드 데이터베이스(Supabase)입니다. Google에서 가져온 일정·할 일은 화면을 빠르게 보여 주기 위해 사본을 둘 수 있고, 사진은 원본을 저장하지 않고 고른 폴더와 사진 목록만 둡니다.
  • 사용자가 WORK ON+에 올린 파일은 사용자 본인의 Google Drive에 저장됩니다.
  • 정보는 작업공간을 쓰는 동안 보관하고, 삭제를 요청하면 6절대로 지웁니다.
  • 앱 안에서 직접 계정을 삭제할 수 있습니다(내 프로필 › 계정 › [계정 삭제]). 누르면 바로 지우고 모든 기기에서 로그아웃됩니다. 앱에 들어갈 수 없으면 11절의 메일로 요청해도 됩니다. 방법·지워지는 것·남는 것·기간은 계정·데이터 삭제 요청에 있습니다.
  • 보낸 의견과 사진은 같은 데이터베이스의 운영팀만 읽을 수 있는 칸에 둡니다(보낸 사람 본인과 다른 사용자는 읽을 수 없습니다). WORK ON+를 고치는 데 필요한 동안 보관하고, 삭제를 요청하면 지웁니다.

5. 다른 곳에 주는 경우

  • 개인정보와 Google 사용자 데이터를 판매하지 않고, 광고·마케팅·신용 판단에 쓰지 않으며, 데이터 중개인에게 주지 않습니다.
  • 다른 사용자와 나누지 않습니다. 사용자가 직접 공유 링크를 만든 내용만 그 링크를 받은 사람이 볼 수 있습니다.
  • 사용자가 WORK ON+의 AI 기능(요약·초안·자료 제목 찾기 등)을 쓰면, 그 기능에 필요한 내용만 AI 처리 업체(OpenAI) API로 보내 결과를 받습니다. 이 내용에는 Google에서 가져온 자료가 들어 있을 수 있습니다. OpenAI에 보내는 요청에는 응답을 OpenAI 쪽에 저장해 두지 않게 하는 설정(store: false)을 붙입니다. Google 사용자 데이터를 범용 AI 모델의 개발·학습·개선에 쓰지 않습니다.
  • 회의 녹음을 글로 받아쓸 때는, 본인 Drive에 저장된 녹음 파일을 AI 처리 업체(Google Gemini API)에 올려 받아쓰고, 끝나면 올린 파일을 지우도록 요청합니다(지우지 못하면 Gemini가 48시간 뒤 지웁니다).
  • 서비스를 돌리는 데 필요한 처리 위탁: 데이터베이스·서버 함수(Supabase), 화면 호스팅(GitHub Pages, Cloudflare), 폰 앱 알림 전달(Google Firebase Cloud Messaging), AI 처리(OpenAI, Google Gemini API).
  • 수사기관 등의 자료 요청에는 법관이 발부한 영장이 있을 때만 영장에 적힌 범위에서 응하고, 법이 금지하지 않는 한 대상 사용자(또는 그 사용자가 속한 조직)에게 바로 알려 압수·수색 과정에 참여할 수 있게 합니다. 기록은 서버에 보관되므로 영장이 오면 제공해야 할 수 있습니다.

6. 연결 끊기와 삭제

  • Google 계정의 타사 연결 관리에서 언제든 WORK ON+ 접근을 끊을 수 있습니다. 끊으면 WORK ON+는 더 이상 Google 데이터를 읽거나 바꿀 수 없습니다.
  • 저장된 연결 정보(토큰)와 Google 데이터 사본만 지우고 싶을 때도 아래 운영 담당자에게 요청하면 지웁니다.
  • 폰 앱 알림은 WORK ON+ 알림 설정에서 종류별로 끄거나, 등록된 폰 목록에서 [끊기]를 눌러 그 기기로 보내지 않게 할 수 있습니다.
  • 계정과 작업공간 데이터 전체 삭제는 앱의 내 프로필 › 계정 › [계정 삭제]로 바로 할 수 있습니다. 앱에 들어갈 수 없으면 운영자 메일(nojoplus.com@gmail.com)로 요청하면 요청을 확인한 날부터 30일 안에 지웁니다(삭제 방법). 본인의 Google 캘린더·할 일·Drive에 있는 원본은 Google 계정에 그대로 남습니다. 서버 장애에 대비한 백업에는 보관 기간(최대 약 1년) 동안 남았다가 저절로 지워지며, 백업은 장애 복구에만 씁니다.

7. Google API 사용자 데이터 정책 준수

WORK ON+가 Google API로 받은 정보를 쓰고 다른 앱으로 옮기는 일은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

WORK ON+'s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. 보호 조치

  • 모든 연결은 암호화된 주소(HTTPS)로만 오갑니다.
  • Google 토큰은 서버 쪽에만 두고 화면 코드에 넣지 않습니다.
  • 로그인하지 않은 사람은 WORK ON+ 안의 어떤 기록도 볼 수 없습니다.

9. 이용자의 권리

  • 본인 정보의 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. 앱 안에서 직접 고치거나 지울 수 있는 기록은 그 화면에서 바로 할 수 있고, 그 밖의 요청은 11절의 메일로 받습니다.
  • Google 연결은 6절의 방법으로 언제든 끊을 수 있습니다.

10. 아동

WORK ON+는 업무용 도구로, 만 14세 미만은 가입 대상이 아닙니다.
