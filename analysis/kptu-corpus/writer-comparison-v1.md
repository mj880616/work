# 공공운수노조 언론자료 담당자 비교분석 v1

기준일: 2026-09-19  
대상: 2023~2026 공공운수노조 홈페이지 성명·보도자료·취재요청 코퍼스  
목적: 개인의 우열을 매기는 것이 아니라, 반복적으로 확인되는 작성·편집 습관과 김명진 글에 적용할 기술을 찾는 것

## 0. 해석상 주의

홈페이지 문서 하단의 ‘문의/담당/취재연락’ 표시는 **실제 초안 작성자를 증명하지 않음**. 담당자가 직접 쓴 경우도 있고, 공동작성·취합·수정·배포만 담당한 경우도 있을 수 있음.

따라서 이 문서에서는 개인을 ‘작성자’로 확정하지 않고 **담당자 기준 작성자 추정**으로 다룸.

기존 자동추출은 게시물 본문이 아니라 페이지 전체 연락처를 읽거나, 여러 HWP 중 첫 첨부파일을 고르면서 다른 게시물의 담당자가 섞이는 문제가 있었음. 해당 방식의 결과는 폐기하고 아래처럼 보정함.

- 현재 게시물 제목과 HWP 본문의 단어 일치도를 계산해 해당 게시물 첨부파일을 우선 선택
- ‘문의/담당/취재문의/보도문의/연락처’ 등 명시적 구역만 분석
- 이름·직책·전화번호를 묶어 신뢰도 부여
- 전화번호가 없는 ‘담당자+직책’ 형식도 별도 중간 신뢰도로 포함
- 기존 자료는 담당자 이름이 문의 문맥에 실제 등장하고 게시물 제목과 문의문맥이 일치하는 경우만 임시 활용

전수 재매핑이 완료되기 전까지 사람별 문서 수 자체는 확정치로 보지 않음.

# 1. 현재 신뢰 표본에서 반복 담당이 확인되는 사람

기존 결과를 강하게 필터링한 임시 신뢰 표본에서는 다음 담당자가 서로 다른 자료에 반복 등장함.

| 담당자 | 현재 확인 문서 | 주된 장르/영역 | 해석 신뢰도 |
|---|---:|---|---|
| 김지영 | 3건 | 발전·정의로운 전환 / 취재요청·보도자료 | 중간 |
| 배동산 | 3건 | 의료연대본부 / 취재요청·보도자료 | 중간 |
| 최종하 | 3건 이상 | 방영환 열사·택시 / 취재요청 | 중간 |
| 강해현 | 2건 | 조직쟁의·문화예술 / 취재요청·보도자료 | 중간 |
| 김호세아 | 2건 이상 | 사회서비스·돌봄 / 취재요청 | 중간 이상 |
| 박대진 | 2건 | 동일 사건의 취재요청→보도자료 | 낮음~중간 |

박대진 2건은 사실상 같은 날 같은 사건의 사전·사후 자료이므로 독립적인 반복 작성 습관으로 보기 어려움.

김호세아는 코퍼스 연락처 외에 동일·인접 이슈를 본인 명의로 직접 작성한 공개 기사들이 다수 확인되어 ‘담당자=실제 글쓰기 관여자’일 가능성이 다른 표본보다 높음. 다만 코퍼스 문서 자체의 초안 작성자는 여전히 단정하지 않음.

# 2. 담당자별 관찰

## 김지영 — 큰 사업의 규모·참여주체·요구를 한 번에 보여주는 방식

### 확인 문서
- 2025.05.09 보도자료 — 도서전력 해고노동자 사망 한국전력 규탄기자회견
- 2025.05.29 취재요청 — 5.31 정의로운 전환 노동자시민 대행진
- 2025.06.09 보도자료 — 태안화력 고 김충현 비정규직 사망사고, 발전비정규직연대 입장 및 투쟁계획 발표

### 반복적으로 보이는 특징

**장점**
- 행사 규모를 보여주는 재료가 많음. 200여 단체, 전국 버스, 태안·창원 동시 개최, 예상 참가자 수처럼 ‘왜 큰 행사인가’를 보여줌.
- 요구를 열거형으로 분명히 함.
- 행사 시간·동선·지역별 문의 등 취재 실무정보가 충실함.
- 발전소 폐쇄·고용·지역·재생에너지를 하나의 사업맥락으로 연결하는 능력이 있음.

**약점**
- 사전 취재요청에서 정책배경이 길어지며 가장 강한 뉴스요소가 뒤로 밀릴 수 있음.
- 행사 취지와 운동의 정치적 의미, 정책설명, 참가안내가 한 본문에 동시에 들어가 정보 위계가 약해짐.
- ‘왜 지금 취재해야 하나’보다 ‘이 투쟁은 왜 중요한가’ 설명이 길어질 위험이 있음.

### 김명진과 비교

둘 다 개별 사건을 산업·정책 구조로 연결하는 경향이 강함. 김명진은 한 사건에서 구조적 모순을 논증하는 쪽이 더 강하고, 김지영 담당 자료는 여러 주체·일정·요구를 큰 판으로 묶는 쪽이 강함.

김명진이 가져올 기술:
- 대규모 사업에서는 구조 설명보다 **규모·주체·새로운 행동**을 먼저 쓰기
- 취재실무 정보와 정책설명을 분리하기
- 사전 취재요청은 ‘당일 뉴스’와 ‘붙임 배경자료’를 더 과감히 나누기

## 배동산 — 복수 사업장 공동행동을 기자가 바로 사용할 수 있게 정리

### 확인 문서
- 2024.12.16 취재요청 — 병원·돌봄 노동자 시국선언 대회
- 2025.09.15 취재요청 — 의료연대본부 9월 17일 공동파업 대회
- 2025.09.17 보도자료 — 의료연대본부 공동파업

### 반복적으로 보이는 특징

**장점**
- ‘언제/어디서/누가/무엇을’이 빠르게 확인됨.
- 공동파업처럼 사업장이 여러 곳인 행사에서 총괄문의와 지역별 문의를 분리함.
- 사전 취재요청과 당일 보도자료의 역할을 구분하려는 흔적이 있음.
- 복잡한 연합행동에서 기자가 취재할 접점을 만들어 줌.

**약점**
- 발언문·세부자료가 당일 별도로 붙는 구조가 많아, 메인 보도자료 자체가 무엇을 새롭게 말하는지 약해질 수 있음.
- 공동행동의 요구가 여러 개일 때 중심 헤드라인이 흐려질 위험이 있음.

### 김명진과 비교

김명진은 본문 논증을 완결하려는 경향이 강한 반면, 배동산 담당 자료는 **기자가 필요한 사람·장소·자료에 접근하도록 안내하는 문서 기능**이 더 강함.

김명진이 가져올 기술:
- 취재요청은 ‘완결된 논평’이 아니라 **취재 인터페이스**라는 관점
- 총괄문의 / 현장별 문의 / 추가자료 제공 가능 여부를 구분
- 당일 상세발언은 붙임으로 미루고 본문은 핵심 사실과 요구만 유지

## 최종하 — 연속투쟁에서 ‘이번에 새로 생긴 사건’을 붙잡는 방식

### 확인 문서
- 2023.12.21 취재요청 — 방영환 열사 투쟁 승리 민주노총 서울본부 결의대회
- 2024.01.12 취재요청 — 방영환 열사 영면 100일 투쟁문화제
- 2024.01.17 취재요청 — 근로감독 시정명령 불이행·정승오 엄벌 촉구 기자회견 및 3차 결의대회
- 추가로 같은 투쟁의 여러 취재요청에서 담당 표기 확인

### 반복적으로 보이는 특징

**장점**
- 장기투쟁이라도 매 문서에서 당일 행동의 명분을 새로 붙임.
  - 연내 장례
  - 영면 100일
  - 근로감독 시정명령 불이행
  - 형사재판
  같은 새로운 계기를 제목에 사용함.
- 제목에서 사건성과 요구가 매우 직접적임.
- 배경을 길게 새로 설명하기보다 기존 투쟁 경과 위에 ‘이번 행동의 이유’를 얹는 방식임.

**약점**
- 규탄 대상과 요구가 많이 누적되면서 제목이 길어지고, 한 자료에 여러 갈래의 책임주체가 들어갈 수 있음.
- 동일한 투쟁의 연속 자료라 문구가 관성적으로 반복될 위험이 큼.

### 김명진과 비교

김명진은 새 사건을 구조 전체의 문제로 확장하는 반면, 최종하 담당 자료는 장기 사건에서 **오늘 새로 발생한 팩트/절차/기한**을 제목에 올리는 데 강점이 있음.

김명진이 가져올 기술:
- 장기 현안 취재요청에서는 매번 ‘오늘의 새 사실’을 하나 고르기
- 이전 경과는 2~3줄로 줄이고, 이번 행동의 직접 계기를 제목·첫 문단에 집중

## 강해현 — 제3자 문서와 공식입장을 앞세워 기사 골격을 제공

### 확인 문서
- 2023.06.19 취재요청 — 노조법 2·3조 개정·최저임금 관련 도보행진 출발 기자회견
- 2025.04.16 보도자료 — 국제음악가연맹, ‘문화한국 2035’ 예술단체 지방 이전 계획 우려

### 특히 강한 사례: 2025.04.16 보도자료

이 자료는 본문이 비교적 짧고 명확함.

1. 국제음악가연맹이 4월 15일 문체부에 공식서한을 보냈다는 **새 사실**
2. 서한이 무엇을 문제 삼았는지
3. 국내에서 이미 제기된 반대·우려의 경과
4. 국제음악가연맹이 제시한 대안과 요구
5. 공공운수노조의 평가
6. 원문·번역본 첨부

순서로 감.

**장점**
- 노조의 판단보다 외부기관의 공식문서가 먼저 옴.
- “IFM은 지적했다/강조했다/촉구했다”처럼 발화주체가 명확해 사실과 평가가 섞이지 않음.
- 기자가 제목·리드·인용을 바로 만들 수 있음.
- 메인 본문과 원문 source pack을 분리함.

실제로 다음날 보도에서도 ‘IFM 공식서한 → 핵심 우려 → 대안 → 공공운수노조 입장’ 골격이 거의 그대로 기사화됨. 이는 자료의 기자 활용성이 높았다는 간접 증거임.

**약점**
- 표본 수가 적어 이것을 강해현 개인의 일반적 습관으로 확정할 수 없음.

### 김명진과 비교

김명진은 스스로 사건의 구조적 의미를 설명하는 능력이 강함. 강해현 담당 자료의 좋은 사례는 반대로 **제3자 문서가 스스로 말하게 두고 노조 해석을 마지막에 붙이는 방식**이 강함.

김명진이 가장 직접적으로 가져올 기술:
- 판정문·정부문서·연구·해외기관 서한이 있을 때는
  **원문 사실 → 핵심 인용/요약 → 노조 평가** 순서를 깨지 않기
- source pack을 본문 밖으로 분리
- 좋은 외부근거가 있으면 구조적 수사를 덜 쓰기

## 김호세아 — 현장 당사자·수치로 추상적 사회서비스 의제를 번역

### 확인 문서
- 2023.07.14 취재요청 — 서울시사회서비스원 어린이집 지속운영·확대 촉구
- 2024.03.13 취재요청 — 한국은행 돌봄서비스 인력난 이슈노트 반대 돌봄·이주노동자 합동 기자회견
- 공공운수노조 활동가 본인 명의의 공개 기사 다수 확인

### 반복적으로 확인되는 특징

공개 기사까지 함께 보면 다음 습관이 선명함.

**장점**
- 추상적인 ‘공공돌봄’ 대신 이용자·학부모·보육교사·이주가사노동자 같은 **당사자**를 전면에 둠.
- 조사자료가 있을 때 96%, 98.1%, 응답자 324명 등 숫자를 기사 첫 골격으로 사용함.
- 정책 문서 비판에서도 한국은행이 실제로 제시한 방식을 먼저 설명한 뒤 그 효과를 비판함.
- 현장 장면과 당사자 발언을 적극적으로 사용해 일반 독자가 제도를 이해하게 함.

**약점**
- 긴 글에서는 공공성·돌봄노동·이주노동·최저임금·사회서비스 체계 등 쟁점이 한꺼번에 확장되는 경향도 있음.
- 운동적 결론이 반복되면서 기사형 설명과 논평이 섞이는 경우가 있음.

### 김명진과 비교

둘 다 구조적 맥락을 잘 아는 편이나 출발점이 다름.

- 김명진: 사건 → 제도·구조
- 김호세아 담당/명의 글: 당사자·생활 장면 → 제도 문제

김명진이 가져올 기술:
- 구조를 설명해야 할수록 먼저 ‘이 제도 때문에 누가 어떻게 일하고/이용하고 있는가’를 한 장면 제시
- 실태조사나 현장조사 결과가 있으면 가장 이해하기 쉬운 비율 하나를 제목·첫 문단에 올리기

# 3. 김명진 글과 전체적으로 비교하면

## 김명진이 상대적으로 강한 부분

1. **사건을 구조적 문제로 재해석하는 능력**
   - 5호선 방화사건 → 1인승무 시스템
   - 통상임금 판결 → 총인건비 제도
   - 인력·사고 → 공공기관 운영구조

2. **정책의 내부 모순을 한 문장으로 압축하는 능력**

3. **구체적인 정책 요구까지 연결하는 능력**

4. **기억에 남는 제목과 문장**
   - 수치, 역설, 질문형 구조를 잘 사용함.

## 다른 담당자 자료에서 김명진보다 더 안정적으로 보이는 부분

1. **문서 기능을 좁게 유지**
   - 취재요청이면 행사 취재 이유와 실무정보에 집중함.
   - 배경 논증은 붙임으로 넘김.

2. **제3자 근거의 발화주체 표시**
   - ‘정부가 밝혔다 / 기관이 판단했다 / 연구에서 나타났다 / 노조는 평가한다’를 분리함.

3. **당사자 장면을 먼저 사용**
   - 구조적 주장을 생활 장면으로 번역함.

4. **외부 source pack과 메인 본문 분리**
   - 원문·발언문·상세자료를 모두 본문 안에 넣지 않음.

# 4. 김명진이 실제로 가져오면 효과가 큰 5가지

## ① ‘구조 설명’보다 ‘새 사실’ 한 칸 앞에 두기

현재 김명진 글은 구조해석이 너무 빨리 나올 때가 있음.

권장 순서:
**새 사실 → 숫자/공식문서 → 판단 → 구조적 의미 → 요구**

## ② 제3자 자료가 있으면 노조가 덜 말하기

판정문, 정부 문서, 조직진단, 연구, 감사 결과가 강하면:
- 원문이 확인한 것
- 그로부터 확인되는 효과
- 노조의 평가
를 분리함.

## ③ 취재요청은 700~1,000자 안의 ‘취재 인터페이스’로 생각하기

기자가 바로 알아야 할 것:
- 무엇이 새 뉴스인지
- 언제 어디서 하는지
- 누가 어떤 새 내용을 말하는지
- 숫자/문서/증언 중 무엇을 공개하는지
- 누구에게 연락하면 되는지

그 밖의 역사·제도 설명은 붙임 1쪽으로 분리.

## ④ 사건의 구조적 확장은 한 단계만

좋은 확장:
철도 사고 → 작업통제·안전인력 문제

과한 확장:
철도 사고 → 인력정책 → 경영평가 → 공공기관 개혁 전체 → 민영화 전체

한 문서에서 첫 번째 구조까지만 증명하고 끝내는 편이 기사 활용성이 높음.

## ⑤ 사람을 한 명 넣기

정책자료라도:
- 1인 역사근무 노동자가 실제로 무엇을 동시에 하는지
- 휴가를 쓰면 다른 역이 어떻게 비는지
- 인력 0명 증원 때문에 누가 몇 회 타역 지원을 갔는지

처럼 한 사람의 노동 장면을 먼저 놓으면 김명진의 강한 정책논증이 더 쉽게 읽힘.

# 5. 현재 단계에서 ‘잘 쓰는 작성자’에 대해 말할 수 있는 범위

현재 근거로 개인별 순위를 매기는 것은 부정확함.

다만 **참고할 만한 기술이 반복 또는 명확하게 확인되는 담당자/자료**는 다음과 같이 분류할 수 있음.

- 강해현 담당 자료: 외부 공식문서 → 귀속된 주장 → 노조평가 분리
- 김호세아 담당/명의 자료: 당사자 장면 + 조사수치로 제도문제 번역
- 최종하 담당 자료: 장기투쟁에서 ‘이번 새 사건’을 제목과 첫 문단에 세움
- 배동산 담당 자료: 복수 사업장의 취재 동선·문의·실무정보 구성
- 김지영 담당 자료: 대규모 공동행동의 규모·주체·요구 제시

이는 ‘누가 가장 잘 쓴다’는 판정이 아니라 **김명진이 상황별로 참고할 수 있는 기능별 레퍼런스**임.

# 6. 남은 검증

최종 담당자 분석은 새 추출 결과에서 다음을 확인한 뒤 확정함.

1. 2023~2026 전체 대상에서 제목과 HWP가 실제로 일치하는 문서 수
2. 명시적 문의/담당 구역에서 개인명이 확인되는 문서 수
3. 동일 연락처·이름 중복 제거
4. 한 사람당 서로 다른 사건이 3건 이상인 경우 우선 심층독해
5. 같은 행사 취재요청+보도자료는 2건이 아니라 ‘1사건 2문서’로 별도 표시
6. 공동문의는 한 사람의 단독 작성으로 간주하지 않음
7. 최종 결과에서도 ‘작성자’가 아니라 ‘담당자 기준 작성자 추정’으로 표기

이 검증 전에는 개인별 순위나 ‘공공운수노조에서 가장 잘 쓰는 사람’ 같은 결론을 내리지 않음.

# 7. 실제 보도 전환 여부 교차검증

자료 자체의 문장력과 별개로 ‘기자가 얼마나 쉽게 기사 골격으로 전환했는가’를 확인하기 위해 공개 보도를 교차확인함.

## 강해현 담당 2025.04.16 자료

같은 날 공개된 보도는 공공운수노조 자료의 핵심 순서를 거의 유지함.

- 국제음악가연맹이 문체부에 공식서한 발송
- 이해당사자 협의 부족 지적
- 지역문화 역량 강화라는 대안
- 국내 예술계의 선행 반대 경과
- 공공운수노조 입장

즉, 자료의 정보 위계가 이미 기사 구조와 가까웠음. ‘외부 공식자료가 주인공인 보도자료’의 좋은 편집 사례로 볼 수 있음.

## 김지영 담당 2025.05.29 자료

취재요청에서 태안·창원 동시 개최, 200여 단체, 전국 기후정의버스, 발전노동자 고용보장·공공재생에너지라는 두 축이 제시됨. 실제 행사 보도에서도 ‘두 지역 동시 개최’와 ‘발전노동자 총고용 보장 + 공공재생에너지 확대’가 주요 기사 골격으로 사용됨.

다만 사전자료의 예상 참가규모와 실제 참가규모는 달라질 수 있으므로, 사전 취재요청에서 규모 수치는 반드시 ‘예상/주최 측 계획’임을 문장 자체에 표시하는 편이 안전함.

## 김호세아 관련 공개 글

동일한 사회서비스 현안을 본인 명의로 작성한 공개 기사에서는 324명 조사, 운영중단 반대 96%, 민간 대비 서비스 만족 98.1% 등 가장 이해하기 쉬운 수치를 기사 초반에 배치함. 이는 정책의제를 ‘공공성’이라는 추상어부터 설명하지 않고 이용자 응답이라는 구체적 사실로 번역하는 방식임.

## 시사점

김명진 글의 기자 활용성을 높이는 핵심은 ‘더 쉽게 쓰기’가 아니라 **기자가 첫 3문장을 거의 다시 설계하지 않아도 되게 정보 위계를 먼저 만들어 주는 것**임.

권장 3문장:
1. 오늘 새로 확인·발표·결정된 사실
2. 그 사실의 크기 또는 가장 강한 수치/공식근거
3. 노조가 요구하는 직접 조치

구조적 의미는 그 다음 문단에서 설명함.

# 8. 추가 단건·소수표본 심층독해

아래 사람들은 현재 담당자 매핑상 반복 표본이 충분하지 않아 개인의 일반적 문체로 단정하지 않음. 다만 개별 자료가 특정 기능에서 참고할 가치가 있어 별도 기록함.

## 류남미 — 하나의 프레임을 통계와 요구로 끝까지 밀어가는 정책형 보도자료

### 확인 문서
- 2024.03.26 보도자료 — 「22대 총선, 비정규직이 사라졌다」

### 관찰
- 제목의 핵심 프레임을 첫 문단에서 바로 설명하고, 이후 공약·정부정책의 부재라는 문제제기와 비정규직 증가 통계를 붙인 뒤 공공부문 요구로 연결함.
- 2019년 187만명→2023년 226만명, 비정규직 비율 40.5%, 공공부문 기간제 16.7만명→24만명 등 숫자가 논증의 축으로 쓰임.
- 기자회견문·근거통계·세부요구를 한 자료에 모두 수록해 source pack 기능은 강하지만 메인 보도자료로는 지나치게 길어짐.
- 핵심 프레임은 선명하나 후반부에 저출산·양극화·공무직 제도·자회사 등으로 범위가 확장되면서 중심이 약해지는 구간이 있음.

### 김명진이 참고할 기술
- 제목에서 만든 한 문장을 **통계 2~3개로 증명하는 방식**.
- 다만 김명진 역시 확장 성향이 강하므로, 이 사례의 장점인 프레임과 수치만 가져오고 전체 요구안을 본문에 다 넣는 방식은 피하는 편이 좋음.

## 박인화 — 실태조사의 강한 숫자를 뉴스로 전환하는 자료

### 확인 문서
- 2024.01.31 보도자료 — 물류센터 노동안전 및 임금 실태조사 결과발표 기자회견

### 관찰
- 435명 조사와 더위 83%, 먼지 80%, 추위 73%, 근골격계 통증 등 **기사 제목으로 바로 전환 가능한 수치**가 명확함.
- 실제 보도에서도 ‘80% 이상이 더위·추위·먼지로 고통’처럼 가장 센 숫자가 제목·리드로 활용됨.
- ‘물류센터가 열악하다’는 일반론보다 조사결과가 먼저 서기 때문에 기자가 별도의 뉴스가치를 만들 필요가 적음.
- 자료의 힘은 문장 수사보다 조사 설계와 숫자 선택에 있음.

### 김명진이 참고할 기술
- 실태조사·설문·조직진단 자료는 배경설명보다 **가장 강한 숫자 1개를 제목과 첫 문장에 배치**.
- 숫자를 많이 나열하기보다 ‘대표수치 → 보조수치 2개 → 요구’ 순으로 편집.

## 김상철 — 공공정책 쟁점을 시민의 비용·절차·대안으로 번역

### 확인 문서
- 2023.01.13 취재요청 — 서울시 대중교통요금 인상 계획 백지화 촉구 긴급 기자회견
- 같은 시기 대중교통요금 토론회·시민공청회 청구 등 연속 자료에서 담당 표기가 반복 확인됨.

### 관찰
- 요금 문제를 단순한 ‘인상 반대’에 두지 않고 시민경제·교통불평등·기후위기와 연결함.
- 이후 자료에서는 5,000명 이상 시민서명을 통한 공청회 청구 등 **반대 이후의 절차적 대안**까지 제시함.
- 대중교통 적자와 비용 문제를 시민 부담 전가라는 언어로 번역하는 능력이 있음.
- 반면 하나의 자료에 경제·기후·불평등·재정구조가 동시에 들어가 제목과 논점이 길어질 위험이 있음.

### 김명진이 참고할 기술
- 정책 반대 자료에서 ‘왜 문제인가’뿐 아니라 **다음에 무엇을 할 것인가라는 제도적·절차적 행동**을 뉴스로 만들기.
- 구조 설명은 여러 가치축을 병렬로 늘이기보다 당일 핵심축 하나를 선택.

## 최세호 — 새 제보·구체적 수치로 장기투쟁에 새로운 뉴스가치를 만드는 사례

### 확인 문서
- 2026.04.03 보도자료 — 택시노동자 고공농성 청와대 직접해결 및 택시사업자 탈세 제보 기자회견

### 관찰
- 고공농성이라는 기존 투쟁에 ‘택시사업자 탈세 제보’라는 별도의 신규 팩트를 결합함.
- 공개 보도에서는 서울 법인택시 248개사 중 169개사, 기사 1인당 월평균 약 185만원, 실제 운송수입의 약 33%라는 수치가 핵심 기사재료로 사용됨.
- 장기투쟁을 반복 소개하는 대신 **새로운 자료·제보를 투쟁의 다음 뉴스로 만드는 방식**이 강함.
- 다만 ‘탈세’처럼 법적 판단이 필요한 표현은 보도자료 단계에서 ‘노조 조사/제보/의혹 제기’와 확정사실을 더 엄격히 구분할 필요가 있음.

### 김명진이 참고할 기술
- 장기 현안은 새로운 기자회견을 열 때마다 **새 문서·새 수치·새 증언·새 절차** 중 하나를 반드시 전면에 세우기.
- 법적·회계적 주장은 주체와 근거를 명시해 사실·평가를 분리.

## 김계호 — 복잡한 안전법 적용 문제를 ‘같은 일터의 차별’로 구체화

### 확인 문서
- 2023.04.25 취재요청 — 산안법 현업업무 고시 확대 및 적용제외 시행령 개정을 위한 증언대회

### 관찰
- 시행령·현업고시라는 난해한 제도를 ‘같은 일터에서도 직종에 따라 산업안전보건법 적용이 달라지는 문제’로 번역함.
- 요구대상도 현업고시 확대, 적용제외 개선처럼 구체적임.
- 이후 관련 공개자료에서는 수도검침, 콜센터, 학교·국방 조리 등 **현장 사례가 제도 문제의 증거**로 사용됨.
- 제도 설명 자체는 길어질 수 있으므로 취재요청에서는 사례 1~2개와 개정요구를 먼저 두는 편이 더 강함.

### 김명진이 참고할 기술
- 법·지침 문제는 조문부터 설명하지 않고 **‘같은 일을 하는데 누구는 보호받고 누구는 제외된다’ 같은 현장 모순**을 첫 문장으로 번역.
- 제도명은 두 번째 문단 이후에 배치해도 됨.

## 허유경 — 사건 개요와 노동위 절차가 명확한 현장형 자료

### 확인 문서
- 2024.05.29 보도자료 — 집단 부당해고 철회! 서울교통공사 규탄 및 원직복직 판결 촉구 기자회견

### 관찰
- 노조 전임활동 → 무단결근 판단 → 36명 해고 → 노동위원회 구제신청이라는 사건 흐름이 비교적 명료함.
- ‘무엇이 벌어졌고 지금 어느 절차에 와 있는가’가 분명해 실제 기사도 이 골격을 활용함.
- 노사관행, 인사위 결정, 노동위 심문 등 후속 취재 지점이 있음.
- 반면 외압·노조 길들이기 등 동기 해석은 노조 주장으로 귀속하지 않으면 사실·평가 경계가 약해질 수 있음.

### 김명진이 참고할 기술
- 노동위·법원·감사 등 절차가 있는 사건은 **사건 → 현재 절차 → 바로 다음 결정시점 → 요구** 순으로 구성.
- 상대의 의도는 최소화하고 확인 가능한 처분·판정·절차를 앞세우기.

## 추가 결론

이번 추가 독해를 반영하면 기존 ‘기능별 레퍼런스’에 다음 세 유형을 더 넣을 가치가 있음.

- **박인화 담당 자료:** 조사자료의 대표수치를 기사 제목으로 전환하는 데이터형
- **류남미 담당 자료:** 하나의 정치·정책 프레임을 통계와 요구로 밀어붙이는 프레임형
- **김상철 담당 자료:** 정책반대를 시민의 비용·절차·대안으로 번역하는 공공정책형
- **최세호 담당 자료:** 장기투쟁에 새 제보·수치를 붙여 뉴스성을 갱신하는 제보형
- **김계호 담당 자료:** 복잡한 법 적용 문제를 현장 차별 사례로 설명하는 제도번역형
- **허유경 담당 자료:** 노동위 등 사건 절차를 기자가 따라가기 쉽게 만드는 사건절차형

개인 우열보다 이 기능 구분이 김명진의 실제 작성에 더 유용함.

# 9. 사용자 추가 제시 14명 1차 검증

대상: 정양현, 안그라미, 남욱진, 이승철, 공성식, 박준형, 서보람, 한재영, 오승은, 조진, 박준선, 신철, 김종태, 김재천

기존 자동추출이 이 명단을 상당수 놓친 것이 확인됨. 따라서 기존 담당자 빈도표만으로 이들을 제외하면 안 됨.

## A. 반드시 심층 비교에 포함할 사람

### 공성식
- 2010년대 후반부터 공공부문 비정규직, 공공기관 임금·인력·노정교섭 등 정책자료·토론·언론대응에 반복 등장.
- 2026년에는 공공기관사업팀장으로 공공기관 지방이전 등 정책기고도 직접 작성.
- 단순 문의담당자가 아니라 정책문장과 논증 자체를 비교할 가치가 큼.
- 김명진과 같은 공공기관 정책영역이라 직접 비교 우선순위가 높음.

### 박준형
- 과거 정책기획실장·부대변인으로 보도자료·취재요청 담당 흔적이 분명함.
- 장문 정책글·노동운동사 글도 있어 문장과 논증의 장기적 특징을 비교할 수 있음.
- 2023~2026 현행 코퍼스만 보면 놓치기 쉬우므로 과거 아카이브까지 확장 필요.

### 한재영
- 인천공항 정규직 전환, 청년노동, 지방공공기관 구조조정 등에서 본인 명의 기고·발제 다수 확인.
- 현장 장면과 정책구조를 함께 쓰는 유형으로 보이며 김명진과 비교 가치가 높음.
- 2023년 공공기관사업국장 시기 자료까지 연결해 볼 필요가 있음.

### 정양현
- 2025~2026 노조법 2·3조, 공공부문 비정규직 정책 등에서 정책담당 및 취재자료 담당이 반복 확인됨.
- 현행 정책기획실 자료의 현재형 문체를 보여주는 표본으로 중요.
- 단순 연락담당인지 실제 문안작성자인지는 개별 문서별 검증 필요.

### 남욱진
- 2026년 특고·플랫폼 적정임금, 지방선거 정책요구, 공공부문 비정규직 임금 등 기자회견·토론회 담당이 반복됨.
- 최근 정책자료 작성/편집 흐름을 보여주는 후보로 중요.
- 현재 코퍼스 자동 담당자 추출에서는 누락되어 별도 수작업 확인 필요.

### 이승철
- 현 정책기획실장으로 정책포럼·대외토론 및 언론 인터뷰가 반복됨.
- 언론자료 초안 담당 여부와 별개로 정책논증·대외메시지 설계 비교에 가치가 있음.
- 성명·보도자료 장르와 장문 정책글을 구분해 비교해야 함.

## B. 현재 코퍼스에서 직접 비교 가치가 확인된 사람

### 오승은
- 2026.02.10~11 지방공공기관 총인건비제 개선 ‘패싱’ 행안부 규탄 취재요청·보도자료에서 핵심 사업 담당.
- 문서는 중앙공공기관 지침과 지방공공기관 지침의 4개 차이를 구체적으로 비교하여 정책 쟁점을 기사거리로 전환함.
- 장점: 비교대상과 요구가 명확함.
- 약점: 취재요청 단계부터 총인건비 제도의 전체 역사·구조설명이 길어져 핵심 뉴스가 묻히는 구간이 있음.
- 김명진 글과 매우 직접 비교 가능한 사례.

### 박준선
- 2025~2026 발전산업·김충현 대책위, 공공기관 자회사 비리·실태조사 등에서 반복적으로 현장·언론대응 담당 확인.
- 2025.11.26 발전소 보도자료는 ‘당일 장관 방문 → 당사자 배제 → 현장 항의 → 장관 답변 → 다음 협의체 일정’의 시간순 뉴스 구조가 비교적 명확함.
- 2026.06 지역난방안전 자료는 제보·실태조사 수치를 전면에 배치해 뉴스성이 강함.
- 다만 본문 후반부에 경과·요구·붙임이 많이 붙어 source pack화되는 경향이 있음.

### 조진
- 정의로운 전환·공공재생에너지 관련 자료와 대외토론에서 반복 등장.
- 2025.05.31 정의로운 전환 대행진 취재요청은 200여 단체, 두 지역 동시 개최, 버스·예상 참가규모 등 ‘대형 공동행동’ 정보 설계가 강점.
- 정책적 의미를 길게 설명하는 구간은 김명진과 비슷하게 확장성이 큼.
- 에너지 정책 자료까지 연결하면 별도 비교 가치가 있음.

### 신철
- 2024 공공부문 비정규직 차별해소 예산 공동투쟁 취재요청과 2025~2026 비정규직 공동투쟁 언론일정에서 반복 담당.
- 2024 자료는 ‘상반기 요구 → 설문수치 → 각 부처 요구 → 결국 기재부라는 결론 → 공동행동’ 구조가 단순하고 실무적임.
- 현재는 표본 수가 충분하지 않아 개인 문체로 단정하기보다는 조직·투쟁형 취재요청 참고사례로 보는 것이 적절.

## C. 역할상 중요하지만 현재 글쓰기 표본이 부족한 사람

### 안그라미
- 과거 공공기관사업 담당 경력과 공공성FESTA 등 행사 담당 흔적은 확인됨.
- 현재 자동추출 자료만으로는 언론문안 작성 특징을 판단하기 어려움.
- 과거 공공기관사업본부 아카이브를 추가 탐색할 필요가 있음.

### 서보람
- 2026 공공기관사업팀 산하조직·사업 담당 흔적은 분명함.
- 현재 공개 언론자료에서 개인 담당이 명확한 표본은 아직 부족함.

### 김종태
- 조직쟁의부장으로 공무직·중앙행정기관 사업 및 증언대회 준비 흔적 확인.
- 현재 언론자료 담당/작성 표본은 부족함.

### 김재천
- 조직쟁의국장으로 물류센터·조직사업 관여 흔적은 확인되나, 현재 언론자료 작성 표본은 부족함.
