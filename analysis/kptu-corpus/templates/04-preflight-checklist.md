# 배포 전 3분 체크

## 사실
- [ ] 날짜·요일·시간
- [ ] 이름·직책
- [ ] 숫자의 분모·기준일
- [ ] 근거 원문 직접 확인
- [ ] 상대방 입장 확인
- [ ] 판정의 결론과 이유 구분
- [ ] 사실과 노조 평가 구분
- [ ] 사망·질병·사고 인과관계 귀속 표시

## 뉴스성
- [ ] 오늘 새로 생긴 사실이 제목에 있음
- [ ] 가장 강한 숫자가 첫 화면에 있음
- [ ] 첫 3문장으로 기사 리드 작성 가능
- [ ] 인용 가능한 한 문장이 있음

## 장르
- [ ] 취재요청이 정책보고서가 되지 않음
- [ ] 보도자료가 취재요청 복사본이 아님
- [ ] 성명에 판단과 근거가 모두 있음

## 패키지
- [ ] 본문과 발언 전문 분리
- [ ] 원자료/표/사진 연결
- [ ] 연락처
- [ ] 웹 링크 실제 열림
- [ ] 첨부파일이 해당 게시물과 일치
- [ ] 최종본 버전 표시

## 행사 후
- [ ] 새 사실 3개 기록
- [ ] 숫자 3개 기록
- [ ] 인용 3개 기록
- [ ] 기사클리핑 연결
