# 장르를 넘나들며 반복되는 좋은 재료

## 1. 제3자 근거
- 외부 연구
- 공식 통계
- 정부 문서
- 판정문
- 조사결과

노조 자체의 수사보다 기사에서 오래 살아남는 경우가 많다.

## 2. 비교 가능한 숫자
단일 숫자보다:
- 현재 vs 필요
- 이전 vs 이후
- 중앙 vs 지방
- 정규직 vs 자회사
처럼 비교 구조가 강하다.

## 3. 한 문장으로 요약되는 모순
예:
- 사람이 필요해서 증원하는데 기존 사람부터 줄여라
- 인력은 허용하면서 그 인건비는 허용하지 않는다

정책을 모르는 독자도 이해할 수 있다.

## 4. 현장 장면
- 혼자 역사 관리
- 연차를 쓰면 1인근무
- 점검시간이 몇 분
- 사건 처리까지 몇 개월/몇 년
처럼 추상적 제도가 실제 노동에 미치는 장면.

# 반면교사로 볼 패턴

특정 자료를 ‘나쁜 자료’라고 순위화하는 것이 아니라, 코퍼스에서 반복된 편집 문제다.

### 1. 행사 전 배경을 행사 후에도 거의 그대로 반복
→ 보도자료가 새 뉴스가 되지 못함.

### 2. 발언문 전문을 메인 본문 뒤에 모두 붙임
→ 중요한 인용 1개와 참고용 전문이 같은 무게가 됨.

### 3. 제목은 강하지만 근거가 뒤쪽
→ 기자는 제목의 수사보다 숫자/공식문서를 찾아 다시 기사화함.

### 4. 사건보다 정권·정책 전체 평가가 길어짐
→ 성명의 당일 트리거가 흐려짐.

### 5. 판정 결과를 기존 주장 전체의 인정으로 확대
→ 이후 판정 이유가 공개될 때 정확성 문제가 생길 수 있음.

# 활용법

새 자료를 쓸 때 “무슨 장르인가?” 다음으로 “무슨 유형인가?”를 고른다.

- 법안/결정 공개 → A
- 이미 큰 사건의 구조적 재해석 → B
- 현장 인력·안전 → C
- 복잡한 정책 → D + 별도 팩트시트
- 조사결과 → E
- 연대체/캠페인 출범 → F
- 자료가 매우 많은 기자회견 → G 구조를 source pack으로만 활용
- 정부 정책평가 → H
- 상대 문서 비판 → I
- 일부 진전 평가 → J

그 뒤 사건 팩트시트와 장르 템플릿을 사용한다.
