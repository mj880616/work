무엇이 바뀌나: 내 프로필 표의 "화면 선택 기억" 값 검사 하나만 바꿔, 화면 색(theme)으로 기억할 수 있는 값을 4가지에서 10가지로 늘립니다(쑥·라벤더·먹·장미·청록·겨자 추가). 새 칸은 없고 다른 규칙(허용 칸 여덟 개, 달력 보기·메뉴·노트 폴더·분할 비율·사업 보고 보기·숨김 날짜, 전체 4000바이트 상한)은 그대로입니다. 기존 자료·권한·정책은 바꾸지 않습니다.
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 적용 전에는 새 색을 고르면 서버가 거절해 화면이 원래 색을 유지하고 알림을 띄우며, 적용 뒤 문제가 나도 기존 4가지 색과 다른 화면 선택은 그대로 동작합니다.
