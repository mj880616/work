무엇이 바뀌나: 담당조직과 사업 보고의 [삭제]를 누르면 바로 지우지 않고 휴지통으로 옮겨 화면에서만 빠집니다. 조직의 기록·담당자·타임라인·쟁의단계, 사업 보고에 달린 메모 연결·원장 연결은 끊기지 않고 그대로 남아, 나중에 휴지통에서 되돌리면 원래대로 돌아옵니다. 영구 삭제는 휴지통에서 직접 누를 때만 일어나고 자동 비우기는 없습니다. 프로젝트 휴지통은 그대로입니다.
