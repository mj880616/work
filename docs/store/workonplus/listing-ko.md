글자 수는 `tests/store-workonplus.test.mjs`가 센다(앱 이름 30자, 짧은 설명 80자, 자세한 설명 4000자 안).
기준: 실제 있는 기능만, 운영자 전용 기능(News·텔레그램·통화·브리핑 룸)은 쓰지 않는다. '최고'·'1위'·'무료 최고' 같은 꾸밈말, 순위, 가격 홍보, 다른 앱 이름을 쓰지 않는다(플레이 메타데이터 정책).

```
일정·할 일·노트·사진·파일을 한 앱에서. 구글 캘린더·할 일 연결, 폰과 PC 같은 기록
```

## 자세한 설명

```
WORK ON+는 일정, 할 일, 노트, 사진, 파일을 한곳에 모아 정리하는 개인 업무 관리 앱입니다.
폰 앱과 웹(PC)에서 같은 기록을 이어서 쓸 수 있습니다.

■ 한 앱에서 정리
· 일정: 달력(월·목록)으로 보고, 일정을 만들고 고칩니다.
· 할 일: 기한별(기한 지남·오늘·내일·일주일 안)로 묶어 보고, 완료를 표시합니다.
· 노트: 폴더·태그·보드·달력으로 정리하고, 사진과 파일을 함께 붙입니다.
· 하루 기록: 그날의 글과 사진을 남기고 날짜별로 다시 봅니다.
· 사진·자료실: 폰 사진과 올린 자료를 날짜·폴더로 찾습니다.

■ 구글 캘린더·할 일 연결
구글 캘린더와 구글 할 일을 연결하면, WORK ON+에서 보고 만들고 고친 내용이 구글 쪽에도 그대로 반영됩니다. 올린 자료는 내 구글 드라이브에 저장됩니다. 연결은 내가 직접 [연결]을 누를 때만 켜지고, 연결하지 않아도 기본 기록은 쓸 수 있습니다.

■ 홈 화면 '이번 주' 위젯
폰 홈 화면에서 이번 주 요일별 일정 수와 고른 날의 일정을 바로 봅니다. 앞뒤 주로 넘겨 볼 수 있습니다.

■ 공유 버튼으로 글 저장
다른 앱에서 읽던 글을 공유 버튼으로 WORK ON+에 보냅니다. 저장한 글은 원문을 받아 두고, 문장에 밑줄을 긋고 메모를 남기고, AI 요약을 볼 수 있습니다. 밑줄 친 문장은 노트로 옮길 수 있습니다.

■ 폰과 PC에서 같은 기록
기록은 서버에 저장되어 폰, 폴더블 폰, PC 브라우저 어디서 열어도 같습니다. 폰을 바꿔도 구글 계정으로 다시 로그인하면 그대로입니다.

■ 내 기록은 나만
한 사람이 자기 작업공간 하나를 씁니다. 내가 기록한 내용은 운영자도 볼 수 없습니다. 운영자에게 가는 정보는 이메일 주소, 가입일, 마지막 사용 시각뿐입니다.

■ 기능 잠금
하루 기록, 사진, 노트 폴더를 4자리 PIN으로 잠글 수 있습니다. 다시 잠그는 시간(바로·5분·30분·앱 닫을 때)도 고릅니다.

■ 내 말로 바꾸기
메뉴 이름과 기록 분류 이름을 내가 쓰는 말로 바꿀 수 있고, 바꾼 이름은 모든 기기에 똑같이 보입니다.

■ 알아 두기
· 구글 계정으로 로그인합니다. 따로 비밀번호를 만들지 않습니다.
· 광고가 없습니다.
· 개인정보 처리방침: https://work.bokdoong.com/work/about/privacy/
· 계정·데이터 삭제 요청: https://workonplus.com/work/about/delete-account/
```
