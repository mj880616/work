무엇이 바뀌나: 노트 보드의 글 상자 표에 '부모 노트 카드' 칸 하나(parent_note)가 더해지고, 글자·도형도 가지가 될 수 있게 꾸미기 검사에서 '글자·도형은 부모 없음' 줄만 뺍니다. 부모는 글 상자나 노트 카드 둘 중 하나만 받고, 노트 카드 부모는 같은 작업공간 노트만 받도록 좁히기 정책 하나를 더합니다. 기존 owner 정책·권한 범위는 그대로이고 주인만 읽고 고칩니다.
잘못되면: 사전 확인이나 적용 안 확인이 어긋나면 전체가 취소되어 아무것도 바뀌지 않습니다. 기존 상자·도형·글자·선·노트는 한 줄도 바뀌지 않으므로, 적용 뒤 문제가 있어도 옛 보드는 그대로 보입니다. 노트를 지우면 그 아래 가지는 지워지지 않고 혼자 선 칸으로 남습니다.
되돌리는 법: (새 화면을 배포했다면 먼저 이전 판으로) 짝 rollback을 SQL Editor 새 창에서 실행합니다. 이미 카드 아래 가지나 글자·도형 가지가 있으면 지우지 않고 멈추므로, 화면에서 먼저 떼어 낸 뒤 다시 실행합니다.
