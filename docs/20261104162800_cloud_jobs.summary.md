무엇이 바뀌나: 파일 복사·옮기기를 화면을 닫아도 서버가 이어서 하도록, 전송 한 건마다 진행(보낸 크기)·상태·실패 까닭을 적는 새 표 1개와, 큰 파일을 이어 올리는 자리(클라우드가 준 올리기 주소)를 서버만 읽게 두는 새 표 1개가 생깁니다. 명진만 진행을 읽을 수 있고 올리기 주소는 화면에서도 못 읽으며, 쓰기는 서버 함수만 합니다. 기존 표·권한은 바꾸지 않습니다.
잘못되면: 사전 확인·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 표가 없으면 새 화면은 전송 목록 대신 '잠시 뒤 다시' 안내를 보이고, 파일·색인에는 영향이 없습니다.
되돌리는 법: (화면·Edge를 먼저 이전 판으로 두고 전송을 모두 멈춘 뒤) 짝 rollback을 SQL Editor 새 창에서 실행해 새 표 2개·기록 1행만 지웁니다. 클라우드 파일·색인은 그대로 남습니다.
