무엇이 바뀌나: 텔레그램 소식의 '그날 요약'과 시각별 요약 줄을 명진이 손으로 고친 값을 따로 담는 표 둘(고친 값 / 고친 이력)과, 로그인한 명진 본인만 그 값을 저장하는 함수 하나가 생깁니다. 지금 소식 줄과 AI가 쓴 요약은 한 글자도 바뀌지 않고, 화면이 아직 새 표를 쓰지 않으므로 겉으로 달라지는 것은 없습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 문제가 생겨도 새 표는 비어 있고 텔레그램 소식 화면·수집은 지금 그대로 돕니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 새 함수와 표 둘, 기록 1행만 걷어 냅니다. 고친 값이 한 줄이라도 있으면 값을 잃지 않도록 멈춥니다.
