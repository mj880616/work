무엇이 바뀌나: 조직·사업 보고 기록 연결마다 '어디서 만들었는지'(기록 입력칸에서 바로 올림 / 잊지 말기에서 옮김) 작은 표시 칸 하나를 더하고, 연결 저장 함수가 그 표시를 받아 저장하게 합니다. 지난 기록은 빈칸으로 두고(지금처럼 '잊지 말기 연결'로 보임), 권한·다른 검사는 그대로입니다. 화면은 다음 PR에서 바뀝니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 문제가 생겨도 기록 원문·연결은 그대로이고, 화면 PR이 들어가기 전에는 표시 칸이 비어 있어 화면 변화가 없습니다.
되돌리는 법: (화면 PR을 merge했다면 먼저 이전 판으로) 짝 rollback을 SQL Editor 새 창에서 실행해 저장 함수를 이전 본문으로 되돌리고 표시 칸·검사·기록 1행만 지웁니다. 저장된 표시는 함께 없어져 모두 '잊지 말기 연결'로 돌아가고, 기록·연결 자체는 그대로 남습니다.
