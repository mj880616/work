무엇이 바뀌나: 메뉴 '읽을 거리'에 저장할 글(주소·제목·받아 둔 원문)을 담는 새 표가 생기고, 기존 밑줄 표가 읽을 거리 밑줄도 받으며, 전체 검색이 이름으로 부를 때 읽을 거리도 찾습니다. 새 표는 자기 작업공간 주인만 보고 쓰며(운영자·서버 권한 없음), 기존 표·권한·자료와 지금 검색 결과는 그대로입니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 화면은 아직 이 표를 쓰지 않으므로 지금 기록과 검색에는 영향이 없습니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 검색 함수·밑줄 검사를 이전 판으로 돌리고 새 표와 기록 1행만 지웁니다. 저장한 읽을 거리만 사라지고 다른 기록은 그대로입니다.
