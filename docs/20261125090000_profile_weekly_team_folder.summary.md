무엇이 바뀌나: 사람마다 '팀 보고 취합 저장 폴더' 한 칸(자료실 폴더 번호, 비어 있으면 처음 저장 때 물음)이 내 프로필 표에 생깁니다. 내 주간 보고 저장 폴더 칸은 그대로이고, 표 권한·정책·함수는 바꾸지 않습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 문제가 있어도 팀 보고 취합 파일이 지금처럼 폴더를 정하지 않은 채 남을 뿐, 자료·폴더·드라이브 파일은 그대로입니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 이 칸·색인만 걷어 냅니다. 화면은 칸이 없으면 주간 보고 저장 폴더 하나만 쓰는 지금 동작으로 돌아갑니다. 자료·폴더는 지우지 않습니다.
