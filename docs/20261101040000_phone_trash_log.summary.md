무엇이 바뀌나: 사진 정리에서 '폰에서만 지우기'로 지운 사진의 기록(사진 번호·원드라이브 사본 번호·지운 시각만)을 남길 새 표 하나가 생깁니다. 자기 작업공간 주인만 읽고, 넣고 고치는 것은 서버 함수만 합니다. 사진 이름·내용은 넣지 않습니다. 서버 함수·화면은 아직 이 표를 쓰지 않아 겉으로 달라지는 것은 없습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 기존 표의 권한·정책·함수는 건드리지 않으므로 다른 메뉴는 그대로입니다.
되돌리는 법: (화면·서버 함수를 붙였다면 먼저 되돌린 뒤) 짝 rollback을 SQL Editor 새 창에서 실행해 새 표와 기록 1행만 지웁니다. 지워지는 것은 지운 사진 기록뿐이고 사진·업무 자료는 없습니다.
