무엇이 바뀌나: 노트 아래 댓글(생각·질문·인용)을 담는 새 표 1개가 생깁니다. 노트 주인만 읽고 쓰며, 기존 노트·표·권한은 한 줄도 바뀌지 않습니다. 해시태그는 노트 본문 글자를 읽어 모으므로 새 칸이 없습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 새 표만 만들므로 노트·다른 화면에는 영향이 없고, 표가 없으면 노트 화면은 댓글 칸만 '준비 중'으로 보입니다.
되돌리는 법: (새 노트 화면을 배포했다면 먼저 이전 판으로 되돌린 뒤) 짝 rollback을 SQL Editor 새 창에서 실행해 새 표와 기록 1행만 지웁니다. 적어 둔 댓글은 함께 사라지고 노트는 그대로입니다.
