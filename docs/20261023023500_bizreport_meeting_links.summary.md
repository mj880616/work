무엇이 바뀌나: 연결 표에 '출처 회의' 칸을 더해 사업 보고 한 건을 여러 조직·프로젝트에 이을 수 있게 하고(같은 곳은 한 줄, 같은 업무공간만), 고른 곳을 한 번에 맞추는 저장 함수 하나를 더합니다. 기존 회의의 프로젝트 연결은 같은 곳으로 연결 줄을 한 번 채우고, 사업 보고에 장소 칸(비워도 됨, 200자 이하)이 없으면 더합니다. 기존 권한·소유자 정책은 바꾸지 않고 좁히는 확인 하나만 더합니다.
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 바구니 목록 화면이 회의 연결을 이름 지정 없이 읽는 옛 판이면 목록이 열리지 않을 수 있어, 그 화면 수정(이름 지정)이 배포된 뒤에만 적용합니다. 지금 화면은 새 칸·함수를 쓰지 않으므로 회의 저장·할 일 연결·바구니 분류는 그대로 동작합니다.
되돌리는 법: preserve SQL로 회의 출처 연결 줄을 먼저 보관한 뒤, 짝 rollback을 SQL Editor 새 창에서 실행해 함수·확인·연결 줄·칸과 기록 1행을 지우고 출처·중복 규칙을 원래 모양으로 돌립니다. 회의의 프로젝트 칸과 장소 칸은 그대로 남습니다.
