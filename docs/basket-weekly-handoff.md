# 바구니 새 메모 ChatGPT로 복사 (BASKET-주간넘기기) — 사용자 확정 문구

2026-10-15 사용자 결정. 구현 전 기준 문서. 원장 쓰기는 ChatGPT 단일 writer, Web2는 원장에 쓰지 않는다.

> **재검토 필요(2026-10-21):** ChatGPT 예약 삭제로 "ChatGPT 원장 대화에 넘기기" 전제가 사라졌다. 원장 쓰기는 Web2 AI 후보 → 사용자 확정으로 바뀐다(`ai-work-system-source-of-truth.md`). 기능을 남길지는 별도 판단.

## 화면

- 버튼: **새 메모 ChatGPT로 복사** + 개수 표시(예: "새 메모 12개")
- 버튼 아래 작은 안내: "누르면 복사됨 → ChatGPT 원장 대화에 붙여 넣기"
- 누른 뒤 알림: "새 메모 12개와 요청문을 복사했어요. ChatGPT 원장 대화 입력창에 붙여 넣고 보내세요."
- ~~별도 버튼 [넘겼어요]~~ → 2026-10-16 사용자 결정으로 합침: 복사 뒤 같은 자리에 **"ChatGPT에 보냈나요?" [예] [아직]**을 한 번 묻는다. [예]를 누를 때만 "여기까지 넘긴 것"(기준선)으로 기억한다. [아직]이나 그냥 나가면 기준선은 그대로라 다음에 같은 메모가 다시 복사된다(복사만 하고 안 보낸 경우 대비).
- 범위: 지난번 [예] 뒤 새로 들어온 메모 전부.
- 위치: 주 1회 기능이므로 바구니 [⋯ 더보기] 안에 둔다(2026-10-16 사용자 피드백).
- 기존 [쓰기요청 후보] 버튼·표시는 제거한다(BASKET-4b-2 폐지). 저장된 `metadata.write_request`는 지우지 않고 무시한다.

## 복사될 요청문 (메모 목록 앞에 붙음)

```
아래는 내 업무 바구니에 지난번 이후 새로 들어온 메모 전체야.
장기기억 원장 기준으로 하나씩 판단해서 처리해 줘.

1. 분류
- 원장 기록: 나중에도 찾아볼 사건·결정·근거·약속·변화. 원장에 기록하고, 어느 탭·항목에 썼는지 메모 번호와 함께 알려 줘.
- Web2 정리만: 업무엔 쓰이지만 원장까지는 필요 없는 것. 원장에 쓰지 말고 아래 정리 결과에만 넣어 줘.
- 버림: 임시 메모·중복·이미 끝난 일. 이유 한 줄.

2. 애매한 것
- 원장에 쓸지 판단이 애매하면 쓰지 말고, 먼저 목록으로 묶어서 나한테 물어봐. 내 답을 받은 뒤 처리해 줘.
- 이미 원장에 있는 내용과 겹치면 새로 쓰지 말고 기존 항목 갱신 여부를 물어봐.

3. 돌려줄 것
- 원장에 쓴 것 / 물어볼 것 / 버린 것을 메모 번호로 정리
- 마지막에 Web2 [분류 결과 입력]에 붙여 넣을 정리 결과(기존 형식)

메모 원문은 고치지 말고, 내가 쓰지 않은 사실은 추측해서 넣지 마.
```

맨 끝 "기존 형식"에는 구현 때 현재 [분류 요청]이 쓰는 정리 결과 형식 설명을 그대로 이어 붙인다.
