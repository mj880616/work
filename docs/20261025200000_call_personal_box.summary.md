무엇이 바뀌나: 개인 통화·애매 통화를 담는 별도 표(개인 통화함)가 새로 생기고, 업무 통화함에서 개인 통화함으로(또는 거꾸로) 한 번에 옮기는 길(로그인한 명진 본인만)과 옮겨 온 통화의 제목·상대·조직을 채우는 길이 함수 둘로 생깁니다. 같은 통화가 두 함에 동시에 들어가지 않게 막는 확인도 더해집니다. 지금 업무 통화 줄·권한·정책은 그대로입니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 문제가 생겨도 서버·화면이 아직 새 표를 쓰지 않으므로 지금 통화 메뉴와 원장 자동 기록은 그대로 돕니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 새 표·함수·트리거·칸을 걷어 냅니다. 개인 통화함에 줄이 있거나 옮긴 흔적이 하나라도 있으면 자료를 잃지 않도록 멈춥니다.
