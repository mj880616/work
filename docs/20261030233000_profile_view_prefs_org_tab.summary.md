무엇이 바뀌나: 담당조직 상세 위쪽의 [기록 | 현황 표] 소탭 가운데 고른 것을 서버에 하나로 기억하게 합니다(폰·PC 같음). 바뀌는 것은 내 프로필의 "화면 선택 기억" 값 검사 하나에 칸 하나(org_tab: 기록 또는 현황 표)를 더하는 것뿐이고, 새 열·권한·정책은 없으며 기존 자료와 다른 화면 기억 규칙은 그대로입니다.
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 검사식이 틀리면 다른 화면 선택 저장이 거절될 수 있어, 실제 PostgreSQL 시험으로 앞선 칸이 그대로 받아지는지 확인했습니다. 적용 전에는 소탭 고르기가 저장되지 않을 뿐(화면은 [기록]으로 시작) 다른 기능은 그대로입니다.
