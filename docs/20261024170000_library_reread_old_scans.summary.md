무엇이 바뀌나: 새 글자 읽기(#1101) 전에 올려 "글자 없음"으로 끝난 자료실 사진(JPG·PNG)과 PDF만 골라, 상태 칸 하나를 "아직 안 읽음"으로 되돌립니다. 그러면 매일 밤 글자 채우기가 그 자료를 새 방식(한국어 OCR)으로 다시 읽습니다. 원본 파일·이미 읽힌 글자·제목·분류·권한·정책은 그대로입니다.
잘못되면: 사전 확인이 다르면 아무것도 바꾸지 않고 멈춥니다. 대상이 0개면 기록 1행만 남고 자료는 그대로입니다. 적용 뒤에는 밤마다 몇 개씩 다시 읽을 뿐이고, 다시 읽어도 글자가 없으면 지금처럼 "글자 없음"으로 다시 끝납니다(남에게 보이는 범위 변화 없음).
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 아직 다시 읽지 않은 그 자료들만 "글자 없음" 상태로 돌아가고 기록 1행이 지워집니다. 이미 다시 읽어 글자가 생긴 자료는 그 글자를 지우지 않습니다.
