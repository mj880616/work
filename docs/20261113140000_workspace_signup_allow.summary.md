무엇이 바뀌나: 가입 문을 '명단에 적은 사람만' 열 수 있는 서버 명단 표가 생기고, 역할 트리거 안에 고정돼 있던 운영자 메일이 그 표로 옮겨집니다(저장소에는 메일을 적지 않음). 스위치는 꺼진 채, 명단도 비어 있어 화면·동작은 지금과 같습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 운영자(명진) 계정의 owner 판정이 표로 옮겨지므로, 옮기기가 틀리면 사후 확인(운영자 1행)에서 멈춥니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 두 함수가 이전 정의로 돌아가고 역할 트리거는 운영자만 owner로 하는 모양(명단 표의 운영자 1행을 읽음)으로 돌아갑니다. 명단 표는 지우지 않고 남깁니다(운영자 메일을 저장소에 적지 않기 위해).
