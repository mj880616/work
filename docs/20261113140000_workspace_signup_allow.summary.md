무엇이 바뀌나: 누구나 자기 작업공간을 스스로 만들 수 있게, 막혀 있던 서버 규칙(운영자 메일만 주인 허용)을 고치고 막을 사람을 넣는 차단 명단 표를 만듭니다. 운영자 메일은 그 표로 옮깁니다(저장소에는 메일을 적지 않음). 이 파일은 가입 스위치를 켜지 않고 차단 명단도 비워 둡니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 운영자 옮기기가 틀리면 사후 확인(운영자 1행·트리거에 메일 없음)에서 멈춥니다.
되돌리는 법: 스위치를 끄고 짝 rollback을 SQL Editor 새 창에서 실행하면 두 함수가 이전 정의로 돌아가고 역할 트리거는 운영자만 owner로 하는 모양(표의 운영자 1행을 읽음)으로 돌아갑니다. 표는 지우지 않고 남깁니다.
