무엇이 바뀌나: 자료실에서 자료가 어느 폴더에 있는지 적는 표에 "마지막으로 폴더를 옮긴 시각" 칸 하나를 더하고, 자료를 폴더에 넣거나 다른 폴더로 옮길 때마다 서버가 그 시각을 적는 자동 장치(트리거) 하나를 답니다. 화면이나 서버가 보낸 시각은 쓰지 않고 늘 서버 시계로 적습니다. 이 시각은 자료실을 열 때 "드라이브에서 옮긴 자료를 자료실 폴더도 따라 옮기기"가, 앱에서 방금(30분 안) 옮긴 자료를 옛 자리로 되돌리지 않게 하는 데만 씁니다. 권한·정책은 바꾸지 않고(새 칸은 아무도 직접 쓸 수 없음), 지금 있는 자료·폴더 자리는 바꾸지 않습니다(기존 줄은 적용 시각으로 채워져 적용 뒤 30분은 따라가기가 쉽니다).
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 적용 뒤 문제가 나도 자료 넣기·옮기기는 그대로 되고(장치는 시각 한 칸만 정함), 최악이면 드라이브 위치 따라가기만 늦어집니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 쿼리 창에서 실행하면 장치·칸·이번 기록 1행만 지웁니다. 자료가 있는 폴더 자리는 그대로이고, 서버는 칸이 없으면 따라가기만 쉬고 나머지는 지금처럼 동작합니다.
