무엇이 바뀌나: 텔레그램에서 나한테 온 요청에 내가 이미 답장했으면(1:1 방은 6시간 안 내 메시지도) 그 제안을 서버가 잊지 말기 '이미 함'으로 저절로 옮길 수 있게, 후보 줄에 요청 시각·번호·'저절로 옮김' 표시 칸 넷과 서버(service_role)만 쓰는 기능 3개를 더합니다. 표 권한·정책·기존 기능은 그대로이고 가족 제안은 건드리지 않으며 밖으로 아무것도 보내지 않습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 판정이 틀리면 답하지 않은 요청이 '이미 함'으로 갈 수 있으나 줄은 지워지지 않고 '이미 함' 보기의 [되돌리기]로 처리 전으로 돌릴 수 있습니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 기능 3개와 새 칸 넷·검사 둘·기록 1행을 걷어 냅니다. 저절로 옮긴 줄은 '이미 함' 그대로 남습니다(지우지 않음). 서버 함수 판(collector-feed)은 새 기능이 없으면 옛 길로 넣으므로 먼저 되돌리지 않아도 됩니다.
