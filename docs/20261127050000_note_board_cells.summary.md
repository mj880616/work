무엇이 바뀌나: 노트 보드의 글 상자 표에 칸 종류 두 가지(표·파일)와 새 칸 넷(표 글 cells, 자료실 자료 file_doc, 노트 첨부 file_note·file_drive)을 더합니다. 표는 줄 30·칸 12까지의 글자 표만, 파일 칸은 같은 작업공간의 자료나 노트 첨부 하나만 가리키도록 서버가 검사하고(좁히기 정책 하나), 파일 원본은 드라이브 그대로 둡니다. 기존 owner 정책·권한 범위는 그대로이고 주인만 읽고 고칩니다.
잘못되면: 사전 확인이나 적용 안 확인이 어긋나면 전체가 취소되어 아무것도 바뀌지 않습니다. 기존 상자·도형·글자·선·노트·자료는 한 줄도 바뀌지 않으므로, 적용 뒤 문제가 있어도 옛 보드는 그대로 보입니다. 자료나 노트를 지우면 그것을 가리키던 파일 칸도 함께 지워집니다.
되돌리는 법: (새 화면을 배포했다면 먼저 이전 판으로) 짝 rollback을 SQL Editor 새 창에서 실행합니다. 이미 표·파일 칸이 있으면 지우지 않고 멈추므로, 화면에서 먼저 지운 뒤 다시 실행합니다.
