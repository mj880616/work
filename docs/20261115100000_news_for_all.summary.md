무엇이 바뀌나: 뉴스 기사를 가입자 모두가 함께 읽는 공용 기사 표 한 벌과, 별표·폴더·숨김을 사람마다 따로 두는 표시 표를 새로 만들고 지금 기사·표시를 복사합니다. 텔레그램 방에 '뉴스방' 시각 칸을 더하고, 사용자만 누를 수 있는 [뉴스방으로] 함수와 수집기만 부르는 '뉴스방 기사 주소 넣기' 함수를 만듭니다. 옛 뉴스 표·정책·화면은 그대로입니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 복사 줄 수가 맞지 않거나 권한이 정해진 것과 다르면 사후 확인에서 전체 취소됩니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 새 표 둘·함수 넷·뉴스방 칸·기록이 지워지고 옛 뉴스 표는 손대지 않았으므로 그대로입니다.
