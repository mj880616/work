무엇이 바뀌나: 사진 정보(찍은 시각·위치) 되돌리기 기록이 받는 출처에 '원드라이브'·'구글 드라이브' 두 가지를 더합니다. 표·권한·기존 기록은 그대로이고, 출처 이름 목록만 늘어납니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 전에는 원드라이브·드라이브 사진을 고쳐도 되돌리기 기록이 남지 않아 '이번 화면에서만 되돌릴 수 있어요'로 알리고, 폰 사진 고치기는 그대로입니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 출처 목록을 원래대로('폰'만) 돌리고 기록 1행을 지웁니다. 원드라이브·드라이브 되돌리기 기록이 이미 있으면 멈춥니다.
