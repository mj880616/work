무엇이 바뀌나: Claude 연결에 쓰기 도구(노트·업데이트·업무일지 줄·담당조직 기록·사업 기록 쓰기, 지우기는 휴지통만)를 받는 함수와 쓰기 기록 표 2개, 설정의 쓰기 스위치(꺼짐)가 생기고, 운영자 작업공간 하나에만 쓰기 허용이 켜집니다. 쓰기 스위치가 꺼져 있어 지금은 아무것도 쓰지 않고, 기존 표·권한·자료·화면은 바뀌지 않습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 쓰기 함수가 잘못되면 Claude 쓰기만 거절되고 Web2·읽생기 사용과 Claude 읽기에는 영향이 없습니다.
되돌리는 법: 요청 전 함수 목록 되돌리기(docs/ops/mcp-claude-write-guard.rollback.sql)를 먼저 하고, 짝 rollback을 SQL Editor 새 창에서 실행해 새 함수·표·칸·허용 행·기록 1행을 지웁니다.
