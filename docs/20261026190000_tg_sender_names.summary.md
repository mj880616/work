무엇이 바뀌나: 텔레그램 소식의 보낸 사람 이름표를 담는 새 표 2개(사람 / 방·날짜별 A·B가 누구인지)와, 이름을 붙이고 합치고 지우는 작은 기능 4개가 생깁니다. 번호 원문 칸은 없고, 소식 원문과 기존 표·권한은 한 글자도 바뀌지 않으며 화면도 아직 안 바뀝니다. 로그인한 명진 본인만 읽고, 쓰기는 기능으로만 합니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 문제가 나도 새 표는 비어 있고 소식 요약과 원문은 그대로이며, 이름표가 비어 있으면 지금처럼 A·B로 나옵니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 새 기능 4개와 표 2개, 기록 1행만 걷어 냅니다. 붙여 둔 이름이 한 줄이라도 있으면 값을 잃지 않도록 멈춥니다.
