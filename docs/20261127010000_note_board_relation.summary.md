무엇이 바뀌나: 노트 보드의 연결선 표에 '선 종류' 칸 하나(지금 선 · 관계선)가 더해집니다. 관계선은 가지와 따로, 멀리 떨어진 칸끼리 잇는 점선입니다. 기존 선은 모두 '지금 선'으로 그대로 보이고, 새 표·권한 범위 넓히기는 없으며 주인만 읽고 고칩니다.
잘못되면: 사전 확인이나 적용 안 확인이 어긋나면 전체가 취소되어 아무것도 바뀌지 않습니다. 기존 선은 값이 바뀌지 않으므로, 적용 뒤 문제가 있어도 옛 보드는 그대로 보입니다.
되돌리는 법: (새 화면을 배포했다면 먼저 이전 판으로 되돌린 뒤) 짝 rollback을 SQL Editor 새 창에서 실행합니다. 이미 만든 관계선이 있으면 지우지 않고 멈추므로, 화면에서 먼저 지운 뒤 다시 실행합니다.
