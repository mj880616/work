무엇이 바뀌나: 노트 보드의 연결선 표에 '재료' 종류 하나와 칸 세 개(노트 · 자료실 자료 · 웹 주소)가 더해집니다. 생각지도 주제마다 기존 노트·자료실 자료·웹 주소를 이어 둘 수 있고, 새 표·권한 범위 넓히기는 없으며 주인만 읽고 고칩니다(남의 노트·자료는 잇지 못함).
잘못되면: 사전 확인이나 적용 안 확인이 어긋나면 전체가 취소되어 아무것도 바뀌지 않습니다. 기존 선·관계선은 값이 바뀌지 않으므로, 적용 뒤 문제가 있어도 옛 보드는 그대로 보입니다.
되돌리는 법: (새 화면을 배포했다면 먼저 이전 판으로 되돌린 뒤) 짝 rollback을 SQL Editor 새 창에서 실행합니다. 이미 이은 재료가 있으면 지우지 않고 멈추므로, 화면에서 먼저 잇기를 푼 뒤 다시 실행합니다.
