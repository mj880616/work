무엇이 바뀌나: 텔레그램 소식의 방마다 '고정한 시각'을 서버에 남기는 칸 하나와, 로그인한 본인이 방을 고정하거나 풀 때만 그 칸을 바꾸는 기능 1개가 생깁니다. 기존 운영자 전용 판정(정책·트리거)이 그대로 이 칸에도 걸리고, 표 권한·정책은 바뀌지 않습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 문제가 있으면 방 고정이 저장되지 않거나 맨 위 칸이 틀리게 보일 수 있으나 소식·요약·폴더·보관은 그대로입니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 기능 1개와 고정 칸을 걷어 냅니다. 고정 표시만 사라지고 방·소식 줄은 지우지 않습니다.
