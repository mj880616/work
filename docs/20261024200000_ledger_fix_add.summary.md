무엇이 바뀌나: 원장 '수정 요청' 저장 함수 하나가 "새 기록 넣기"(명진이 직접 [+ 기록하기]로 넣는 기록)도 받도록 넓어집니다. 기존 고치기·폐기·근거 추가는 그대로이고, 표·권한·정책은 바뀌지 않으며 로그인한 명진 본인만 쓸 수 있습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 문제가 생겨도 기존 원장 기록은 건드리지 않았고, 화면의 [+ 기록하기]만 저장에 실패합니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 함수 본문만 앞 단계 모양으로 되돌립니다. 그동안 직접 넣은 기록은 지우지 않고 남으며, 화면의 [+ 기록하기]만 저장을 거절합니다.
