무엇이 바뀌나: 폰 알림이 쓸 새 표 2개(알림 받을 폰 주소·보낸 알림 기록)와 내 프로필의 '알림 설정' 칸 하나가 생깁니다. 모두 자기 작업공간 주인만 보고, 폰 주소와 기록을 넣는 것은 서버 함수만 할 수 있습니다(화면은 폰 주소 자체를 읽지 못함). 서버 함수·앱·설정 화면은 아직 없어 겉으로 달라지는 것은 없습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 기존 표의 권한·정책·함수는 건드리지 않으므로 적용 뒤 문제가 생겨도 다른 메뉴는 그대로입니다.
