무엇이 바뀌나: 내 프로필 표의 "화면 선택 기억" 값 검사 하나만 바꿔, 일기 화면에서 마지막으로 고른 보기(diary_view: 달력 calendar·목록 list)를 서버에 기억할 수 있게 합니다. 새 열은 없고 다른 규칙(색·달력·노트 폴더·분할 비율·사업 보고 보기·숨김 날짜·메뉴 순서·홈 칸·사진 칸 수, 전체 4000바이트 상한)은 그대로입니다. 기존 자료·권한·정책은 바꾸지 않습니다. 일기 📌 고정·★ 별표는 DB 변경 없이 일기 행의 기존 metadata 칸에 저장합니다(노트 고정과 같은 방식).
