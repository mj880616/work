무엇이 바뀌나: 자료 표에 화면에 안 보이는 "칸별 기록" 칸 하나가 생깁니다(제목·분류·출처·날짜를 AI가 채웠는지 사용자가 넣었는지, 처음엔 모두 비어 있음). 파일에서 읽은 글자는 자료 표에 이미 있는 글자 칸을 다시 씁니다. 로그인한 명진 본인만 읽고 쓰는 기존 권한 그대로이고, 기존 자료 값·분류·권한은 바뀌지 않습니다.
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 적용 뒤 문제가 나도 지금 화면·서버는 새 칸을 쓰지 않으므로 자료 올리기·고치기는 그대로 동작합니다.
