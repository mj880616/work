무엇이 바뀌나: 노트 보드 위에서 노트와 노트를 잇는 연결선(곡선·직선, 실선·점선, 화살표 방향, 짧은 글자)을 담는 새 표 1개가 생깁니다. 노트 주인만 읽고 쓰며, 같은 작업공간의 노트끼리만 이을 수 있고, 기존 노트·카드 자리·표·권한은 한 줄도 바뀌지 않습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 새 표만 만들므로 노트·다른 화면에는 영향이 없고, 표가 없으면 보드는 카드만 보이고 선은 '준비 중'으로 알립니다.
되돌리는 법: (새 보드 화면을 배포했다면 먼저 이전 판으로 되돌린 뒤) 짝 rollback을 SQL Editor 새 창에서 실행해 새 표와 기록 1행만 지웁니다. 그어 둔 선은 함께 사라지고 노트와 카드 자리는 그대로입니다.
