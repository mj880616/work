무엇이 바뀌나: 사람마다 '내 주간 보고 양식'(항목 순서·이름·표 칸·칸마다 채울 기록)을 하나씩 저장하는 새 표 1개가 생깁니다. 자기 것만 읽고 고치고 지울 수 있고, 기존 표·권한·자료는 한 줄도 바뀌지 않으며 지금 화면은 아직 이 표를 쓰지 않습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 새 표만 생기므로 지금 화면·주간 보고에는 영향이 없습니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 새 표·함수·기록 1행만 지웁니다. 저장된 '내 양식'만 사라지고 올린 파일·주간 보고 기록은 그대로입니다.
