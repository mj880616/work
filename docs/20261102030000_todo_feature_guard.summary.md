무엇이 바뀌나: 텔레그램 방 설정과 텔레그램에서 온 챙길 것은 텔레그램이 허용된 작업공간(명진)에서만 보이고 저장됩니다. 다른 챙길 것(노트·업데이트·회의 출처, 레이더 상태·내 일 아님·피드백·규칙)은 모든 사용자가 그대로 씁니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면(명진 작업공간 밖에 텔레그램 후보·방 줄이 있으면 포함) 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 문제가 생기면 명진의 텔레그램 챙길 것 저장이 막히는 모양으로 드러납니다(허용 줄이 있으므로 정상이면 영향 없음).
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 트리거 2개·읽기 정책 2개·기록 1행만 걷어 냅니다. 챙길 것 자료는 지우지 않습니다.
