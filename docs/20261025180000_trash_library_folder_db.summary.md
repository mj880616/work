무엇이 바뀌나: 자료실에서 폴더를 지우면(폴더 지우기) 바로 지우지 않고 휴지통으로 옮겨 화면에서만 빠집니다. 그 폴더 안의 하위 폴더도 함께 휴지통에 들어가고, 폴더 안에 있던 자료는 그대로 폴더에 붙어 있습니다(자료실 목록에서만 함께 숨고, 자료 원본·Drive 파일·다른 화면의 자료 목록은 그대로입니다). 휴지통에서 되돌리면 하위 폴더와 자료까지 원래 구조로 돌아옵니다. 영구 삭제는 휴지통에서 직접 누를 때만 일어나며 지금의 폴더 지우기처럼 안의 폴더·자료를 한 단 위로 올립니다. 자동 비우기는 없습니다. 프로젝트·담당조직·사업 보고 휴지통은 그대로입니다.
