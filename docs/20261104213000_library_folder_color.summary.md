무엇이 바뀌나: 자료실 폴더마다 색 번호(1~8, 안 고르면 비움) 한 칸이 생기고, 로그인한 본인이 자기 폴더의 색만 바꾸는 기능 1개가 생깁니다. 표 권한·정책은 넓히지 않고, 색은 그 기능으로만 바뀝니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 문제가 있으면 색 고르기가 저장되지 않거나 색이 안 보일 수 있으나 폴더·순서는 그대로입니다. 적용 전에는 화면이 색 고르기 저장만 실패 알림을 냅니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 기능 1개와 색 칸을 걷어 냅니다. 고른 색만 사라지고 폴더는 지우지 않습니다.
