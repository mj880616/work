무엇이 바뀌나: 사람(작업공간)마다 한 달 AI 한도 칸(기본 3,000원, SQL로만 바꿈)과 이번 달 AI 사용 합계를 읽는 서버 함수가 생기고, 운영자(명진) 작업공간만 '한도 없음' 표시를 받습니다. 화면·Edge는 이 파일만으로는 바뀌지 않습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 운영자 표시가 다른 작업공간에 붙거나 권한이 넓어지면 사후 확인에서 멈춥니다.
되돌리는 법: Edge를 이전 커밋으로 먼저 되돌린 뒤 짝 rollback을 SQL Editor 새 창에서 실행하면 함수 셋·한도 표·운영자 표시가 사라지고 검사 모양이 원래대로 돌아갑니다.
