무엇이 바뀌나: 프로젝트 기록 표의 규칙 4개가 "모든 접속 역할"에 걸려 있던 것을 "로그인한 사용자"에게만 걸리도록 좁힙니다. 규칙의 내용(누가 어떤 기록을 보고 쓰는지)과 기록 자체는 하나도 바뀌지 않고, 지금도 비로그인 접속은 표 권한에서 막혀 있어 화면 동작은 그대로입니다.
잘못되면: 사전·사후 확인이나 규칙 내용 비교가 다르면 전체가 취소되어 아무것도 바뀌지 않습니다. 적용 뒤 프로젝트 기록이 안 보이거나 저장이 안 되면 바로 되돌리기를 실행합니다(로그인 사용자 권한은 그대로라 그럴 가능성은 낮습니다).
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 규칙 4개의 대상만 원래대로(모든 역할) 돌리고 기록 1행을 지웁니다. 규칙 내용은 그대로입니다.
