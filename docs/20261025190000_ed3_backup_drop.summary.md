무엇이 바뀌나: 노트를 새 편집기 형식으로 바꾸기 전에 만들어 둔 비공개 백업 표 하나(`app_ed3_text_backups`)와 그 표의 읽기 규칙 하나를 지웁니다(명진 결정 10/25: 백업은 버려도 됨). 화면·AI·서버 함수는 이 표를 쓰지 않아 지금 쓰는 화면에는 영향이 없고, 원래 노트·업데이트·일기·담당조직 기록·프로젝트 기록과 다른 표·권한은 하나도 바뀌지 않습니다.
잘못되면: 사전 확인(표와 기록이 있는지, 이 표를 쓰는 다른 표·뷰·함수가 없는지)이 하나라도 다르면 아무것도 지우지 않고 멈춥니다. 지운 뒤에 문제가 생기는 경우는 없는 것으로 확인했지만(참조 0곳), 지운 백업 글은 어떤 방법으로도 다시 볼 수 없습니다.
되돌리는 법: 짝 rollback(SQL Editor 새 창)은 빈 백업 표의 구조·권한만 다시 만들고 이번 기록 1행을 지웁니다. 지운 백업 원문은 돌아오지 않습니다(되돌릴 수 없음).
적용 경로: 승인형 DB workflow는 DROP TABLE을 차단하므로 SQL Editor 직접 실행(폰 경로 C)으로만 적용합니다.
