무엇이 바뀌나: 노트 폴더를 PIN으로 잠글 때 쓰는 새 표 1개와 함수 2개가 생깁니다. 이미 정해 둔 같은 PIN과 같은 틀린 횟수 셈을 쓰고, 내 작업공간 폴더만 서버가 받으며, 기존 표·권한·자료·PIN 잠금 함수는 한 줄도 바뀌지 않습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 새 표·함수만 생기므로 지금 화면과 노트·폴더에는 영향이 없습니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 새 표·함수·기록 1행만 지웁니다. 잠근 폴더 목록만 사라지고 노트·폴더·PIN은 그대로입니다.
