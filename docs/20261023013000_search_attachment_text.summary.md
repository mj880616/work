무엇이 바뀌나: 전체 검색이 자료실 파일(PDF·한글·워드·파워포인트·엑셀 등) 안 글자에서도 찾게 됩니다. 이미 읽어 둔 파일 글자만 찾고, 파일 안 글자에서 찾은 줄에는 '파일 안 글자에서 찾음'과 앞뒤 한 줄이 나옵니다. 검색 기능(DB 함수) 1개의 내용만 바뀌고, 일기 제외·명진 본인 자료만 찾는 권한은 그대로이며 표·자료·권한은 바뀌지 않습니다.
잘못되면: 사전 확인에서 멈추면 아무것도 바뀌지 않습니다. 적용 뒤 문제가 있으면 전체 검색칸 결과만 영향을 받고 다른 화면·자료에는 영향이 없습니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 검색 기능을 이전 판(파일 안 글자를 찾지 않음)으로 되돌리고 기록 1행만 지웁니다(자료·읽어 둔 글자 변경 없음).
