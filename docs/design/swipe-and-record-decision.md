# 줄 밀기 3칸 통일 · 기록 줄 높이 통일 — 결정 대기 (S70-61 시안)

시안: `docs/design/swipe-and-record-mockup.html`(혼자 열리는 파일, 내용은 모두 가짜 예시). 앱 코드는 아직 바꾸지 않았다.
요청: 2026-11-26 07:33 명진(UI-밀기메뉴통일 · UI-기록줄높이통일). 앞선 규칙(S70-60): 밀면 칸만 펼치고, 끝까지 밀어도 바로 실행하지 않는다.

## 고를 것 (2~3가지)

1. **시안 A 밀기 3칸**: 가안 `[주 동작][수정][숨기기·삭제]` / 나안 `[⋯][수정][숨기기·삭제]` 중 하나. (화면마다 다르게 고르는 것도 가능 — 시안 표의 줄 단위로 말하면 된다.)
2. **넓힐 화면**: [파일] 화면 파일 줄 · 조직 관리 기록 · 사업 관리 진행 기록에도 붙일지(시안은 셋 다 붙인 모습). 하루 기록·텔레그램은 따로 만든 밀기라 공용 밀기로 옮길지.
3. **시안 B 기록 줄**: 가안 한 줄(40px) / 나안 두 줄(54px) 중 하나 — 둘 다 누르면 그 자리에서 펼침, 첨부·메모 수는 줄 끝 작은 표시.

## 시안에서 정한 것(바꾸려면 말하면 됨)

- 칸 순서는 지금 규칙 그대로: 왼쪽 덜 위험 → 맨 오른쪽 숨기기·삭제. 오른쪽으로 밀기 [선택]은 그대로. 공유는 넣지 않음.
- 수정할 내용이 없는 줄(읽을 거리에서 온 저장한 글 등)은 [수정] 자리에 [⋯]. 홈·읽을 거리 기사 줄은 ⋯ 메뉴도 저장·숨기기뿐이라 2칸 그대로.
- 파일(자료실·[파일] 화면)은 [수정] 대신 **[이름 바꾸기]**(`docs/design/ui-words.md` 예외 '이름 바꾸기는 그대로').
- 잊지 말기의 수정은 곧 '수정해서 할 일로' 창이라 **[할 일로]** 한 칸으로 합침.
- 빠지는 칸은 ⋯ 메뉴에 남는다(예: 할 일 [기한] → ⋯ '기한 바꾸기', 노트 [고정] → ⋯ '고정').

## 조사 메모 (2026-11-26 저장소 main `427da4c` 기준)
