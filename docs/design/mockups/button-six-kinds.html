버튼 전수 통일
① 사이트 버튼을 6가지로만: 주 동작 · 작은 버튼 · 글자 버튼 · 칩 · 보기 바꾸기 · 아이콘. 모양(모서리)·크기·색·테두리는 종류마다 하나.
② 전수 조사: 모든 화면(홈·노트·파일·사진·자료실·일정·할 일·News·담당조직·사업 보고·메뉴·작은 창·설정) × 폰·폴드 펼침·PC에서 버튼을 하나씩 찾아 '지금 모양 → 6가지 중 무엇' 표로. 화면별로 새로 정한 높이·둥글기·색은 모두 지움.
③ 한 번에 고침(작은 화면별 PR로 나눠도 같은 규칙 하나).
④ 다시 안 생기게: 6가지에 안 드는 버튼이나 화면별 버튼 크기·색을 새로 쓰면 시험이 실패.

기존 결정(작고 낮게, 주 동작 하나만 채움)은 그대로 — 이번엔 '빠진 곳 없이 전부'와 '종류 6개 고정'이 새것.
