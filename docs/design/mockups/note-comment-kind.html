시안: 노트 댓글 종류 고르기 자리

노트 본문과 댓글은 모두 예시예요. 폰 기준으로 그렸어요. PC는 같은 모양에 폭만 넓어요.

지금 — [생각 ▾]은 왼쪽 끝, [저장]은 오른쪽 끝(넓은 화면에서 멀리 떨어짐)
댓글 1
질문이 숫자 출처 다시 확인11.9.
댓글 쓰기
생각 ▾저장
A안(추천) — 제목 줄 오른쪽에 [생각 | 질문], 아래엔 [저장]만
댓글 1생각질문
질문이 숫자 출처 다시 확인11.9.
댓글 쓰기
저장
A안 — 본문에서 문장을 드래그했을 때
예시 본문입니다. 인력 35명을 직종별로 어떻게 나눌지가 핵심 쟁점이다. 나머지 예시 문장.
댓글 1생각질문인용
“인력 35명을 직종별로 어떻게 나눌지가 핵심 쟁점이다.” ✕
댓글 쓰기
저장
B안 — [생각 ▾]을 [저장] 바로 왼쪽으로
댓글 1
질문이 숫자 출처 다시 확인11.9.
댓글 쓰기
생각 ▾저장
A안: 종류는 제목 줄 오른쪽 작은 두 칸 [생각|질문]. 문장을 드래그하면 '인용' 칸이 하나 더 생기고 저절로 골라져요(✕로 문장을 빼면 인용 칸도 사라짐). 쓰기 칸 아래엔 [저장]만.
B안: 지금 고르기 상자 그대로, 자리만 [저장] 옆으로. 인용도 지금처럼 목록 안에.
그대로: 댓글 줄 모양(꼬리표·인용 문장·날짜·✕), Ctrl+Enter 저장, [되돌리기].
