바뀌는 것 (화면)
① 메뉴 이름 Now → News. 안의 탭은 [전체][사회운동][언론][보관] — '뉴스' 탭은 '언론'으로(메뉴와 겹치지 않게). 문장 찾기는 위 찾기 칸으로 합침.
② 목록은 제목 중심: 날짜 묶음 → 흰 상자 안 줄. 줄 왼쪽 매체 색 띠 + 매체 이름 같은 색 + 분류 꼬리표 색(노동·정치·국제·성명). 안 읽은 글 굵게, 읽은 글 흐리게.
③ 누르면 요약 → 시사점 → 원문 전체 순서로 한 화면. 요약·시사점은 수집 때 미리 만들어 둠 → 누르자마자 보임(지금은 누를 때 만들어 30초~2분).
④ 원문 전체는 글자 크기 3단계, 사진 포함. 못 읽은 글만 '원래 사이트 ↗'.
