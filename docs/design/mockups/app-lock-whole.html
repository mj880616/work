  • 스위치는 맨 위 한 줄. 같은 PIN, 같은 '다시 잠그기'. 켜기·끄기는 PIN 확인 뒤(처음이면 PIN 정하기).
  • 켜 두면 앱(웹·폰 앱)을 열 때, 그리고 앱을 떠났다가 다시 잠그기 시간이 지나 돌아왔을 때 어떤 화면보다 먼저 ②. 풀기 전에는 화면·자료를 불러오지 않아요.
  • 맞는 PIN이면 원래 가려던 화면으로. 한 번 풀면 하루 기록 같은 기능 잠금도 함께 풀려요(PIN 하나). 기능 잠금은 그 뒤 따로 다시 잠겨요.
  • 앱 전체가 잠긴 동안은 나갈 화면이 없어 왼쪽 위 [✕] 대신 아래 [로그아웃]. '잊음'은 지금처럼 구글로 다시 로그인한 뒤 새 PIN.
