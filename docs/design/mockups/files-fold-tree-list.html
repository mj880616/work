지금: 폴드를 펼쳐도 폰처럼 나무만 화면 전체에 깔리고 오른쪽 절반이 비어 있음. 폴더를 누르면 나무가 사라지고 목록만.

개선
① 펼치면 왼쪽 나무(좁게) | 오른쪽 목록 — 폴더를 눌러도 나무가 그대로 있어 옆 폴더로 바로 이동.
② 목록은 핀치로 목록 ⇄ 4칸 격자(폴드는 칸 수 하나 더).
③ 위 줄에 [두 칸 보기] — 누르면 좌우 두 목록(나무는 칸 위 ▾로 내려옴), 꾹 눌러 끌어 옆 칸으로.
④ 저장소마다 이름 줄 옅은 배경 + 접기 — 안 쓰는 저장소는 한 줄.
⑤ 나무 폭은 경계선을 끌어 조절, 서버에 기억.
⑥ 폴드 펼침 판단은 화면 폭 숫자만 보지 말고 폰 앱·삼성 인터넷 모두에서 '펼친 폴드'로 확실히 잡히게(지금 폰 모양으로 나오는 원인부터 확인).

같은 종류: 자료실·노트 폴더 화면도 폴드 펼침에서 같은 '나무 | 목록'.
