① 펼침은 폴더 아이콘으로: 꺾쇠 대신 하위 폴더가 있으면 펼친 폴더 모양/닫힌 폴더 모양. 아이콘을 누르면 펼치기, 이름을 누르면 들어가기 — 작은 세모 누를 일 없음. 하위 없는 폴더는 늘 닫힌 모양(처음부터 정확히).
② 저장소마다 상자: 원드라이브·구글·이 폰이 상자로 나뉘어 구분감, 상자 머리를 누르면 접기.
③ 휴지통은 상자 맨 아래 회색 줄.
④ 폴더 색을 정한 폴더는 아이콘 색으로(노트 업무 메모·가족처럼).
⑤ 사진의 꺼 둔 폴더는 흐리게 + '끔', 켜기·끄기는 ⋯ 안으로(스위치 줄 정리).
⑥ 탭은 폰 아래 가운데(01:25 규칙), [+]는 그 위.
⑦ 점(●)은 자료실에서만 — 다른 화면엔 없음.
