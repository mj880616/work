시안: 조직 보고 — 묶음을 화면에서 만들고 조직을 끌어 넣기

폰 412 폭. 조직·묶음 이름은 예시(다른 담당자 화면을 가정). 주황 테두리가 새로 생기는 것.

요청함 방 추천 — 명진 확정 아님
· [+ 묶음] → 이름 한 칸 → 빈 묶음이 생김. 조직 줄을 끌어 묶음에 넣고, 같은 묶음 안에서 끌면 순서가 바뀜. 묶음 머리를 끌면 묶음 순서.
· 묶음 ⋯: 이름 바꾸기 · 묶음 풀기(조직은 지우지 않고 '그 외'로).
· 정한 묶음·순서는 지금과 같은 내 프로필 설정(org_order)에 저장 — 주간보고 조직 순서·고르기 창 묶음이 그대로 따라옴. 내 프로필의 글자 칸은 없앰.
· 명진 화면: 지금 묶음(철도·지하철·민자철도·민간도시철도…)이 그대로 보이고, 끌기 손잡이만 생김.
· 폰은 손잡이를 꾹 눌러 끌기, PC는 줄을 끌기. 키보드는 Alt+↑↓(자료실 폴더 끌기와 같은 규칙).
