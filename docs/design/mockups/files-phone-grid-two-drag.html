① 핀치로 크게 보기
두 손가락을 벌리면 목록 → 3칸 격자 → 2칸 격자, 오므리면 반대로. 사진은 작은 그림, 폴더는 큰 폴더 아이콘. 마지막 보기는 서버에 기억(폰·폴드 따로).

② 폰 두 칸
폰은 폭이 좁아 위·아래로 나눔. 칸마다 출처 고르기(▾)는 PC와 같음. 누른 칸이 지금 칸(옅은 보라).

③ 꾹 눌러 끌기
꾹 누르면 집어 들기 → 손가락 따라 움직임 → 폴더(같은 칸·다른 칸·나무) 위에서 보라 점선 → 놓으면 [복사][옮기기]. 꾹 누르고 움직이지 않고 떼면 지금처럼 고르기·메뉴. 여러 개 골라 둔 상태면 고른 것 모두 함께.
