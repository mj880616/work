개선
① 폴드 펼침·PC는 왼쪽 목록 | 오른쪽 상세. 줄을 누르면 오른쪽에 바로 열리고, 고르면 보라색 줄.
② 오른쪽에서 바로 고침 — 제목·기한(빠른 단추 + 달력)·연결·메모·첨부, 바꾸면 바로 저장(따로 [저장] 없음).
③ 오른쪽 위 ✕ 또는 뒤로 키 = 상세 닫기(목록만).
④ 아무것도 안 골랐을 때 오른쪽은 비워 두지 않고 '오늘 할 일' 요약.
⑤ 폰(접은 화면)은 지금처럼 누르면 수정 창.

같은 종류: 폴드 펼침에서 노트·업데이트·정리함도 같은 '목록 | 상세'인지 확인해 맞춤.
