⋯(지부 줄) = 현황 표 모두 넣기 · 줄 추가 · 현황 표 보기. 제안이 3개 넘으면 '제안 2개 더 ▾'.

  • 지부마다: 이름 줄(이름 · n줄 · ⋯) → 이미 넣은 줄(보통 글자) → 그 아래 흐린 제안 줄. 주간 정리 위쪽 칸과 같은 '제안 줄' 부품 — 줄 끝은 ⋯ 하나, 누르면 [넣기][이미 있음][고쳐서 넣기][빼기](명진 19:22). 같은 부품이라 WEEKLY-칸합치기·이미있음의 제안 줄도 같은 모양. 큰 기울임 글·큰 버튼 없앰.
  • '현황 표'는 따로 펼치는 덩어리가 아니라 제안 줄의 출처 꼬리표('현황 표'·'AI 제안')로. 이미 넣은 줄과 같은(부호만 다른 것 포함) 현황 표 줄은 제안에 안 나옴 — 같은 글 두 번 없음.
