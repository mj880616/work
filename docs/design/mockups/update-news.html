시안 1차 — 업데이트 기록(운영자만) · 업데이트 소식(이용자) (명진 11/15 12:56~12:59)

지금의 '업데이트 기록'(개발할 때마다 쌓이는 전체 기록)은 운영자(명진)만 본다 — 서버가 운영자 계정에서만 연다. 이용자에게는 운영자가 고르거나 직접 써서 보낸 것만 '업데이트 소식'으로 보인다. 보이는 범위는 운영자가 정한 시작 날짜 이후 보낸 것 전부. 기록 파일은 공개 배포물에서 뺀다. 글은 모두 가상 예시.

정할 것(요청함 방 추천 — 명진 확정 아님)
  1. 보낼 때 '폰에서 볼 것' 줄은 기본으로 빼기(추천 — 개발 확인용이라서) / 같이 보내기
  2. 여러 기록을 묶어 한 소식으로 보내기 가능(추천 — 하루치 고친 것을 한 번에)
  3. 새 소식이 오면 메뉴 '업데이트 소식' 옆 작은 점만(추천) / 새 판을 열 때 창으로 한 번 띄우기도
