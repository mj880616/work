4. [파일] 두 칸에서 칸마다 출처 고르기

[파일] 두 칸 보기에서 칸 머리마다 출처(이 폰·원드라이브·구글 드라이브·내 PC)를 따로 고르게 한다. 고르는 모양과, 고른 것을 서버에 기억할지 정하면 된다.

지금 어디까지 됐나 (조사한 사실)
  • 두 칸 보기는 이미 있음(PC·폴드 좌우, 폰은 위·아래 — S49-30·S51-20). 켬/끔만 서버 기억(view_prefs.files_two: 기기 종류 app·phone·pc × 폭 fold·wide·narrow, 참·거짓).
  • 출처 넷은 이미 있음: 원드라이브·구글 드라이브(서버 색인), 이 폰(폰 앱에서만), 내 PC(바구니 PC 앱 문이 켜졌을 때만).
  • 지금은 두 칸을 켜면 오른쪽(아래) 칸이 "왼쪽과 다른 켜진 클라우드 맨 위"에서 시작하고(otherStart), 칸마다 출처를 고르는 단추는 없음. 칸 위치는 기억하지 않음.
  • 11/05 시안(text-only-items-1105.html "FILES-칸출처고르기")에 칸 머리 "원드라이브 ▾" 모양이 이미 한 번 그려졌음 — 아래 A안이 그것.
  • DB: 고른 출처를 기억하려면 view_prefs에 새 칸(예: files_panes)을 허용하는 제약 확장이 필요(files_two는 참·거짓만 받아서 넣을 수 없음). 기억하지 않으면 DB 변경 없음. 설계 메모: docs/design/files-pane-source.md.

명진이 고를 것

  1. 칸 머리 모양 — A: "원드라이브 ▾" 이름을 누르면 목록 / B: 출처 아이콘 4개가 칸 머리에 늘 보임. 추천 A(촘촘, 폰 폭에서도 한 줄)
  2. 고른 출처 기억 — A: 서버에 기억(기기 종류마다, DB 한 번 — 시험 적용 먼저) / B: 기억 안 함(켤 때마다 지금처럼 시작). 추천 A

답 예: "1 A, 2 A"
