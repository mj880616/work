1. 블로그형 편집기 하나로

일기·업데이트·노트·공유 페이지·기록 [크게] 쓰기 화면은 이미 같은 편집기 하나를 쓴다. 남은 것은 도구 줄 위치와 여러 장 사진 넣는 방식 두 가지다.

지금 어디까지 됐나 (조사한 사실)
  • 같은 편집기(ed-editor.js)를 쓰는 곳: 공유 페이지, 노트, 일기, 업데이트 쓰기·큰 창, 담당조직·사업영역 기록 [크게] — 10/25에 옛 큰 창(md-editor·write-window)은 삭제됨.
  • 도구 줄은 지금 편집기 위에 붙어 있음(스크롤해도 위에 고정). 폰에서는 묶음 버튼(글자·문단·넣기·기호 ▾) 한 줄.
  • 사진 나란히는 코드에 이미 있음: 사진을 다른 사진 옆에 끌어 놓으면 한 줄(최대 4장), 여러 장을 한 번에 고르면 [나란히]/[한 장씩]을 묻는다. 원장 ED-사진나란히 행은 아직 '대기'로 남아 있어 맞춰야 함.
  • 남은 원장 행: ED-서식줄펼침기억(펼침 상태 서버 기억), ED-파일카드(본문 안 파일 카드·끌어 놓기).
  • DB 변경 없음(나란히 사진은 이미 저장 형식에 있음).

명진이 고를 것

  1. 도구 줄 위치 — A: 지금처럼 위에 고정 / B: 글을 고를 때만 그 위에 작은 줄이 뜨고, 아래에는 [사진]·[넣기]만. 추천 A(폰에서 손이 덜 감, 이미 익숙)
  2. 여러 장 사진 넣기 — A: 지금처럼 [나란히]/[한 장씩] 묻기 / B: 묻지 않고 바로 나란히, 풀고 싶으면 [따로 놓기]. 추천 B(한 번 덜 누름)

답 예: "1 A, 2 B" 또는 "추천대로"
