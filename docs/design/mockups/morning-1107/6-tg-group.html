6. 텔레그램 소식 같은 날·같은 방 묶기

날짜 아래 방 한 줄 목록·방 상세(하루 요약·‹ 날짜 ›)·폴더·보관·날 삭제는 이미 운영에 들어가 있다. 남은 것은 '모든 방' 켜기(뺄 방 정하기)와 [텔레그램에서 열기]가 실제로 열리게 하는 방 정보다.

지금 어디까지 됐나 (조사한 사실)
  • 10/27 명진 결정 7개 모두 추천대로 → DB #1293 적용, 서버 #1295(Edge 배포), 화면 #1297(방·날 한 줄 목록·방 상세)·#1298(폴더 칸 줄·밀기·보관함·날 삭제) merge.
  • 남은 것 ①: 지금은 허용한 업무방만 읽음(TG_FEED_ROOMS). '모든 방'(*)으로 켜려면 뺄 방 목록이 먼저 필요 — 명진 답 대기.
  • 남은 것 ②: Apps Script 3단계(방 정보·첫 메시지 번호를 본문에 더함) 붙여 넣기와 수집기 쪽 방 정보 파일(저장소 밖) — 명진 직접. 이게 없으면 [텔레그램에서 열기]가 방을 못 찾는 방이 있음.
  • 남은 것 ③: 갤럭시 폴드 두 화면 실기기 확인(밀기·버튼 폭·되돌리기 줄·열기 링크).
  • 그 뒤 더해진 것: 보낸 사람 이름(TG-발언자이름), 나한테 온 요청 노란 띠·안 본 것(TG-요청강조·안본것).

명진이 고를 것

  1. 뺄 방 정하는 곳 — A: 지금 설계대로 스크립트 속성에 직접 적기(화면·DB 변경 없음) / B: Web2 소식 ⋯ [AI에 보내지 않을 방] 창에서 체크(서버 저장 — DB·Edge·스크립트 변경 필요). 추천 A(지금 바로 가능, 새 표·새 서버 길이 필요 없음)
  2. [텔레그램에서 열기] 위치 — A: 방 상세 머리줄·소식 줄에만(지금) / B: 목록 줄마다 작은 ↗도. 추천 A(목록이 촘촘하게 유지)

답 예: "1 A, 2 A" — A를 고르면 CC가 붙여 넣을 칸·순서를 한 단계씩 따로 드림
