② 이름을 누르면 그 자리에서 바로 고침(보라 테두리), [완료] 또는 엔터로 저장.
③ 지우기는 빨강 없이, 누르면 "○○ 분류를 지울까요? 자료는 지워지지 않아요" 한 번 묻기.
④ 긴 안내문 삭제. '새 분류 이름' 칸은 맨 위로 — 아래 바에 가려지지 않게.
⑤ 왼쪽 ⠿ 손잡이를 끌어 순서 바꾸기(자료실 위 분류 칩 순서와 같음).
⑥ '기타'는 맨 아래 🔒 고정 표시만.
⑦ 창이 아래 바를 가리지도, 아래 바에 가려지지도 않게(폰·폴드 공통).

같은 종류: 노트 폴더·태그 고치기, 사진 앨범 고치기, 담당조직 묶음 고치기 등 '목록 고치기' 창은 모두 이 모양으로.
