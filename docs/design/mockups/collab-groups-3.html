시안 3차 — 함께쓰기: 묶음 만들기 · 초대 링크 · 같은 이름 들어오기 요청

2차에서 바뀐 점: 운영자가 미리 만든 조직 목록·찾기·명함 승인은 없앴어요(11/15 핫픽스). 노조명·부서명은 각자 프로필에 직접 입력한 글 그대로 쓰고, 묶이는 길은 ① 초대 링크와 ② 노조명+부서명이 똑같을 때 들어오기 요청 두 가지뿐이에요. 묶음은 부서 묶음(노조명+부서명)과 노조 묶음(노조명) 두 단계예요. 예시 이름은 모두 지어낸 것이에요. 자리: 프로필 › 내 묶음.

  • 새는 길 막기: 같은 이름 묶음이 있든 없든 만든 사람에게는 같은 한 줄만 보여요(③). 하루에 3번까지만 만들 수 있고, 요청한 사람은 요청이 어떻게 됐는지 볼 수 없어요(거절해도 알리지 않음).
  • 관리자가 보는 것: 멤버 이름·직책, 들어오기 요청뿐이에요. 다른 멤버의 개인 기록은 볼 수 없고, 본인이 켠 공유만 보여요. 운영자도 묶음 이름·내용을 보지 않아요(개수만 봄).
  • 공유 켜기(⑦)는 다음 단계 화면이지만 08:29 결정(담당조직은 조직 관리 기록까지 · 보기만/쓰기까지 고르기)을 같이 그려 뒀어요.
