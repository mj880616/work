· '받는 폴더 나누기'(잡동사니 하나만 봄)와 같은 부품을 자료실 전체(또는 고른 폴더 안)로 넓힌 것. 같은 제안 창·고르기 창·[되돌리기]를 그대로 씀.
· 묶음 찾기: ① 이름에 같은 낱말(합의서·회의록·명단 등)이 있거나 분류·사업이 같은 자료인데 폴더가 둘 이상으로 갈라진 것 ② 그걸로 못 묶은 것만 AI가 제목·본문 첫머리를 보고 묶음. 묶음마다 가장 많이 든 폴더를 옮길 곳으로, 마땅치 않으면 새 폴더 제안.
· AI는 제안까지만 — 명진이 [옮기기]를 눌러야 옮겨요. 묶음은 [옮기기]/[그대로], 자료는 체크로 하나씩 뺄 수 있고, 옮길 폴더도 ▾로 바꿔요.
· 저절로 돌지 않아요. 명진이 메뉴를 누를 때만. [되돌리기] 한 번이면 이번에 옮긴 것 전부 원래 폴더로, 새로 만든 빈 폴더도 지움.
· 파일 원본(Drive)은 그대로 두고 자료실 폴더만 바뀌어요.
