# 노트 보드 → 브레인스토밍·마인드맵 (S69-82)

2026-11-24 23:51 명진 결정: "그냥 하나하나 고치지 말고 전체를 브레인 스토밍 마인드맵 하게. 제대로 개선".
노트 › 보드의 글 상자를 부분 수선하지 않고 Miro·FigJam·Whimsical·XMind 같은 가벼운 생각 지도 도구로 다시 설계한다.
같은 보드 데이터·저장 경로(서버 표 `app_note_board_texts`·`app_note_board_links`, 노트 카드 자리 `metadata.boards`)를 이어 쓰고, 옛 보드는 새 모양으로 읽힌다.
옛 글 상자 그리기 코드는 지우고 그 자리를 새 상자 그리기로 바꾼다(옆에 새 것을 따로 두지 않음).

## 4. 데이터 모양 (migration `20261125000000_note_board_mindmap`)

기존 표 `app_note_board_texts`(보드에만 있는 글 상자, owner RLS)에 칸만 더한다. 새 표·함수·트리거·정책 바꾸기 없음. 권한은 새 칸 넣기·고치기만 authenticated에 더한다.

| 칸 | 뜻 | 값 |
| --- | --- | --- |
| `parent_id` | 위 상자(비면 혼자 선 상자 = 뿌리) | 같은 작업공간·같은 보드 상자만((id, 작업공간, 보드) 세 칸 외래 키), 위 상자를 지우면 아래도 지워짐(cascade), 자기 자신 불가 |
| `ord` | 형제 순서 | 0~1000000(1024 간격, 틈이 없으면 형제를 다시 번호) |
| `side` | 뿌리 가지의 쪽 | -1 왼쪽 · 1 오른쪽 · 비면 가벼운 쪽 |
| `kind` | 종류 | `topic`(주제 상자) · `sticky`(메모지 — ② PR에서 만들기 단추) |
| `color` | 색 | 노트 색 0~7 · 비면 기본 |
| `shape` | 모양 | `round` · `rect` · `pill` · `plain` |
| `font` | 글자 크기 | 1~4 |
| `w` | 손으로 정한 폭 | 60~600 · 비면 글 길이만큼(③ PR에서 손잡이) |
| `collapsed` | 가지 접힘 | 참·거짓 |

- 가지 자리는 저장하지 않는다. 뿌리만 자기 자리(`x`·`y`)를 쓰고 나머지는 화면이 그릴 때마다 자동 배치한다(`app/note-board-mindmap-model.mjs` `layoutMindmap`). 가지를 만들 때의 자리는 `x`·`y`에 함께 넣어 둔다(되돌리기 때 그 근처에 남도록).
- 연결선(`app_note_board_links`)·노트 카드 자리는 바꾸지 않는다. 가지 선은 `parent_id`로 그리고, 손으로 이은 선은 지금처럼 연결선 표.
- 고리(서로가 서로의 위)는 서버가 막지 않는다(트리거를 두지 않음). 화면은 끌어 붙일 때 자기·자기 아래로 붙이지 않고, 읽을 때 고리를 끊어 뿌리로 본다.

## 5. 옛 데이터 읽기

- 적용 뒤: 옛 글 상자는 새 칸이 기본값이라 모두 **혼자 선 주제 상자**(둥근·보통 크기·기본 색)로 읽힌다. 자리·글·선 그대로.
- 적용 전(새 화면이 먼저 배포된 경우): 화면은 새 칸으로 읽다가 칸이 없다는 답이면 옛 칸으로 다시 읽는다. 혼자 선 상자 만들기·고치기·옮기기·잇기·지우기는 되고, 가지·꾸미기는 '준비 중' 알림만 낸다(막대의 꾸미기 단추는 숨김).
- 되돌리기(rollback): 새 칸만 지운다. 가지였던 상자는 만들 때 자리에 혼자 선 상자로 남는다.
