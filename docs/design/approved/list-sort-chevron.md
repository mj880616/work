# 목록 머리 정렬 표시 — 승인 시안 A (LIST-정렬꺾쇠)

2026-11-28 사용자 결정. 머리 줄 있는 모든 목록(노트 [목록]·[폴더] 오른쪽 목록, [파일], 브리핑 룸 자료 목록 등)이 같은 머리 칸 부품을 쓴다
(정렬 머리 `app/head-sort.mjs` `headCellHtml`, 칸 너비 금 `app/col-resize.js` `gripHtml`, 모양 `app/ui-standard.css` 'LIST-정렬꺾쇠').

## 사용자 요청 원문

- (노트 [목록] PC 캡처와 함께) "이거 여전히 좀.. 아래 세모가 좀 삐뚤어져 있고 조악해 이거 개선하자. 시안 먼저. 노트 목록임"
- 시안 A·B·C 중 "a 좋다"

## 고치기 전 모양

- 머리 줄 '제목 | 폴더 | 태그 | 수정일 ▼ | 첨부 👁'.
- 정렬 표시가 굵은 검은 ▼ 글자라 글꼴마다 굵기·기준선이 달라 칸 이름보다 아래로 처져 보였다.
- 칸 사이 폭 조절 막대(|)가 늘 보여 머리 줄이 지저분했다.

## 시안 A (승인)

1. 정렬 표시
   - 정렬 중인 칸 이름 오른쪽에 작은 선 꺾쇠 그림(SVG, 선 굵기 1.4, 약 10px, 글자색과 같은 색). 내림차순 ⌄, 오름차순 ⌃.
   - 꺾쇠는 칸 이름 글자 높이의 세로 가운데. 칸 이름과 꺾쇠 사이는 4px 안팎(`--ds-sort-mark-gap`), 크기 `--ds-sort-mark-size`(`app/theme-tokens.css`).
   - 정렬 중인 칸 이름만 진한 글자(굵게), 나머지 칸 이름은 흐린 글자.
   - ▼▲ 글자 기호는 머리 칸에 쓰지 않는다.
2. 칸 사이 폭 조절 막대
   - 마우스 화면에서는 평소에 안 보인다. 머리 줄에 마우스를 올렸을 때, 키보드 초점이 머리 줄에 있을 때, 끄는 중일 때만 보인다.
   - 숨김은 보이기 정도(opacity)만 바꾼다(`display:none` 아님) — 자리·폭·잡는 범위·두 번 눌러 맞추기·키보드(←/→·Home) 조절은 그대로.
   - 터치 화면(마우스 올림이 없는 화면)은 지금처럼 늘 보인다.
