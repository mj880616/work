# 휴지통 줄 그림 단추 — 승인 시안 '마' (TRASH-줄그림단추)

2026-11-28 사용자 결정. 노트 휴지통과 [파일] 구글 드라이브 휴지통이 같은 줄·같은 동작을 쓴다(공용 `app/trash-row.js`·`app/trash-row.css`).

## 사용자 요청 원문

- "여전히 못생김. 개선 시안 제출 / 특히 … 너무 뚱뚱 빽빽"
- "너무 되돌리기랑 …가 자주 반복"
- "복원이랑 영구삭제 두 개인데 … 안에 다 넣던가 둘다 이모티콘으로 처리하던가"
- "마로 하고 꾹 눌러 선택 가능 선택시 일괄 복원 영구 삭제 가능"

## 시안 '마'

- 휴지통 한 줄 = [제목(한 줄 줄임표)] [지운 날짜(작은 회색)] [되살리기 그림 단추 ↶] [영구 삭제 그림 단추(휴지통·X 모양)].
- 글자 단추 [되살리기]와 네모 테두리 [⋯] 칸은 없앤다.
- 그림 단추는 테두리·배경 없는 작은 회색 그림(약 17px). 누르는 칸은 손가락 크기(공용 글자 버튼 `row-act`의 44px)를 유지하고, `aria-label`("되살리기: 제목"·"영구 삭제: 제목")이 있다. 영구 삭제는 지금처럼 확인을 거친다.
- 줄을 꾹 누르면(PC는 기존 표준의 Ctrl+클릭·Shift+클릭) 고르기 모드: 줄 앞에 동그라미 체크, 아래에 막대 "N개 선택 · 되살리기 · 영구 삭제", 위쪽에 [전체 선택]·[취소].
- 고르기 모드의 줄은 그림 단추를 숨기지 않고 고르기 줄 모양으로 다시 그린다(화면 구조로 뺀다, display:none 땜질 아님).
- [휴지통 비우기]는 유지(머리줄 오른쪽 작은 빨간 글자).

## 용어 맞춤 (사용자 확인 필요)

사용자 요청의 '모두 고르기'·'N개 고름'은 용어 기준표(`ui-words.md` 고르기 → 선택, W3 [전체 선택])에 맞춰 [전체 선택]·'N개 선택'으로 적었다.

## 화면 범위

- 노트 휴지통(`app/note-trash.js`): 그림 단추·고르기·일괄 되살리기·일괄 영구 삭제(한 번 확인).
- [파일] 구글 드라이브 휴지통(`app/files-trash.js`): 그림 단추 ↶·고르기·일괄 되살리기. 서버(`cloud-files`)에 영구 삭제 길이 없어 영구 삭제 그림 단추·막대 칸은 두지 않는다.
- 같은 모양으로 맞출 후보(이번 범위 밖): 사업 관리 보관 창 휴지통 탭(`project-system-v3.js`, 2줄 줄·종류 말이 달라 따로).
