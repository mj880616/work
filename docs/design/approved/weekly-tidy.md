## 시안 '나'

1. 본문(폰·PC 공통) 글자는 네 단계뿐: 큰 제목(1.~5.) `--ds-text-head`, 소제목(1) 요약 등) `--ds-text-row` 굵게·흐린 색, 줄 글자 `--ds-text-row`, 날짜·보조 글자 `--ds-text-meta`. 칸 이름(3. 사업장 이름·4. 조직 이름·사업영역 › 세부 과제)은 줄 글자 크기·진한 색 보통 굵기로 3·4번이 같은 모양.
2. 줄 입력: 입력칸 + [취소](글자 단추) + 작은 [저장](`--ds-compact-height`)이 한 줄. 화면 안 모든 [취소][저장] 짝이 같은 크기. (UI-저장자리 규칙대로 [취소] 왼쪽·[저장] 맨 오른쪽.)
3. 확정 칸: 머리 '이번 주 확정 · 시각'(확정 전이면 '이번 주 확정 전') + ⋯ → 짧은 탭 [파일][비울 줄 N][AI 초안][환류][기억](할 일이 남은 탭은 숫자, 공용 ⑤ 보기 바꾸기 모양) → 한 번에 한 탭 내용(한 문장 요약 + 세부 접기) → 맨 아래 [확정하고 한글 파일 받기].
   - 고른 탭은 기기에 저장하지 않는다(화면 메모리만). 열 때는 할 일이 남은 첫 탭, 없으면 [파일]. [학습 시험]·[초안 다시 쓰기]를 누르면 [AI 초안] 탭.
   - 탭 내용: 파일 = 확정 파일 두 줄·양식 자리 고르기·겹친 칸·본문과 일정표 다름·줄을 찾지 못한 기록·확인 한 줄들, 비울 줄 = 더는 투쟁 중이 아닌 사업장 줄 '삭제할까요?', AI 초안 = 초안 소식·학습 시험, 환류 = 환류 보고(답할 규칙 후보 수), 기억 = 다음 주에도 쓸 일정.
4. PC(1100px부터): 왼쪽 본문, 오른쪽 확정 칸(내려도 위에 붙음). 폰·좁은 화면: 한 칸(본문 아래 확정 칸).
5. 홈 '오늘 한 일' 줄: [수정][삭제] 글자 단추 → 줄 끝 ⋯ 하나(안에 수정·삭제). PC도 같은 자리, 마우스를 올릴 때만 보이던 방식 없이 늘 보인다. ⋯ 모양(세로 점)은 공용 줄 ⋯(`row-more`)를 따른다(PR #3277이 공용으로 세로 점으로 바꿈).

## 시안과 다른 점(판정 칸에도 적음)

- 3. 투쟁 사업장 현황은 양식에 '1) …' 소제목이 없다(제목이 '3. 투쟁 사업' + '2) 투쟁 사업장 현황'을 합친 한 줄). 중복 제목을 만들지 않으려고 3번은 소제목 줄을 새로 만들지 않고 글자 크기·칸 이름 모양만 4번과 맞췄다. [+ 사업장 추가]는 칸 아래 그대로.
