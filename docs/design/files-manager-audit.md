# [파일] 화면 — '편한 파일 관리자'까지 모자란 것 전수 점검 (요청함 방, 2026-11-08)

명진 11/08 01:57: "하나하나 지시할 게 아니라 전수조사해서, 편리한 파일 관리자 앱처럼 쓰이기 위해 뭐가 부족하고 뭘 개선해야 하는지 스스로 판단해 봐. 지금 완성도 50% 수준."

기준: 윈도우 탐색기·두 칸 파일 관리자(토탈 커맨더류)·구글 드라이브 웹에서 '당연히 되는 것'.
근거: `app/files.js` 머리 주석(기능 목록)과 11/07~08 명진 캡처. 판단이 필요한 곳은 **결정** 표시.

## 0. 한 줄 진단

클라우드(원드라이브·구글) 안에서는 고르기·옮기기·복사·이름·휴지통·끌어 놓기까지 상당히 되지만,
**① 내 PC가 '보기·열기'만 되는 반쪽**이고 **② 두 칸 보기와 왼쪽 나무의 역할이 겹치며** **③ 저장소 사이 이동에 제한이 많아**
"칸을 넘나들며 끌어 옮기기"라는 파일 관리자의 기본 동작이 막혀 있다.

## 1. 지금 되는 것 (코드 확인)

| 영역 | 상태 |
| --- | --- |
| 클라우드 고르기 | PC Ctrl·Shift, 폰 꾹 누르기, 고르기 막대 |
| 클라우드 쓰기 | 이름 바꾸기·새 폴더·옮기기·복사·휴지통(확인 한 번) |
| 저장소 사이 | 복사·옮기기(전송 목록, 서버가 이어서), 원드라이브↔구글 옮기기 1개·200MB까지, 폴더째 복사는 같은 저장소 안만 |
| 두 칸 | 칸마다 저장소·위치·정렬·고르기, F5 복사·F6 옮기기·Tab, 칸 사이 끌어 놓기 → [복사][옮기기] |
| 이 폰(폰 앱) | 보기·받기·공유, 폰→클라우드 복사, 클라우드→폰 복사, 폰 새 폴더·이름·휴지통. **폰이 낀 옮기기 없음** |
| 내 PC | **보기·열기만**(이 PC에서 열기·탐색기에서 위치). 복사·옮기기·이름·휴지통·미리보기·별표 없음, 끌기·놓기 대상 아님 |
| 미리보기 | 사진·PDF·글(앞 200KB). 그 밖은 이름·크기 + 클라우드 새 창 |
| 찾기 | 클라우드만(내 PC 안 섞음, D3 결정) |
| 보기 | 목록·격자·큰 격자(두 손가락), 정렬 이름·바뀐 날·크기 |

## 2. 모자란 것 — 급한 순서

### A. 내 PC를 '진짜 드라이브'로 (가장 큼)
1. 내 PC ↔ 클라우드 **복사·옮기기**(끌어 놓기·F5/F6·Ctrl+C/V 모두). 지금 칸을 못 넘나드는 직접 원인.
2. 내 PC 안 **이름 바꾸기·새 폴더·옮기기·휴지통**(윈도우 휴지통으로, 확인 한 번).
3. 내 PC **미리보기**(사진·PDF·글 — 클라우드와 같은 미리보기 칸).
4. 내 PC 줄도 고르기 막대·⋯·우클릭 메뉴가 클라우드와 **같은 항목**.
- 보안: 바구니 PC 문(127.0.0.1·허용 출처·매 요청 로그인 토큰) 그대로, PC 파일 이름·경로는 서버·로그에 남기지 않음. 쓰기는 사람이 누른 것만.

### B. 두 칸 보기 정리 — **결정 필요**
- 문제: 두 칸이면 칸마다 저장소 ▾·위치 줄로 다 다닐 수 있어 왼쪽 나무가 겹친다(명진 01:56 "맨 왼쪽 칸은 왜 있는 거야?").
- (가, 추천) 두 칸일 때 왼쪽 나무는 **접어 둠**(맨 위 ◫ 단추로 필요할 때만 열기). 열면 나무에서 누른 폴더는 **지금 칸**(밑선 칸)에 열림. 고정한 폴더·별표·큰 파일은 칸 위 저장소 ▾ 안 맨 위에도.
- (나) 두 칸이면 나무를 아예 그리지 않음(고정한 폴더는 저장소 ▾ 안으로만).

### C. 끌어 놓기·붙여넣기를 어디서나
1. 칸 ↔ 칸, 목록 ↔ 나무, **어느 저장소끼리든** 끌어 놓기(내 PC·이 폰 포함). 놓으면 [복사][옮기기], 같은 저장소면 기본 옮기기(Shift·Ctrl로 바꾸기 — 탐색기와 같게).
2. 윈도우 바탕화면·탐색기에서 Web2로 **끌어 넣기 = 올리기**, 클립보드 그림 붙여넣기 = 올리기.
3. Ctrl+C·Ctrl+X·Ctrl+V가 저장소와 칸을 넘어 같게.

### D. 저장소 사이 제한 풀기
1. 원드라이브↔구글 **옮기기 1개 제한** → 복사처럼 여러 개(전송 목록으로).
2. **폴더째** 다른 저장소로 복사·옮기기(안의 파일을 전송 목록에 펼쳐 넣기).
3. 폰이 낀 **옮기기**(복사 뒤 원본 휴지통을 한 번에).

### E. 되돌리기·안전
- 이름 바꾸기·같은 저장소 옮기기·휴지통에 5초 [되돌리기](지금은 같은 저장소 옮기기만). 휴지통은 그 저장소 휴지통에서 [되살리기].

### F. 위치·상태 기억 (일부 이미 접수)
- 상자 접힘 기억(FILES-상자접힘기억), 고정한 폴더(FILES-폴더고정), 칸 따로 스크롤(FILES-칸따로스크롤)은 접수됨.
- 추가: **마지막으로 보던 폴더**(칸마다)를 서버에 기억 → 다시 열면 그 자리. 두 칸의 칸 폭도(UI-칸너비끌기).

### G. 미리보기·열기 넓히기
- 동영상·소리 재생, 한글(HWP 편집과 연결)·워드·엑셀 미리보기(클라우드가 주는 미리보기 이용), 미리보기 칸에서 ←→로 다음 파일.

### H. 찾기·거르기
- 지금 폴더 안 찾기와 전체 찾기 구분, **종류·날짜·크기 거르기**(칩), 내 PC 찾기는 D3 결정 유지 여부 **결정 필요**.

### I. 작은 것
- 정보 열(종류) 추가, 열 폭 끌기, 파일 ⋯에 [경로 복사]·[공유 링크]·[여러 개 받기(zip)].
- 큰 폴더(수천 개)도 끊김 없이(보이는 줄만 그리기).
