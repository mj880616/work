## 0. 사용자 결정(2026-11-28 20:30 무렵)

- 방향: **A안(뜻으로 나누기) 확정.** 탭은 보는 방식, ▾는 사용자가 만들어 늘어나는 분류로 거르기, 칩은 고정 상태 거르기만.
- 모양: **탭 = 1번(각진 묶음 칸) + 거르기 ▾ = 가번(연한 바탕 상자)** 조합으로 확정.
- 바탕색: 내 프로필에서 메뉴 색 고르기처럼 **10가지가 넘는 색 중에서 고르는 설정**으로 한다. 기본은 차분한 회색, 서버 저장(한 기기에만 남기지 않음), 글자 색은 바탕 밝기에 맞춰 저절로 바뀐다. 이번 PR은 시안에 '바탕색 고르기' 예시 칸만 넣었고 실제 설정 코드는 만들지 않았다.

### 확정 모양(시안 기준값)

| 부품 | 모양 |
| --- | --- |
| ⑤ 탭(1번 각진 묶음 칸) | 붙은 네모 칸 한 묶음. 바깥 얇은 회색 선 1px, 칸 사이 선 1px, 모서리 6px(묶음 바깥만). 높이 `--ds-compact-height`(32px), 글자 `--ds-compact-text`(13px). 고른 칸만 바탕색(아래 고른 색) + 굵게, 나머지 칸은 흰 바탕·흐린 글자 |
| ▾ 거르기(가번 연한 바탕 상자) | 선 없는 상자, 모서리 6px, 바탕은 고른 색(기본 차분한 회색), 높이·글자는 탭과 같음. 글자 '이름: 지금 고른 것' + 가는 꺾쇠(S73-49 [LIST-정렬꺾쇠]와 같은 모양). 값을 고른 상자('전체'가 아님)는 굵게 + 안쪽 얇은 선 |
| ④ 칩 | 지금 공용 `ds-chip` 그대로(고정 상태 거르기만) |
| 바탕색 | 탭의 고른 칸과 ▾ 상자 바탕이 같은 색 하나를 쓴다(한 가족). 시안 견본 15색(밝은 12 + 진한 3), 기본 회색. 글자 색은 바탕 밝기로 정함(진한 바탕이면 밝은 글자) |

구현 때는 이 값을 `app/theme-tokens.css`의 새 토큰 하나(예: 고른 칸·거르기 상자 바탕)와 그 글자 색 토큰으로 두고, 사용자 설정이 그 토큰만 바꾸게 한다(화면 CSS는 색을 정하지 않음). 지금 ⑤ 탭 모양(UI-보기탭한모양: 연한 알약 + 흰 알약)은 이 결정으로 바뀌므로, 구현 PR에서 `docs/design-decisions.md` UI-보기탭한모양 절을 고쳐 쓴다.

## 1. A안 규칙

1. **⑤ 탭**(`.ds-seg`) = 같은 자료를 다르게 보는 방식. 칸은 고정 2~6개. 예: 목록/달력, 폴더/목록/보드, 글/밑줄/메모, 전체/안 읽음.
2. **▾ 고르기 상자** = 사용자가 만들어 늘어나는 것(폴더·분류·종류·태그·매체·담당조직·사업영역)으로 거르기. 상자 글자는 '이름: 지금 고른 것'(예: '종류: 전체'). 여러 개 고르기는 상자 안 체크 목록. 높이·글자 크기·바탕은 탭과 같은 기준값(`--ds-compact-height` 32px, `--ds-compact-text` 13px, `--ds-seg-track`)을 쓴다. ▾ 표시는 가는 꺾쇠.
3. **④ 칩**(`button.ds-chip`) = 고정 몇 개(4개 이하) 켜고 끄는 상태 거르기만(★·요청·안 본 것·게시 중). 하나만 고르는 고정 칩 줄은 ⑤ 탭으로 옮긴다.

지금 두 부품의 차이(사용자가 '혼용'으로 본 것): 탭은 연한 알약 바탕에 테두리가 없다. 머리 줄의 `<select>`는 높이는 같은 32px이지만 화면마다 따로 쓴 테두리·회색 바탕·채운 세모(`--ds-select-arrow`)를 쓴다. 파일 정렬 상자만 24px·11.5px로 혼자 작다.

| 사업 보고 | 목록·달력·사진 두 번 → 한 번, 상자 글자 '이름: 값' | 폰 묶음 칩 글자가 짧아짐 |
| 사업영역 | 글자 통일 | 없음 |
| 텔레그램 소식 | 폴더가 늘어도 한 줄, 상태 칩만 눈에 띔 | 폴더 바꾸기 한 번 → **두 번** |

| 운영자 받은 의견 | 고정 칩 → 탭, 저장한 글과 같은 모양 | 없음 |

## 4. 잃는 것 줄이는 방법(제안)

- ▾ 목록 맨 위에 최근 고른 3개(서버 저장 보기 기억 `KPTUViewPrefs` — 한 기기에만 남기지 않음).
- 값을 고른 ▾ 상자는 고른 색으로 바뀌고 오른쪽 작은 ✕로 한 번에 '전체'.
- 읽을 거리 [매체 ▾] 안 맨 위 두 줄은 늘 [사회운동 묶음][언론 묶음].
- 노트 보드 ▾ 안 맨 아래 [+ 새 보드], 텔레그램 폴더 ▾ 안 맨 아래 [+ 폴더]·[보관함 n].
- 폰에서 머리가 두 줄이 되는 곳(자료실·사진·텔레그램)은 둘째 줄을 목록과 함께 숨겼다 보이는 안이 있다(따로 결정).

AGENTS.md 4절 '땜질 금지, 구조로 고친다'에 따라 공용 부품에서 한 번에 한다.
