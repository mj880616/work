### robots.txt 원문 확인(2026-11-02, 클라우드 작업 세션)

- 이 세션에서는 여섯 곳(kmwu.kr·kfsu.kr·www.hakbi.org·www.kgeu.org·www.eduhope.net·www.kcwu.or.kr)의 `/robots.txt`를 **읽지 못했다**: 직접 요청은 세션 네트워크 경로가 거절(CONNECT 403)했고, 공개 웹 읽기 도구는 주소 허가가 필요해 열지 못했다. 로봇 확인 화면을 풀거나 돌아가는 방법은 쓰지 않았다.
- L1 세 곳은 넣었다. 수집기(`outside-feed`)는 robots 예외 단체(공공운수노조·노동당)가 아니면 **실행마다 robots.txt를 먼저 읽고**, `Web2OutsideFeed`·`*` 규칙이 막은 경로는 읽지 않는다(목록이 막히면 `last_error='robots'`, robots.txt 요청이 401·403이면 `robots_denied`, 화면에는 '못 읽음 · 사이트가 자동 읽기 막음'). 그래서 '막혀 있으면 넣지 않는다'는 결정은 첫 운영 실행 결과로 확인한다: 배포 뒤 첫 예약 실행에서 세 곳 중 `robots`·`robots_denied`가 나온 단체는 다음 작은 PR로 카탈로그에서 뺀다(CC 확인 항목).
- 목록 표본(`tests/fixtures/outside-feed/kmwu.html`·`kfsu.html`·`hakbi.html`)은 1절 조사표의 링크 모양에 맞춘 지어낸 것이다. 실제 목록 HTML이 다르면 첫 실행에서 `parse_empty`로 드러나고, 그때 표본과 규칙을 함께 고친다.
