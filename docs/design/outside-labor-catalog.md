# 사회운동 Now [노동] 묶음 후보 조사표 (OUTSIDE-노동묶음·정돈, 2단계 준비)

- 요청: 요청함 11/02 00:19 「'노동' 묶음 만들고 주요 노조 더하기」 2) — 사이트·읽는 길·robots를 먼저 조사해 표로 보여 주고 명진이 고른다.
- 이 PR(S48-4, 1단계)은 묶음 칩 [노동] [정당] [사회운동] [외국]과 민주노총·공공운수노조를 [노동]으로 옮기는 것까지만 한다. **단체를 카탈로그에 더하는 것은 명진이 이 표에서 고른 뒤 다음 PR**이다(Edge 재배포 정지 지점, `supabase/functions/_shared/outside-catalog.ts` 머리 주석).
- 확인 시각: 2026-11-02 03:13~03:30(UTC). 클라우드 작업 세션에서 확인했다. 이 세션은 노조 사이트에 직접 요청(수집기 이름 `Web2OutsideFeed`)을 보낼 수 없어, 공개 웹 읽기 도구로 목록 첫 쪽만 1~3번 열어 봤다. **robots.txt 원문은 어느 곳도 직접 읽지 못했다** — 아래 'robots' 칸은 그 읽기 도구가 robots 때문에 거절당했는지만 적은 것이고, 수집기에 적용될 `User-agent: *` 규칙은 모두 '미확인'이다. 단체를 넣는 PR에서 robots.txt 원문을 다시 확인한다(다른 단체와 같은 규칙: robots를 지키고, 로봇 확인 화면은 풀지 않는다).
- 추측은 '추정', 확인 못 한 것은 '미확인'으로 적었다.

## 2. 명진이 고를 것(다음 PR 몫)
