# NOTE-에버노트 ① — 노트 안 할 일·노트 알림·서식 (S69-97)

요청: 사용자 2026-11-25 03:19~03:23 "에버노트 기능 중 가져올만한 거 있으면 제안 추천" → CC 제안 1~8 → "좋아 모두 다 넣어!".
이 문서는 제안 1·2·3이다(4~8은 S69-98). 노트 블록 편집(S69-96, `docs/design/note-notion-edit.md`) 위에서 만든다.

## 1. 원칙

- 정보 원본은 그대로: 할 일 = 구글 할 일, 노트 글 = Web2. 앱은 **연결만** 저장한다.
- 모든 저장은 서버 저장(기기 저장 없음). 새 권한 확대 없음 — 노트는 기존 owner RLS, 새 표는 owner RLS, anon 권한 없음.
- 남의 구글 연결로 읽지 않는다: google-tasks 함수는 로그인한 사람 자신의 연결(`ensureAccess(user.id)`)만 쓴다.

## 2. 노트 안 할 일 → 구글 할 일 (제안 1)

- 저장 모양: 할 일 체크 목록(`bullet_list` marker `check`)의 항목(`list_item`)에 `gtask` 칸 = 구글 할 일 id (`ed-schema.mjs` `GTASK_ID`, Edge 복사본도 같음). 새 표·DB 변경 없음.
- **기본은 끔(체크칸마다 켜기).** 수정 화면 [문단 ▾] → [구글 할 일로]를 누른 줄(또는 고른 여러 줄, 한 번에 20개까지)만 구글 할 일이 된다. 체크 목록이 아닌 줄에서 누르면 그 줄을 체크칸으로 바꾼 뒤 만든다. 연결된 줄에서는 같은 단추가 [구글 할 일 연결 풀기](구글 할 일은 그대로).
  - 노트 단위 일괄 켜기는 두지 않았다: 사용자가 원치 않는 할 일까지 구글로 쏟아지지 않게. 필요하면 다음에 노트 ⋯ 한 줄로 더할 수 있다.
- 만들 때: `google-tasks` `create`(기본 목록) + 그 노트의 '이 노트에서 만든 할 일' 기록(`metadata.tasks`, 기존 basket-note-tasks.js — 할 일 창의 '노트에서' 줄).
- 상태는 구글이 기준:
  - 노트 읽기 화면·수정 화면·큰 창이 열릴 때, 다른 화면에서 할 일이 바뀔 때(`kptu:google-tasks-changed`), 창으로 돌아올 때 `google-tasks` `pick`(새 동작: 할 일 id 최대 50개의 지금 상태만 읽음, 쓰기·DB 없음)으로 맞춘다.
  - 노트에서 연결한 체크를 누르면 바로 `toggle`. 실패하면 체크를 되돌리고 한 줄 알림(구글 쪽 우선).
  - 구글에서 삭제한 할 일은 연결을 풀고 한 줄로 알린다.
  - 읽기 화면은 노트를 쓰지 않고 구글 상태로 그리기만 한다. 수정 화면에서 맞춘 체크는 다음 [저장] 때 노트에 같이 저장된다(맞추기만 한 것은 '고친 것'으로 치지 않음).
- 줄 나누기·복제로 같은 id가 둘이 되면 뒤의 것, 체크 목록 밖으로 나간 항목은 연결을 뺀다(`gtaskDedupe`). 붙여 넣은 글에는 연결이 따라가지 않는다(id를 화면에 그리지 않음).
- 할 일 글 고치기는 구글 제목에 옮기지 않는다(끝냄·되살림만 맞춤).

## 3. 노트 알림 (제안 2)

- 저장 모양: 노트 `metadata.alarm = {at: ISO UTC}` 한 칸(고치기가 아니라 `updated_at` 그대로, 다른 metadata 칸 그대로 — `setNoteAlarm`).
- 화면: 노트 ⋯ [알림 걸기…](걸려 있으면 [알림 수정…]) → 오늘 저녁 6시 · 내일 아침 9시 · 금요일 9시 · 다음 주 월요일 9시 · [날짜·시각 선택…](달력 + 시각) · [알림 끄기]. 걸면 읽기 머리 줄 '알림 11/27(금) 09:00'(지난 것은 '지난 알림 …'), 누르면 같은 창.
- 보내기: `phone-push` 15분 예약(quarter)이 지난 36시간 안에 시각이 지난 노트마다 '노트 다시 보기' 한 번(본문 없음, 누르면 `?view=basket&pane=note&doc=<id>`). 열쇠 `note:<노트 id>:<시각>`으로 한 번만. 읽는 칸은 id·작업공간·alarm뿐(제목·글 없음). 알림 설정 '노트 알림'으로 끌 수 있다. 조용한 시간은 적용하지 않는다(사람이 직접 고른 시각).
- DB: `20261125130000_note_alarm_push_kind`(app_push_log 종류·알림 설정 종류에 `note`). 폰 앱은 종류 `note`('노트 알림')를 알아야 그린다(PushRules.kt) — 다음 폰 앱 릴리스 필요.
- 15분 예약이라 늦으면 15분 안쪽으로 늦게 온다.

## 4. 서식 (제안 3)

- 앱이 미리 넣은 서식은 없다(S71-65, 2026-11-26 사용자 결정 — 처음 두었던 기본 서식 셋은 지웠다). 서식은 사람이 저장한 내 서식뿐이다.
- 내 서식: 새 표 `app_note_templates`(주인만 읽고 쓰는 RLS, 이름 1~40자·작업공간 안에서 하나, 글은 ed1 200KB까지, migration `20261125131000_note_templates`). 화면이 50개까지로 막는다.
- 쓰기: 새 노트 창 도구 줄 [넣기 ▾] › [서식](S71-65, 제목 줄 [서식 ▾]는 없앰) · 노트 목록 ⋯ [서식으로 새 노트](창이 열리며 고르기창이 바로 뜸, 내 서식이 없으면 창 없이 안내 한 줄). 빈 글이면 서식 그대로, 쓴 글이 있으면 뒤에 붙인다. 제목 칸이 비었으면 서식 이름.
- 저장: 노트 ⋯ [서식으로 저장] → 이름(기본은 노트 제목) → 같은 이름이 있으면 바꿀지 묻는다. 구글 할 일 연결·체크 표시는 서식에 따라가지 않는다(빈 체크칸).
- 삭제: 고르기창 맨 아래 [내 서식 삭제…].
- 내 서식이 없으면 고르기창은 안내 한 줄 '노트 ⋯ [서식으로 저장]으로 내 서식을 만들어요.'만. 표를 읽지 못하면 '내 서식을 읽지 못했어요'.

## 5. 남은 일·결정 항목

- 게시(공유 페이지)로 연 노트 글에도 `gtask` id 글자가 실린다(받는 화면은 그리지 않음, 주인의 구글 로그인 없이는 쓸 수 없는 id). 빼려면 `share-page-read`에서 걸러야 한다(Edge 배포) — 별도 작업으로 제안.
- 노트 알림은 '최근 알림 7일' 목록에 넣지 않았다.
