# Web2 화면 용어 기준 (UI-용어통일)

명진 결정 2026-11-08: "웹2에서 사용하는 고치기, 수정 이런 용어들을 다 통일" → 전수조사 뒤 "수정 삭제로 맞추자".
새 기능·새 버튼도 이 표를 따른다. 화면 글자(버튼·메뉴·안내·알림·도움말)에 적용하고, 코드 이름·주석은 바꾸지 않아도 된다.

| 하는 일 | 쓰는 말 | 바꿀 말(지금 섞여 있음, 11/08 조사 횟수) | 예외(남김) |
|---|---|---|---|
| 내용 바꾸기 | **수정** | 고치기 25 · 편집 8 · 바꾸기 8 · 고침 4 | '이름 바꾸기'는 그대로. 메뉴 이름 'HWP 편집'은 도구 이름이라 그대로 |
| 없애기 | **삭제** | 지우기 50 · 버리기 20 · 휴지통으로 4 | 휴지통으로 가는 것도 버튼은 [삭제], 안내에 '휴지통으로 옮겨요'. **빼기**(원본은 두고 목록에서만 뺌)는 뜻이 달라 남김 |
| 저장 | **저장** | 완료(저장 뜻) · 적용 2 | '완료'는 할 일을 끝냄 뜻으로만 |
| 창 나가기 | 고친 것 없으면 **닫기**, 고친 것 버리면 **취소** | — | 확인 창의 실행 버튼은 '확인' 대신 하는 일 이름([삭제] 등) |
| 새로 더하기 | 새 것 **추가**, 이미 있는 것을 다른 곳에 **넣기** | 등록 4 → 추가 | '새 폴더'는 그대로 |
| 되돌리기 | **되돌리기** | 원래대로 2 | 휴지통에서 꺼내기만 **되살리기** |
| 새로 받아 오기 | 직접 눌러 새로 받기 **최신화**, 실패 뒤 **다시** | 다시 불러오기 9 · 다시 찾기 3 · 새로고침 1 | '방금 맞춤'은 상태 글자라 그대로 |
| 고르기 | **선택** · **모두 선택** | 고르기 6 | (수정·삭제와 같은 한자어 쪽으로 맞춤) |
| 보기 | Web2 안에서 **보기**, 원래 앱·파일로 **열기** | 더보기 5 → ⋯ | 접기·펼치기 그대로 |
| 치우기 | **보관**(보관함으로) · **숨기기**(안 보이게 설정) | — | 둘은 뜻이 달라 남김 |

- 같은 뜻 상태 글자도 맞춘다: '고침' 꼬리표 → '수정됨', '지웠어요' → '삭제했어요', '지울 수 있는' → '삭제할 수 있는'.
- 공개 배포물(업데이트 기록 release-notes)도 새로 쓰는 것부터 이 표를 따른다(옛 기록은 그대로).

## 재발 방지 검사

- `tests/ui-words.test.mjs`(검사기 `tests/ui-words.mjs`, App smoke check)가 화면 글자에서 위 표의 '바꿀 말'을 센다: 고치기·고쳐·고침·고치면 등 · 편집('HWP 편집' 제외) · 지우기·지워·지웠·지우면 등 · 버리기·버려·버리면 등('잊어버린'처럼 다른 말은 뺌) · 원래대로 · 다시 불러오기·다시 찾기·새로고침 · 더보기 · 고르기·골라·고른·고르면 등.
- 세는 곳: `app/` 화면 코드(`*.js`·`*.mjs`·`*.html`)의 따옴표·템플릿 글자와 HTML 글자, 폰 앱(`android-app/app/src/main`)의 Kotlin 글자·`strings.xml`, 이 표를 정한 뒤 새로 쓴 업데이트 기록. 주석·코드 이름은 세지 않는다.
- 파일마다 남은 수를 `tests/ui-words-baseline.json`에 둔다. 늘면 시험이 실패하고, 줄면 숫자를 줄이라고 알린다. 화면 묶음 PR마다 줄여 마지막에 0이 되게 한다.
- 사람이 쓴 말을 알아보는 패턴(예: 빠른 입력에서 '지워줘'를 알아듣기)처럼 화면에 나오지 않는 글자는 같은 줄에 `ui-words-ok`를 적고 까닭을 짧게 쓴다.
