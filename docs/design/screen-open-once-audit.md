# 화면을 열 때 한 번에 최종 모양으로 — 조사와 공통 구조 (RULE-한번에그리기)

2026-11-27 사용자 요청: 사업 관리 위쪽 고르기 상자가 3개였다가 4개가 되고, 파일 화면은 메뉴가 먼저 나왔다가 다른 메뉴가 그 위를 덮는다, 고르기 상자 ▾가 깨져 보인다. "이런 식의 땜질 처방 안 된다고 했잖아" — 화면마다 따로 고치지 말고 공통 원인을 구조로 고친다. 규칙 원문은 `AGENTS.md` 4절, 점검표 줄은 `docs/design/standard-interactions.md` U1.

## 1. 화면이 보이는 순서 (사실)

1. 앱 시작: 세션 확인 → 소유자 확인 → 화면 설정(`view-prefs.js` `viewPrefs.load()`)을 **앱을 보이기 전에** 기다림(`loader-v2.js` 189행 부근) → 첫 화면.
   그래서 `kptu:view-prefs-ready`가 늦게 와서 덮는 경우는 읽기가 시간을 넘긴 예외 길에서만 생긴다(조사한 12개 화면 모두 이 원인은 아님).
2. 메뉴로 화면 열기: `app-router.js` `go()`는 `view-loader.js` `load(view)`가 끝난 뒤에야 화면을 보인다(그 사이 위쪽 가는 줄). 이미 불러온 화면은 바로 보인다.
3. 그런데 화면 불러오기 함수 대부분이 **모듈 import만** 기다린다(`module(path)`). 모듈은 자료 읽기를 기다리지 않고(`void refresh()`) 끝나거나, 라우터 진입(`KPTURouter.on`)에서 그때부터 읽기 시작한다. 그래서 화면은 기본 모양으로 먼저 보이고, 자료가 오면 머리 줄 구성이 바뀐다.
4. 앱 시작 때 정적 껍데기가 있는 화면(`loader-v2.js` `staticShellViews`: home·basket·calendar·tasks·diary·library·meetings·team)은 불러오기보다 **먼저** 보인다.

## 4. 공통 구조 (이 PR)

**화면 첫 그림 약속.** 화면 모듈은 첫 그림에 필요한 서버 값(연결 상태·목록·설정)을 받아 그리는 약속을 `window.__KPTU_<화면>_READY__`에 두고, `view-loader.js` `screen(path, readyName)`이 그 약속을 기다린 뒤 끝난다. 라우터는 원래 불러오기가 끝나야 화면을 보이므로, 화면은 처음 보이는 순간부터 최종 모양이다. 기다리는 동안은 기존 위쪽 가는 줄만 보인다.

- 상한 `FIRST_PAINT_MS`(4초): 서버가 그보다 늦으면 기다리지 않고 연다. 그때는 화면 모듈이 받은 뒤 한 번 그린다(기본 모양을 먼저 그리지 않음).
- 사업 관리는 이미 `team('meetings')`(`loadForView`)를 기다리는 구조라, 그 안에서 머리 줄을 정하는 값(사업영역 나무·회의명 정리·보고 연결)을 모두 받은 뒤 그리게 했다.
- 숨긴 채 그린 화면이 처음 보일 때 재는 부품은 재기를 다음 프레임으로 미루지 않는다(ResizeObserver 알림은 그리기 전에 온다).
- 새 상태 저장소·지연 덮어쓰기·MutationObserver·`display:none`·임시 `setTimeout` 없음. 기존 `module(path, readyName)` 길(달력 등)과 같은 모양이다.
- 시험: `tests/app-e2e/screen-open-once.spec.mjs` 화면 표(머리 줄 읽기를 늦춘 채 열어 머리 줄 모양이 한 가지인지), `tests/screen-open-once.test.mjs`(길 지키기). 새 화면은 표에 더한다.

**▾ 선명도.** 공용 고르기 상자 ▾는 그라데이션 반쪽 두 장(4×4 두 장을 이어 붙인 세모 — 대각선 계단·흐림, 소수 px 폭에서 두 장 이음매 어긋남, 0.5px 테두리로 세로 반 픽셀)으로 그렸다. 같은 8×4 세모를 벡터 그림 한 장(`--ds-select-arrow`)으로 바꿨다. data: 그림 안에서는 `var()`를 못 쓰므로 테마마다 `--kptu-muted` 색으로 토큰을 둔다(`theme-tokens.css`·`base-ui.css`). 자리·크기·모양은 그대로(`ui-standard.css` 공용 규칙 한 곳, 날짜 칸 같은 그림 포함). 시험 `tests/select-arrow.test.mjs`.
