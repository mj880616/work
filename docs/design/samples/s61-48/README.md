# S61-48 WEEKLY-기본HWP 예시 파일

실제 보고 내용 없이 예시 글(예시 사업영역·예시 과제·예시 조직)만 넣어 만든 주간보고 파일 두 벌이다. 저장소가 공개라 진짜 주간보고 파일은 올리지 않는다.

- `주간보고_예시.hwpx` — Web2가 만드는 원래 판(.hwpx). ⋯ [.hwpx로 받기]가 이 형식이다.
- `주간보고_예시.hwp` — 같은 파일을 화면 안 한글 엔진(HWP 편집기와 같은 칸막이 엔진)으로 바꾼 판. [확정하고 한글 파일 받기]·[확정 없이 파일만 받기]가 이 형식이다.

바탕 양식은 시험용 표본(`tests/fixtures/hwp-lab/sample.hwpx`)이라 실제 상집보고 양식보다 단순하다. 두 파일을 한글에서 열어 모양·글자가 같은지 비교하면 된다.
.hwp를 다시 엔진으로 .hwpx로 바꿔 읽으면 같은 칸 글(사업영역·과제·진행 줄·조직 소식)이 나오는 것을 확인했다.
