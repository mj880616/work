## 남기는 것 / 빼는 것

- 남김: 홈('오늘'), 일정(달력·할 일·하루 기록), 노트(잊지 말기), 사진·파일·자료실, PIN 잠금, 백업, 쓰는 법(다이어리용), HWP 편집·공유 페이지(선택).
- 뺌(11/20 고침: 사업 관리는 남겨 '프로젝트·거래처'로 이름만 바꿈): News·브리핑 룸·아스날, 자료실 '성명·보도자료' 종류, 통화·텔레그램(원래 운영자 전용).
- 나중: 거래처·사람 수첩(담당조직 구조 재사용), 가족·팀 공유.
- 빠지는 기능은 화면 숨김이 아니라 메뉴·경로 제거 + 서버 거절(AGENTS.md 5절 운영자 기능과 같은 방식).

## 서버를 따로 둘 때 할 일

1. 새 Supabase 프로젝트 생성(명진 로그인). 요금제·무료 프로젝트 수 확인.
2. 스키마 옮기기: 운영 DB에서 **구조만**(내용 없이) 떠서 새 프로젝트에 적용. `rtw_*`·Web1 표는 빼고 Web2 구조만. `supabase db push`·`migration repair` 금지는 새 프로젝트에도 그대로.
3. 이후 migration은 두 프로젝트에 모두 적용: `db-migration-apply.yml`·`edge-function-deploy.yml`에 대상(노조 플러스/다이어리) 입력 추가, 대상별 GitHub environment·프로젝트 ref 변수.
4. Edge 함수 비밀값(구글·AI 키 등)은 새 프로젝트에 명진이 대시보드에서 넣음(AI는 비밀값 변경 안 함).
5. 구글 로그인: 새 OAuth 동의 화면(다이어리 이름)·개인정보처리방침 페이지·도메인 → 구글 심사 따로.

## 단계

1. 명진: 아이콘 시안 고르기, 웹 주소(이름은 기록+로 확정).
2. 얼굴 설정 파일·단어표, 노조 플러스 화면 불변 시험.
3. 다이어리 얼굴에서 메뉴·경로 빼기 + 서버 거절.
4. 새 Supabase 프로젝트·스키마·workflow 대상 추가.
5. 웹 주소·구글 로그인 연결·심사 신청.
6. 폰 앱 새 판(새 applicationId·서명 열쇠) → GitHub 공개 릴리스.
7. 플레이 스토어 비공개 시험 → 출시(노조 플러스 출시 뒤).
