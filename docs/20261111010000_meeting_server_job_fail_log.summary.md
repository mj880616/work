무엇이 바뀌나: 녹음 서버 정리 작업에 '실패 이력' 칸 하나가 생기고, DB가 상태가 바뀔 때(실패·다시·끊김·오래 걸림) 이유·단계·시각·걸린 시간만 짧게 쌓습니다(글 내용 없음, 최근 20줄). [다시]를 눌러도 지워지지 않습니다. 기존 작업은 빈 이력으로 시작합니다. 정책·권한은 바뀌지 않습니다(서버에 새 권한을 주지 않음).
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 이력 쓰기는 상태 저장과 같은 한 번의 쓰기 안에서 일어나므로, 만약 이력 계산이 실패하면 그 상태 저장도 실패합니다 — 시험 적용에서 걸러지며, 그래도 문제가 보이면 아래로 되돌립니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 트리거·함수·새 칸·검사·기록 1행만 지웁니다. 실패 이력만 사라지고 녹음·전사 글·요약은 그대로입니다.
