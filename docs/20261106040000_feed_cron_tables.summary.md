무엇이 바뀌나: 사회운동·언론 수집을 GitHub 예약 대신 DB 안 예약으로 돌리기 위한 빈 기록 표 셋(예약 열쇠 지문·예약 칸·칸 안의 일)과 그 표만 다루는 내부 함수 다섯이 생깁니다. 화면·로그인 사용자·익명은 이 표와 함수에 아무 권한이 없고 서버는 읽기만 합니다. 아직 예약은 켜지지 않으며(다음 단계), 기존 표·권한·화면은 그대로입니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 같은 이름의 표·함수가 이미 있으면 멈춥니다. 적용 뒤 문제가 생겨도 지금 수집(GitHub 예약)과 화면에는 영향이 없습니다(아직 이 표를 쓰는 예약·코드가 없음).
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 새 표 셋·함수 다섯·기록 1행만 지웁니다. DB 예약(다음 단계)이 이 함수를 부르고 있으면 멈추므로, 예약을 먼저 끈 뒤 실행합니다.
