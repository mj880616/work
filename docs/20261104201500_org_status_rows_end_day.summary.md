무엇이 바뀌나: 담당조직 현황 줄에 '끝나는 날'(비워도 됨) 칸이 하나 생깁니다. 기존 줄은 끝나는 날 없음(하루 일정)으로 그대로이고, 기존 칸·권한·정책은 바뀌지 않습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 새 칸만 더해지므로 이전 화면은 그대로 동작합니다(새 화면은 칸이 없으면 줄을 못 읽으므로 DB 적용 뒤에 화면을 배포합니다).
되돌리는 법: 화면을 이전 판으로 돌린 뒤 짝 rollback을 SQL Editor 새 창에서 실행해 새 칸·검사·기록 1행만 지웁니다. 적어 둔 끝나는 날만 사라지고 시작일·글은 그대로입니다.
