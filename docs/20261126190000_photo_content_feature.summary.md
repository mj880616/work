무엇이 바뀌나: 운영자 기능 목록에 '사진을 설명 낱말로 찾기(photo_content)' 키 하나가 생기고, 통화 기능이 켜진 작업공간(명진) 하나에만 켭니다. 새 표·함수·권한·정책은 없고, 사진 설명 글은 DB에 들어가지 않습니다(명진 드라이브 안 시트).
