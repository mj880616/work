무엇이 바뀌나: 할 일에 붙인 파일을 기억하는 작은 새 표 1개("어느 할 일에 어느 Drive 파일")가 생깁니다. 로그인한 명진 본인만 읽고 쓸 수 있고, 로그인 없는 사람·서버 관리자 키에게 여는 권한은 없습니다. 파일 내용은 Drive에만 있고 표에는 이름·크기·Drive 파일 번호만 들어갑니다. 기존 표·자료·권한은 그대로입니다.
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 적용 뒤 문제가 나도 화면은 표가 없을 때처럼 "파일 붙이기" 메뉴와 파일 이름만 숨고, 할 일 기능과 기록은 그대로입니다.
되돌리는 법: 짝 rollback으로 새 표 1개와 기록 1행만 지웁니다. 첨부가 한 줄이라도 생긴 뒤면 지우지 않고 멈추고, 먼저 화면 사용을 멈춘 뒤 보관 여부를 정합니다(Drive 파일과 할 일 메모의 링크 줄은 어느 경우에도 남습니다).
