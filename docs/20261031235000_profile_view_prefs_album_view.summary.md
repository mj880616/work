무엇이 바뀌나: 사진 [앨범] 탭에서 [− +]로 고른 보기 크기(큰 칸·작은 그림 목록·한 줄 목록)를 서버에 기억합니다(폰·컴퓨터 같음). 바뀌는 것은 내 프로필의 "화면 선택 기억" 값 검사 하나에 '앨범 보기' 칸(album_view, card·thumb·line 셋 중 하나)을 더하는 것뿐이고, 새 열·권한·정책은 없으며 기존 자료와 다른 화면 기억 규칙은 그대로입니다.
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 검사식이 틀리면 다른 화면 선택 저장이 거절될 수 있어, 실제 PostgreSQL 시험으로 앞선 칸이 그대로 받아지는지 확인했습니다. 적용 전에는 앨범 보기 저장만 거절될 뿐(이번 접속 동안만 기억, 다시 열면 큰 칸) 다른 기능은 그대로입니다.
되돌리는 법: (화면 PR을 merge했다면 먼저 이전 판으로) 짝 rollback으로 검사를 이전 모양(폰 폴더 단계 20261031060000)으로 되돌리고 기록 1행만 지웁니다. 앨범 보기가 저장된 프로필이 있으면 지우지 않고 멈추며, 그 값을 어떻게 할지 정한 뒤 다시 계획합니다.
