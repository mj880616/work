무엇이 바뀌나: 내 프로필 표에 "이름 바꾸기" 칸 하나(처음엔 비어 있음)와 값 검사(칸 이름 15가지만, 이름은 1~20자 글자, 앞뒤 공백·제어문자·< > & " ' ` \ 없음, 전체 2000바이트)를 더합니다. 비어 있는 동안 화면은 지금 이름 그대로이고, 내 프로필에서 메뉴·분류 이름을 바꿔 저장하면 어느 기기에서 열어도 같은 이름이 보입니다. 기존 자료·권한·정책은 바꾸지 않습니다.
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 적용 뒤 문제가 나도 화면은 칸을 못 읽으면 기본 이름으로 열고 '이름 바꾸기' 저장만 "저장 준비 중"으로 막히므로, 프로필 저장·다른 화면은 그대로 동작하고 남에게 보이는 범위도 바뀌지 않습니다(내 행만 읽고 씀).
되돌리는 법: 짝 rollback으로 검사·칸과 기록 1행만 지웁니다. 누군가 이름을 저장해 둔 뒤면 지우지 않고 멈추고, 먼저 값을 보관한 뒤(운영자 값은 docs/ops/custom-words-operator.rollback.sql로 먼저 비움) 다시 계획합니다.
