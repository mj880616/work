무엇이 바뀌나: 자료실 자동 정리용 작은 새 표 2개(바꾸기 전 원래 값 백업, 이미 AI에 보낸 자료 기록)와 함수 2개(백업하면서 바꾸기, 묶음 되돌리기)가 생깁니다. 적용하면 그때부터(화면·서버 배포 뒤) 자료실을 열 때 손으로 넣지 않은 칸(빈 칸·파일 이름 그대로인 제목·'기타'나 목록 밖 분류)을 AI가 자동으로 바꿉니다(기존 자료 약 75개 포함). 손으로 넣거나 고친 칸은 바꾸지 않습니다. 로그인한 명진 본인만 읽고 쓸 수 있고, 로그인 없는 사람·서버 관리자 키에게 여는 권한은 없습니다. 적용 순간에는 기존 자료 값이 하나도 바뀌지 않습니다.
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 적용 뒤 AI가 잘못 바꾼 칸은 원래 값이 백업되어 있어 묶음 단위로 되돌릴 수 있습니다. 표·함수가 없거나 서버가 아직 배포 전이면 화면은 조용히 아무것도 하지 않고 자료실은 그대로 동작합니다.
되돌리는 법: 값만 되돌릴 때는 묶음마다 되돌리기 함수를 SQL Editor에서 실행합니다(지금 값이 AI 값 그대로인 칸만 원래대로, 그 사이 고친 칸은 건너뜀). 표·함수까지 없앨 때는 화면·서버를 먼저 이전으로 돌린 뒤 짝 rollback을 SQL Editor에서 실행합니다. 되돌리지 않은 백업이 한 줄이라도 있으면 rollback은 지우지 않고 멈춥니다.
