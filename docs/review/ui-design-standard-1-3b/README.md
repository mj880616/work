# UI-디자인기준 1/3 보완(8-9c2) 전후 캡처

검사용 합성 데이터로 390(폰)·1280(PC) 폭에서 찍은 화면이다. `before/`는 시작 main `c821924`, `after/`는 이 작업 브랜치다.

| 파일 | 화면 |
| --- | --- |
| `home-basket-*` · `home-task-*` · `home-update-*` | 홈, 빠른 입력 탭 바구니·할 일·업데이트 선택 |
| `basket-list-*` | 바구니 목록 |
| `basket-more-*` | 바구니 목록, [⋯ 더보기] 펼침(after만) |
| `basket-read-*` | 바구니 메모 읽기(PDF·HWP 첨부) |
| `basket-edit-*` | 바구니 메모 수정 |

전체 페이지 캡처라 폰의 아래 탭 줄이 화면 중간에 겹쳐 보일 수 있다.
