# UI-일기손질 화면 검토

📱 폰 가능. 일기·달력 작은 손질 묶음(원장 "UI-일기손질" ①~⑥).

- `diary-*`: [일기] 달력. 오늘(10월 6일)은 날짜 숫자가 보라 동그라미(채움), 고른 날(10월 4일)은 칸 보라 테두리. 아래 상자에는 고치기·지우기만.
- `diary-empty-day-*`: 일기가 없는 날을 고른 모습. "이 날 일기가 없어요." 한 줄뿐이고 [이 날 일기 쓰기]가 없다. 오른쪽 아래 [+]가 그 날짜 쓰기.
- `calendar-*`: [달력] 탭 월간. 오늘 칸 날짜 숫자가 [일기]와 같은 보라 동그라미.
- `note-open-*`: 바구니 [노트]에서 노트를 연 화면. 위에는 "‹ 노트"·⋯만 있고 [메모|노트]는 그리지 않는다. 첨부는 공용 파일 한 줄(종류 색 · 이름 / 크기 · 작은 [Drive에서 열기]).
- `note-empty-390-light.png`: 노트가 없을 때. 안내 문장 없이 빈 화면.
- ① [+] 위치는 그림이 아니라 검사로 확인한다(`tests/app-e2e/ui-diary-polish.spec.mjs` ①: [오늘]·날짜·탭 전환을 누르는 동안과 뒤의 좌표가 같음).

캡처는 `UI_REVIEW_DIR=<이 폴더> npx playwright test tests/app-e2e/ui-diary-polish.spec.mjs -g 캡처`로 다시 만든다.
