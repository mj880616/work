# UI-디자인기준 2/3(8-9d) 전후 캡처

검사용 합성 데이터로 390(폰)·1280(PC) 폭에서 찍은 화면이다. `before/`는 시작 main `ffe1d50`, `after/`는 이 작업 브랜치다.

| 파일 | 화면 |
| --- | --- |
| `calendar-*` | 일정(폰은 목록 보기, PC는 주간 보기) |
| `tasks-*` | 할 일 |
| `projects-*` | 프로젝트 목록(메인 아래 하위 가지 선, 오른쪽 D-day 알약) |
| `project-detail-*` | 프로젝트 상세(모양만, 구조 그대로) |
| `basket-more-*` | 바구니 [⋯ 더보기] 펼침(버튼 이름 변경) |

캡처 환경(클라우드 컨테이너)에는 한글 글꼴의 중간 굵기(500)가 없어 굵기 500이 400처럼 보인다. 폰(안드로이드 Noto Sans CJK)에서는 메인 프로젝트 이름(500)이 하위(400)보다 굵게 보인다.
