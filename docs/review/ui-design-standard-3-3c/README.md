# UI-디자인기준 3/3 3부(8-9e-3) 캡처

검사용 합성 데이터로 찍은 이 작업 브랜치 화면이다. `light/`는 기기 설정 밝음, `dark/`는 기기 설정 어두움(다크 모드), 테마는 기본(오트밀·올리브), 로케일 한국어, 기준 시각 2026-10-16 12:00(한국 시간).
테마 4종(남색·크림·테라코타·모래·갈색)의 어두운 화면 대비는 검사 `ui-standard-3c`가 화면마다 확인한다(본문 글자 4.5:1 이상).
