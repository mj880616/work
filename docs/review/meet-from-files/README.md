# MEET-파일로만들기 화면 검토

📱 폰 가능. 회의 [+] 창 맨 위 [직접 쓰기 | 파일·글로 만들기] 중 [파일·글로 만들기] 화면(원장 "MEET-파일로만들기").

- `preview-*`: 파일 5개(PDF)와 결과 글 2건(회의 제목 줄로 나뉨)을 넣은 미리보기 표. 회의별 한 줄: 날짜·종류·차수·자료 수·결과 있음/없음.
  - 25.10.15 중앙집행위원회 5차: 자료 파일 + 결과 글(경우 ①).
  - 25.08.20 대의원대회 1차: 결과 글만(경우 ④), 처음 보는 회의명이라 주황 테두리와 [새 종류로 만들기].
  - 25.09.10 본부 운영위원회 2차: 자료 파일 + 결과 파일(경우 ②), 결과 파일 본문을 결과 칸에 넣는다.
  - 25.12.01 중앙집행위원회 7차: 자료만 있어 "결과 없음"(빨간 글자) · "결과를 더해 주세요". 만들지 않는다.
  - 중앙집행위원회 8차: 이름에 결과/자료 낱말이 없어 주황 테두리 · "결과인지 자료인지 골라 주세요".
  - 아래 버튼은 만들 수 있는 건수만 센다("회의 2건 만들기"), 확인이 필요한 줄은 그 위에 한 줄로 알린다.
- 줄을 누르면 종류·차수·날짜 칸과 그 묶음의 파일(종류 색 · 이름 · 결과/자료 고르기 · ×)이 펼쳐진다. 직접 골라야 하는 줄은 처음부터 펼쳐져 있다.
- 경우 ③(결과 파일만, HWP 본문 읽기)·기존 회의에 더하기·여러 회의 한 번에·중간 실패 뒤 다시 만들기는 그림이 아니라 검사로 확인한다(`tests/app-e2e/meeting-from-files.spec.mjs`).

캡처는 `UI_REVIEW_DIR=<이 폴더> npx playwright test tests/app-e2e/meeting-from-files.spec.mjs -g 캡처`로 다시 만든다.
