무엇이 바뀌나: 운영자만 부를 수 있는 '가입자 목록' 서버 함수가 사람마다 조직·부서·이름·직책·이메일·가입일·마지막 사용 시각을 돌려줍니다(맨 위 숫자 셋은 화면이 이 목록에서 셉니다). 기록 내용은 돌려주지 않고, 표·권한·기존 기록은 그대로입니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 목록 모양(배열)은 그대로라 지금 화면과 새 가입 알림 줄은 적용 전후 똑같이 동작합니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 함수를 어제 모양(이름·가입 시각·마지막 접속만)으로 되돌리고 이번 기록 1행을 지웁니다. 표·자료는 바뀐 것이 없어 지울 것이 없습니다.
