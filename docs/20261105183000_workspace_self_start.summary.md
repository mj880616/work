무엇이 바뀌나: 새로 로그인한 사람이 자기 작업공간을 스스로 만드는 서버 기능과, 그 기능을 켜고 끄는 서버 스위치(꺼진 채)가 생깁니다. 스위치는 SQL로만 켤 수 있고 이번에는 켜지 않으므로 화면도 동작도 지금과 같습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 스위치를 켠 뒤 만들기가 실패하면 그 사람의 작업공간은 만들어지지 않고 지금처럼 접근 거부 화면이 보입니다(반쯤 만들어진 것은 남지 않음).
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 새 함수 둘·스위치 표·기록 1행만 지웁니다. 기존 작업공간·명진 자료는 건드리지 않습니다.
