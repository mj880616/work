무엇이 바뀌나: 노트 폴더를 담는 새 표 1개가 생깁니다(폴더 안에 폴더, 100단까지, 빈 폴더도 남음). 지금 노트에 적힌 폴더 이름들은 그대로 맨 위 폴더로 옮겨 담기고, 노트 자체는 한 줄도 바뀌지 않습니다. 새 노트 화면이 이 표를 씁니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 기존 표·권한은 건드리지 않으므로 노트·다른 화면에는 영향이 없고, 표가 없으면 새 노트 화면은 지금 폴더 이름만 읽기 전용으로 보여 줍니다.
되돌리는 법: (새 노트 화면을 배포했다면 먼저 이전 판으로 되돌린 뒤) 짝 rollback을 SQL Editor 새 창에서 실행해 새 표·함수·기록 1행만 지웁니다. 노트는 그대로이고, 폴더 이름은 옛 폴더 줄에 다시 보입니다(폴더 안 폴더는 맨 끝 이름 하나로).
