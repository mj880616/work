무엇이 바뀌나: '바깥 성명' 메뉴가 쓸 새 표 4개(켠 단체·들어온 글·국내 글 문장·마지막으로 본 시각)와 문장 찾기 함수 1개가 생깁니다. 모두 자기 작업공간 주인만 보고, 글을 넣는 것은 서버 수집기만 할 수 있습니다. 화면과 수집기는 아직 없어 겉으로 달라지는 것은 없습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 기존 표·권한·함수는 건드리지 않으므로 적용 뒤 문제가 생겨도 다른 메뉴는 그대로입니다.
되돌리는 법: (수집 예약·화면을 붙였다면 먼저 끈 뒤) 짝 rollback을 SQL Editor 새 창에서 실행해 새 표 4개·찾기 함수·기록 1행만 지웁니다. 지워지는 것은 단체 홈페이지에서 다시 읽을 수 있는 공개 글 사본과 켠 단체 목록뿐입니다.
