무엇이 바뀌나: Claude 읽기 연결 설정에 영역 스위치 5개(하루 기록·통화·녹음·정리함 켜짐, 가족 방 꺼짐)가 생기고, 그 영역을 읽기만 하는 함수 10개가 더해집니다. 연결 전체 스위치는 그대로 꺼진 채라 지금은 아무도 이 함수로 읽을 수 없고, 기존 표·권한·자료·화면은 바뀌지 않습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 문지기 함수가 잘못되면 Claude 연결만 거절되고 Web2·읽생기 사용에는 영향이 없습니다(지금 화면은 이 함수들을 쓰지 않음).
되돌리는 법: 요청 전 함수 목록 되돌리기(docs/ops/mcp-claude-read-guard-areas.rollback.sql)를 먼저 하고, 짝 rollback을 SQL Editor 새 창에서 실행해 새 함수·칸·기록 1행을 지우고 문지기를 원래 모양으로 되살립니다.
