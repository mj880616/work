# Web2 P5 전체 안정화·기술부채 점검 보고서

## 범위와 점검 방법

Web2의 공개/인증 부팅 경계, 홈, 일정, 할 일, 프로젝트와 상세, 자료실, 언론대응, 회의, 게시판, 팀/프로필, 로그인·로그아웃·초대 및 모바일 흐름을 코드 경로와 기존 브라우저 회귀검사로 점검했다. `app.js`에서 시작하는 로더 의존성, 라우터 이벤트, 화면별 renderer, 전역 observer와 지연 실행, 저장 실패·세션 갱신·직접 URL 테스트를 함께 확인했다.

변경은 DB 스키마, RLS, Edge Function 인증, 저장 데이터, 공개범위 정책 및 URL 구조에 손대지 않는 범위로 제한했다.

## 실제 수정사항

- 홈 render 시작부터 loading과 오류 경계를 적용해 인증 컨텍스트 조회 실패도 네 패널에서 동일하게 설명한다.
- 세션 세대(`renderEpoch`)를 컨텍스트 조회와 데이터 commit 양쪽에서 확인한다. 이전 세션의 늦은 멤버십 응답이 전역 컨텍스트를 다시 채우지 못하게 하고, 폐기된 render 뒤에는 최신 세션 render를 다시 예약한다.
- 현재 홈에 대상 DOM이 없고 테스트도 부재를 기대하는 `home-task-controls.js`와 전용 CSS를 loader/style graph에서 제거했다.
- P4에서 이미 비활성화됐고 안전한 Drive 공개 순서를 구현하지 않는 `library-public-toggle.js`를 제거했다.
- smoke 검사에 세 파일의 부재와 재참조 금지를 추가했다.
- 홈 초기 컨텍스트 실패 메시지와 세션 이벤트 뒤 정상 복구를 검증하는 브라우저 회귀검사를 추가했다. 멤버십 조회 도중 계정이 바뀌는 경우 새 사용자의 workspace/assignee 조건으로만 데이터가 조회되는 경쟁 조건 검사도 포함한다.

## 삭제한 기술부채와 근거

- `app/home-task-controls.js`: 유일한 runtime import는 loader였고, 소유 대상 `#myTaskMini`는 P2 renderer가 교체한 `#homeView` 내부에서 사라진다. 기존 모바일/UI 검사는 `[data-hta-expand]`가 없음을 명시적으로 확인한다.
- `app/home-task.css`: 활성 코드에서 `hta-*` DOM을 만들지 않으며 위 모듈 전용 selector만 있었다.
- `app/library-public-toggle.js`: loader/import/HTML 참조가 없었다. 현재 공개범위와 Drive 권한 동기화는 `library-upload.js`가 소유한다. 옛 파일의 직접 PATCH 흐름은 현재 안전 원칙과도 맞지 않는다.

## 수정하지 않고 남긴 항목

- 일부 프로젝트·모달 보조 모듈에는 DOM observer와 지연 후처리가 남아 있다. 여러 테스트가 해당 모듈의 존재를 구조 계약으로 검사하고 있어, 실제 runtime 호출과 소유권을 기능별로 분리 검증하기 전 대량 삭제하지 않았다.
- loader의 인증 후 기능 모듈은 여전히 긴 순차 구간을 가진다. readiness promise 및 화면 간 의존성이 얽혀 있어 측정 없이 병렬화하지 않았다.
- 라이브 Supabase/Google Drive의 네트워크 단절과 실제 계정별 RLS는 로컬 mock E2E만으로 완전히 재현할 수 없다. 기존 trusted-layer 정적 회귀와 SQL 자산은 유지했다.
- 원격 저장소 연결이 실행 환경의 CONNECT 403으로 차단되어 최신 `main` fetch를 검증하지 못했다. 작업은 제공된 HEAD(`97670ec`)에서 분기했다.

## P5 이후 제품개선 후보

다음은 안정화 범위를 벗어나므로 구현하지 않았다.

- 주요 일정 선정 기준 개선(현재 프로젝트 마일스톤 기준 유지)
- 화면 단위 기능 모듈 lazy loading 및 부팅 성능 계측
- 실제 staging 계정을 이용한 공개/내부/개인 자료와 Drive ACL 통합 E2E
- 프로젝트 보조 모듈의 이벤트 소유권을 기능 단위로 통합하는 후속 정리

## 직접 확인 권장 화면

1. 로그인 홈을 느린 네트워크로 열 때 네 카드가 한 번만 나타나고 오류 후 복구되는지
2. 로그아웃 직후 공개 홈에 이전 사용자의 할 일·자료 요약이 남지 않는지
3. 자료실에서 외부 공개/공개 해제 시 Web2 표시와 Drive 링크 권한이 함께 바뀌는지
4. 모바일 프로젝트 상세의 하위 프로젝트 disclosure와 생성 동선
5. 로그인 만료 상태에서 저장 실패 후 버튼이 다시 활성화되고 재로그인이 가능한지
