# 노조 문서 양식 스타일·번호 체계 기준 (2026-10-15 사용자 확정)

MD-내보내기([한글용 복사]·문체 점검)와 HWP-서식변환([HWP로 만들기])의 기준이다. Web2 편집기의 목록 단계·문단 종류를 아래 한글 스타일과 번호 기호로 바꾼다.

## 1. 기준 양식

- 공공운수노조 문서 통일 양식(2018년 1월부터 사용, 한글 스타일 F6 목록 + Ctrl+숫자 단축키).
- 원본 HWP는 사용자 Drive에 있다. 내부 문서이므로 **이 공개 저장소에 파일을 넣지 않는다.** HWP-서식변환 구현 때 사용자가 Drive "양식" 폴더의 파일을 지정한다.
- 아래 스타일 이름·크기는 그 파일의 DocInfo 스타일 표를 읽어 확인했다(2026-10-15 커맨드센터).

## 2. 단축키별 스타일(파일 기준)

| 단축키 | 스타일 | 글자 | 비고 |
|---|---|---|---|
| Ctrl+1 | 바탕글 | 13pt | 일반 본문 |
| Ctrl+2 | 안건제목 | 36pt | 문서 제목 |
| Ctrl+3 | 큰 제목 | 18pt | |
| Ctrl+4 | 중간 제목 | 16pt | |
| Ctrl+5 | 작은 제목 | 14.5pt 굵게 | |
| Ctrl+6 | 최하위 제목[강조] | 13.5pt | |
| Ctrl+7 | 세부 참고사항 | 11pt, 왼쪽 20pt | * 참고 줄 |
| Ctrl+8 | 표내부 | 10pt | |
| Ctrl+9 | (기타)의결주문 | 13pt | [의결주문] |
| Ctrl+0 | 중간대제목 | 28pt 굵게 | |
| — | 문서표지제목·쪽 번호·각주·공문 본문 | | 단축키 없음 |

## 3. Web2 편집기 → 한글 대응(사용자 확정)

| Web2 | 기호 | 한글 스타일 |
|---|---|---|
| 문서 제목 | — | 안건제목 (Ctrl+2) |
| 목록 1단계 | 1. | 큰 제목 (Ctrl+3) |
| 목록 2단계 | 1) | 중간 제목 (Ctrl+4) |
| 목록 3단계 | (1) | 작은 제목 (Ctrl+5) |
| 목록 4단계 | ① | 최하위 제목[강조] (Ctrl+6) |
| 목록 5~7단계 | 가. → 가) → (가) | 바탕글 (Ctrl+1) + 기호 |
| 8단계 이상 | (가) 반복 | 바탕글 |
| 일반 문단 | — | 바탕글 (Ctrl+1) |
| 참고 줄(*)·강조 상자 | — | 세부 참고사항 (Ctrl+7) |
| 표 안 글 | — | 표내부 (Ctrl+8) |

- [한글용 복사]: 클립보드로는 한글 스타일이 넘어가지 않으므로 기호·들여쓰기·굵게·표만 맞춘다. 스타일은 한글에서 단축키로 입힌다.
- [HWP로 만들기]: 기준 양식 파일을 바탕으로 각 문단에 위 스타일을 직접 입힌다.

## 4. 문체

- 노조 일반 문서: "~함. ~임." 체.
- 사용자 선호(기본값): 명사형 종결. 예: "회의를 진행함." → "회의 진행."
- 문체 점검은 두 모드(명사형 기본 / ~함·~임)를 고를 수 있게 한다.
