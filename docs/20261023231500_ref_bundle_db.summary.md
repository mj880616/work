무엇이 바뀌나: 바구니 업데이트를 담당조직·프로젝트 말고 '참고 묶음'(공공운수노조 / 공공기관사업(본부) / 기타 조직 세 개로 시작)에도 붙일 수 있도록 묶음 이름표와 연결 칸을 더하고, 연결 저장 함수 둘이 참고도 받게 합니다(다른 업무공간 묶음은 못 붙고, 소식이 붙은 묶음은 못 지웁니다). 화면은 아직 바뀌지 않습니다.
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 적용 뒤 문제가 생겨도 기존 연결(조직·프로젝트·회의·문서)과 업데이트 원문은 그대로이며, 참고에 붙인 소식이 없는 동안은 화면에 보이는 변화가 없습니다.
되돌리는 법: 참고에 붙인 소식이 없다면 짝 rollback을 SQL Editor 새 창에서 실행해 함수 둘을 이전 본문으로 되돌리고 칸·규칙·묶음 표를 지웁니다. 붙인 소식이 있으면 rollback이 멈추므로 preserve SQL로 먼저 보관한 뒤 명진 확인을 받아 그 연결 줄만 따로 지우고 진행합니다.
