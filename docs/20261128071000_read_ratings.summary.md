무엇이 바뀌나: 읽을 거리 줄을 밀어 누르는 👍(좋아요)·👎(별로예요)를 담는 새 표 1개가 생깁니다. 글 하나에 평가 하나(다시 누르면 취소)이고, 글 제목·본문은 다시 저장하지 않습니다. 평가한 사람만 읽고 쓰며, 기존 표·권한은 한 줄도 바뀌지 않습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 새 표만 만들므로 다른 화면에는 영향이 없고, 표가 없으면 👍·👎 저장만 되지 않고 추천은 지금처럼 고릅니다.
되돌리는 법: (화면을 배포했다면 먼저 이전 판으로 되돌린 뒤) 짝 rollback을 SQL Editor 새 창에서 실행해 새 표와 기록 1행만 지웁니다. 남긴 평가도 함께 사라지고, 글·저장한 글은 그대로입니다.
