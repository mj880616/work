무엇이 바뀌나: 자료실 자료 중 AI가 자료 날짜의 해를 잘못 붙인 것이 확실한 자료(제목·파일 이름·본문 첫머리에 같은 월·일로 다른 해가 하나만 분명히 적힌 것)만 자료 날짜의 해를 바로잡습니다(월·일은 그대로, 최대 50건). 사람이 넣은 날짜와 애매한 자료는 그대로 두고 건수만 셉니다. 바꾼 자료의 옛 날짜는 화면·API가 읽지 못하는 비공개 표에 남습니다.
잘못되면: 사전·사후 확인(건수·권한·정책·해시)이 하나라도 다르거나 고칠 자료가 50건을 넘으면 전체가 취소되어 아무것도 바뀌지 않습니다. 날짜가 틀어져도 자료는 그대로 있고, 주간보고 후보·자료 목록의 날짜와 순서만 달라집니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 비공개 표의 옛 날짜로 되돌리고 그 표와 기록 1행을 지웁니다. 적용 뒤 사람이 다시 고친 날짜가 있으면 멈춥니다. 적용 직전 자동 사본(ops_backup)에도 자료 표 전체가 남습니다.
