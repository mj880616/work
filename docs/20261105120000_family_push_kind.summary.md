무엇이 바뀌나: 폰 알림 종류에 '잊지 말기'(가족 1명 제안이 새로 생겼을 때 "잊지 말기 n건"만 알림)를 하나 더합니다. 알림 기록·알림 설정이 받는 종류 목록에 이름 하나만 늘고, 표·권한·기존 기록은 그대로입니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 전에는 잊지 말기 알림만 기록 저장에 실패해 보내지 않고, 다른 알림·화면은 그대로입니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 종류 목록을 원래대로 돌리고 기록 1행을 지웁니다. 잊지 말기 알림 기록이나 설정이 이미 있으면 멈춥니다.
