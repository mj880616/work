무엇이 바뀌나: 기능별 PIN 잠금에 쓰는 새 표 1개와 함수가 생깁니다. PIN은 알아볼 수 없게 바꾼 값(해시)만 저장하고 틀린 횟수는 서버가 셉니다. 표는 아무도 직접 읽지 못하고 정해진 함수로만 쓰며, 기존 표·권한·자료는 한 줄도 바뀌지 않고 지금 화면은 아직 이 함수를 쓰지 않습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 새 표·함수만 생기므로 지금 화면과 기록에는 영향이 없습니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 새 표·함수·기록 1행만 지웁니다. 정해 둔 PIN·잠금 설정만 사라지고 각자 기록은 그대로입니다.
