무엇이 바뀌나: Claude 연결의 쓰기 기록에 '파일 첨부' 칸과, Claude가 노트·업데이트에 파일을 붙일 때 서버가 확인·저장하는 함수 3개가 생깁니다. 쓰기 스위치를 켠 운영자 작업공간에서만 동작하고, 기존 표·권한·자료·화면은 바뀌지 않습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 함수가 잘못되면 Claude 파일 첨부만 거절되고 Web2 사용·Claude 읽기·다른 쓰기에는 영향이 없습니다.
되돌리는 법: 요청 전 함수 목록 되돌리기(docs/ops/mcp-claude-attach-guard.rollback.sql)를 먼저 하고, 짝 rollback을 SQL Editor 새 창에서 실행해 새 함수·칸·기록 1행을 지우고 문지기·되돌리기 함수를 1판 본문으로 돌립니다(이미 붙은 첨부 파일은 노트에 남습니다).
