무엇이 바뀌나: 내 프로필 표의 "화면 선택 기억" 값 검사 하나만 바꿔, 기억할 수 있는 칸에 "사업 보고 보기"(목록·달력·사진 중 하나)를 더합니다. 새 칸은 없고 다른 규칙(테마·메뉴·달력 보기·노트 폴더·분할 비율·숨김 날짜, 전체 4000바이트 상한)은 그대로입니다. 적용 뒤 사업 보고 화면에서 고른 보기가 PC·폰 어느 기기에서나 다음에 같게 열립니다. 기존 자료·권한·정책은 바꾸지 않습니다.
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 적용 전에는 화면이 이 선택을 저장하지 않고 이번 방문 동안만 유지하며, 적용 뒤 문제가 나도 화면은 기본 보기(목록)로 열리고 기억만 하지 않으므로 다른 화면 선택·프로필 저장은 그대로 동작합니다.
