무엇이 바뀌나: 내 프로필 표의 "자료실 보기 기억" 값 검사 하나만 바꿔, 묶기·꺼 둔 종류에 더해 "최근 넣은 폴더"(폴더 번호 최대 5개)도 저장할 수 있게 합니다. 새 칸은 없고 다른 규칙(묶기 다섯 값, 꺼 둔 종류 개수·길이, 전체 4000바이트 상한)은 그대로입니다. 적용 뒤 자료실 [폴더로 옮기기]의 "최근 넣은 폴더"가 PC·폰 어느 기기에서나 같게 맨 위에 보입니다. 기존 자료·권한·정책은 바꾸지 않습니다.
