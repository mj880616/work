무엇이 바뀌나: 소식·통화 줄을 넣을 때 도는 검사 함수 하나가 내부 도우미를 거치지 않고 표를 직접 읽어 같은 검사(다른 작업공간 연결 거절, 전문은 비우기만)를 하도록 바뀝니다. 서버가 소식을 저장하다 "권한 없음"으로 막히던 문제가 풀립니다. 새 권한은 주지 않고 표·정책·자료는 그대로입니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 문제가 나도 이미 막혀 있던 소식 저장이 계속 막힐 뿐 기존 기록은 영향이 없습니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 함수 본문만 이전 모양으로 되돌립니다(소식 저장은 다시 막힘). 들어온 줄은 지우지 않습니다.
