무엇이 바뀌나: 사진 [폴더]·아스날·노트 폴더·노트 보드 화면에서 칸 사이 경계를 끌어 고른 폭을 화면마다 서버에 기억하게 합니다(새로고침·다른 PC에서도 같음). 바뀌는 것은 내 프로필의 "화면 선택 기억" 값 검사 하나에서 칸 폭을 받는 화면 이름을 여덟 개에서 열두 개(photos·arsenal·notes·noteboard 추가)로 늘리는 것뿐이고, 새 열·권한·정책은 없으며 기존 자료와 다른 화면 기억 규칙은 그대로입니다.
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 검사식이 틀리면 다른 화면 선택 저장이 거절될 수 있어, 실제 PostgreSQL 시험으로 앞선 칸·앞선 화면 이름이 그대로 받아지는지 확인했습니다. 적용 전에는 새 화면 넷의 폭이 저장되지 않을 뿐(새로고침하면 기본 폭) 다른 기능은 그대로입니다.
되돌리는 법: (화면 PR을 merge했다면 먼저 이전 판으로) 짝 rollback으로 검사를 이전 모양(텔레그램 보기 단계 20261031010000)으로 되돌리고 기록 1행만 지웁니다. 새 화면 폭이 저장된 프로필이 있으면 지우지 않고 멈추며, 그 값을 어떻게 할지 정한 뒤 다시 계획합니다.
