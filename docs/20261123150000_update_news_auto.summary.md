무엇이 바뀌나: 새 업데이트 기록이 배포되면 서버가 이용자 '업데이트 소식'으로 기록 하나당 소식 하나씩 바로 보냅니다(운영자가 누르지 않아도). 이미 쌓인 옛 기록은 보내지 않고, 운영자는 소식마다 거두거나 거둔 것을 다시 보낼 수 있습니다. 알림은 보내지 않으며 표 권한은 그대로입니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 기록에 이상한 것이 섞여 한 번에 20개 넘게 새로 보이면 하나도 보내지 않습니다.
되돌리는 법: 화면을 이전 판으로 돌린 뒤 짝 rollback을 SQL Editor 새 창에서 실행하면 함수 둘이 이전 본문으로 돌아가고 새 칸·새 함수와 기록 1행이 지워집니다. 이미 자동으로 보낸 소식은 남으며 [거두기]로 거둘 수 있습니다.
