무엇이 바뀌나: 담당조직의 '쟁의 단계'를 담을 새 표 둘(단계 목록, 조직별 단계 이력)과 단계 지우기 함수 하나가 생깁니다. 두 표시('투쟁 중으로 봄'·'끝남')를 한 단계에 같이 켤 수 없고, 기본 단계는 지울 수 없으며, 다른 단계를 지우면 거기 있던 조직은 기본 단계로 옮겨집니다. 표는 비어 있고(기본 9단계는 앱이 나중에 채움) 화면은 아직 바뀌지 않습니다.
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 적용 뒤 문제가 생겨도 기존 담당조직·보고 표는 건드리지 않았고, 새 표는 아직 아무 화면도 쓰지 않으므로 보이는 변화가 없습니다.
되돌리는 법: 단계·이력 줄이 없다면 짝 rollback을 SQL Editor 새 창에서 실행해 함수와 새 표 둘을 지웁니다. 줄이 있으면 rollback이 멈추므로 preserve SQL로 먼저 보관한 뒤 명진 확인을 받아 그 줄만 따로 지우고 진행합니다.
