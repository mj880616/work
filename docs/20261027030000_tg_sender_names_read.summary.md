무엇이 바뀌나: 서버가 AI 요약 재료에 보낸 사람 이름을 넣을 수 있도록, 그 방·그날 A·B가 누구인지(손으로 붙인 이름과 본인 표시)만 읽어 주는 읽기 전용 기능 1개가 생깁니다. 표·권한·정책은 바뀌지 않고 서버(service_role)만 쓸 수 있으며 아무것도 저장하지 않습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 문제가 나도 서버는 이름을 못 읽을 뿐 소식 저장은 계속되고, 수집기가 보낸 이름이나 A·B로 물러납니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 이 기능 1개와 기록 1행만 걷어 냅니다. 저장된 이름표 자료는 그대로입니다.
