무엇이 바뀌나: 웹2에서 사진 정보(찍은 시각·위치)를 고칠 때 '고치기 전 값'을 적어 두는 새 표 1개가 생깁니다. [되돌리기]가 이 값으로 원래대로 돌립니다. 사진 이름·내용은 넣지 않고, 위치가 들어 있으므로 자기 작업공간 주인만 읽습니다. 지우기는 없고 고치기는 '되돌린 시각'만 됩니다.
잘못되면: 사전 확인·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 기존 표·권한은 건드리지 않으므로 사진 보기·앨범·별표에는 영향이 없습니다. 표가 없을 때도 화면은 고치기를 하되 '이번 화면에서만 되돌릴 수 있어요'로 알립니다.
되돌리는 법: (화면을 먼저 이전 판으로 둔 뒤) 짝 rollback을 SQL Editor 새 창에서 실행해 새 표 1개와 기록 1행만 지웁니다. 이미 고친 폰 사진은 그대로 남습니다.
