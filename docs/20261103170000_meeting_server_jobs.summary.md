무엇이 바뀌나: 녹음 정리(합치기·전사·요약)를 화면 대신 서버가 이어서 하도록, 그 진행 상태와 결과(전사 전문·요약 초안)를 적는 새 표 1개가 생깁니다. 명진만 읽을 수 있고, 쓰기는 서버 함수만 합니다. 기존 표·권한은 바꾸지 않습니다.
잘못되면: 사전 확인·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 표가 없으면 새 화면은 지금처럼 화면에서 정리하는 길로 돌아가므로 녹음·사업 보고에는 영향이 없습니다.
되돌리는 법: (화면·Edge를 먼저 이전 판으로 둔 뒤) 짝 rollback을 SQL Editor 새 창에서 실행해 새 표 1개·기록 1행만 지웁니다. 소리 파일·회의 기록은 그대로 남습니다.
