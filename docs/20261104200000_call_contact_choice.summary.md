무엇이 바뀌나: 통화 상대별로 명진이 한 번 고른 구분(업무/개인)을 기억하는 작은 표가 새로 생기고(번호·이름은 저장하지 않고 암호로 바꾼 열쇠만), 통화 한 건이 어느 상대인지 적는 작은 표가 하나 더 생기며(통화 줄 표는 그대로), 업무↔개인 옮기기 함수가 옮길 때 그 선택을 기억하도록 고쳐집니다. 지금 통화 줄·권한·정책은 그대로입니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 문제가 생겨도 서버(Edge)는 이 DB 적용 뒤에 배포하므로 그 전까지 통화 메뉴·옮기기는 지금처럼 돕니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 옮기기 함수를 앞 단계 모양으로 되돌리고 새 표 둘·기록 1행을 걷어 냅니다. 기억한 선택이 한 줄이라도 있으면 값을 잃지 않도록 멈춥니다(Edge를 먼저 이전 SHA로 되돌려야 함).
