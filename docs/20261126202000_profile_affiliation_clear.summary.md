무엇이 바뀌나: 모든 사람의 내 프로필 기본 정보에서 소속(조직)·부서·직책 글자를 비웁니다. 이름과 다른 설정·기록은 그대로이고, 칸 자체도 남깁니다. 비우기 전 같은 순간에 옛 값 세 칸을 백업 표(누구도 화면·API로 못 읽음)에 복사합니다. 화면에서 그 칸을 없애는 작업(S71-34)이 배포된 뒤에 적용합니다.
잘못되면: 사전·사후 확인(행 수·이름 해시·권한·정책·트리거)이 다르거나, 프로필에 걸린 자동 처리가 담당 조직·조직·묶음 구성원 줄을 바꾸면 전체가 취소되어 아무것도 바뀌지 않습니다. 비운 뒤에는 AI 안내문에 소속·직책이 빠지고, 새로 묶음에 들어갈 때 직책 없이 들어갑니다(이미 들어간 묶음의 직책 표시는 그대로).
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 백업 표의 옛 값을 지금도 비어 있는 칸에만 되돌려 넣고 백업 표와 기록 1행을 지웁니다. 적용 직전 자동 사본(ops_backup)에도 프로필 표 전체가 남습니다.
