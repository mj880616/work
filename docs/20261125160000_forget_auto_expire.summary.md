무엇이 바뀌나: 잊지 말기의 업무 제안(텔레그램 요청·AI 제안) 중 마감도 없고 나를 직접 부르지도 않은 것은, 들어온 날과 그다음 날까지 두었다가(그 사이 그 사람과의 1:1 방에 내가 답하면 바로 '이미 함(답장함)') 그다음 날 자정(서울)이 지나면 서버가 매일 한 번 저절로 '이미 함(지남)'으로 옮깁니다. 이를 위해 후보 줄에 '직접 부름' 표시 칸과 '부탁한 사람' 열쇠 칸(이름·번호가 아닌 해시) 둘, 옮기기 기능 하나, 텔레그램 요청 넣기 새 판과 '1:1 방 상대가 다른 방에서 한 요청 찾기' 기능(서버만), 매일 밤 예약 하나를 더합니다. 표 권한·정책·가족 제안·소식 줄은 그대로이고 밖으로 아무것도 보내지 않습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 남겨야 할 제안이 옮겨져도 지워지지 않고 '이미 함' 보기의 '지남' 줄 [되돌리기]로 처리 전으로 돌릴 수 있으며, 되돌린 줄은 다시 옮기지 않습니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 예약·기능 셋·새 칸 둘·넓힌 검사·기록 1행을 걷어 냅니다. 이미 옮긴 줄은 '이미 함'으로 남고 '지남' 꼬리표만 사라집니다. 서버 함수 판(collector-feed)은 새 기능이 없으면 옛 길로 넣으므로 먼저 되돌리지 않아도 됩니다.
