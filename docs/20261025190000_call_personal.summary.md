무엇이 바뀌나: 통화 줄이 "업무·개인·애매" 세 구분을 가질 수 있게 되고(지금 줄은 전부 업무 그대로), 개인·애매 통화는 고정·조직·프로젝트에 연결되지 못하게 막습니다. 구분을 옮기는 길(로그인한 명진 본인만)과 업무로 옮긴 직후 제목·상대·조직을 채우는 길이 함수 둘로 생기고, 같은 통화가 두 줄로 들어가지 않게 하는 중복 방지가 더해집니다. 기존 줄·권한·정책은 그대로입니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 문제가 생겨도 서버·화면이 아직 새 구분을 쓰지 않으므로 지금 통화 메뉴와 원장 자동 기록은 그대로 돕니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 함수·index·칸·검사를 걷어 내고 검사 함수를 이전 본문으로 되돌립니다. 개인·애매 줄이나 옮긴 흔적이 하나라도 있으면 자료를 잃지 않도록 멈춥니다.
