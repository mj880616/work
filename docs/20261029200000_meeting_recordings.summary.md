무엇이 바뀌나: 노트북 [녹음]이 5분마다 서버에 올린 녹음 조각의 위치·순서·길이·진행 상태를 적는 새 표 1개가 생깁니다. 소리와 전사 글은 두지 않습니다(소리는 명진 Drive, 글은 회의 기록에만). 화면·서버 함수가 아직 이 표를 쓰지 않아 겉으로 달라지는 것은 없습니다.
잘못되면: 사전 확인·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 기존 표·권한은 건드리지 않으므로 지금의 녹음 파일 전사·회의·사업 보고에는 영향이 없습니다.
되돌리는 법: (화면·Edge를 먼저 이전 판으로 둔 뒤) 짝 rollback을 SQL Editor 새 창에서 실행해 새 표 1개·기록 1행만 지웁니다. 지워지는 것은 녹음 구간 기록뿐이고, 소리 파일은 Drive에 남습니다.
