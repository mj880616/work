무엇이 바뀌나: 두 가지만 바꿉니다. ① 사진 색인 표에 "원드라이브에 올린 시각" 칸 하나를 더합니다(비어 있어도 됨, 다음 색인 때 채워짐). ② 내 프로필 표의 "화면 선택 기억" 값 검사가 사진 화면의 정렬 기준(찍은 날 최근·오래된 먼저, 올린 날 최근 먼저, 파일 이름 가나다, 크기 큰 것 먼저, 동영상 길이 긴 것 먼저)을 하나 받도록 합니다(폰·PC 같음). 다른 규칙(색·달력·노트 폴더·칸 폭·사업 보고 보기·숨김 날짜·메뉴 순서·홈 칸·사진 칸 수·일기 보기·사진 거르기·연락 없는 조직 기준·노트 보기·노트 보드, 전체 4000바이트 상한)은 그대로입니다. 기존 자료·권한·정책·인덱스는 바꾸지 않습니다.
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 검사식이 틀리면 다른 화면 선택 저장이 거절될 수 있어, 실제 PostgreSQL 시험으로 앞선 칸들이 그대로 받아지는지 확인했습니다. 이 DB가 적용되기 전에는 화면 PR(2/2)과 Edge 새 판을 내보내지 않습니다(적용 전에는 정렬 기준 저장이 거절되고 '찍은 날 최근 먼저'로만 보입니다).
되돌리는 법: (화면 PR·Edge 새 판을 내보냈다면 먼저 이전 판으로) 짝 rollback으로 올린 시각 칸을 지우고 검사를 노트 보드 단계(20261030091000) 모양으로 되돌린 뒤 기록 1행만 지웁니다. 정렬 기준이 저장된 프로필이 있으면 지우지 않고 멈추며, 그 값을 어떻게 할지 정한 뒤 다시 계획합니다. 올린 시각은 원드라이브에서 다시 받을 수 있는 사본이라 지워도 자료 손실이 없습니다.
