무엇이 바뀌나: 운영자에게 가는 사람 정보를 이메일주소·가입일·마지막 사용 시각 셋으로 줄입니다. '가입자 현황' 목록은 이 셋만, 새 가입 폰 알림은 '새 가입 n명'만, '받은 의견'의 보낸 사람은 이름 대신 이메일주소로 보입니다. 표·권한·기존 기록은 그대로입니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 화면이 아직 옛 판이어도 깨지지 않고 이름 칸이 '이름 없음'으로 보일 뿐입니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 세 함수를 어제 모양(조직·부서·이름·직책 포함, 알림 이름, 의견 보낸 사람 이름)으로 되돌리고 이번 기록 1행을 지웁니다. 표·자료는 바뀐 것이 없어 지울 것이 없습니다.
