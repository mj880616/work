# 📱 폰 가능 — 자료실 삭제 안내 후속 준비

자료실 목록과 회의자료의 삭제 결과가 원본 보존·휴지통 처리·결과 불명을 정확히 안내하도록 기존 화면을 보완한다. 계정이나 화면을 떠났다가 돌아와도 이전 삭제 요청·안내·Drive 재연결이 다시 이어지지 않게 한다. 준비·검토·일반 반영은 이미 승인된 범위이며 운영 서버 적용과 자료 등록 후속은 별도다.

이 문서는 검토용 PR을 마련하는 문서 중간본이다. 아직 이 브랜치에는 공통 helper나 소비자 제품 소스를 포함하지 않았다. 검토된 helper는 별도 보존 브랜치의 `a1c07713ca464ac3e1d98a5d8a4119b629f08f6f`이고, 두 화면의 구현 담당은 별도 작업공간에서 작업 중이다. 최종 검토·CI를 완료했다고 주장하지 않는다.

1. **세션:** CC17.4, Codex 웹. CC는 순서·문서·검토·승인된 일반 반영을 맡고 제품 구현과 독립 검토를 분리한다.
2. **시작·최종 SHA·branch·PR:** 문서 준비 기준 실제 main `28e620c06ee0fbd508d3aca3d574b451e4d4560c`; 검토용 브랜치 `codex/library-delete-ui`. 정확한 최종 소스와 PR 번호는 최종 준비 기록으로 갱신한다.
3. **원인:** 기존 소비자는 삭제 요청의 계정·화면 수명을 충분히 전달하지 않고 자료실 API는 helper의 세션 갱신 금지 옵션을 전달하지 않는다. 신규 요구 검사에서 확인한 사실이며 전체 제품 회귀 수로 표현하지 않는다.
4. **변경 파일:** 현재 이 문서만. 최종 범위는 공통 삭제 helper·자료실·회의자료 소비자, 필요한 기존 검사와 캐시 연쇄·원장이다.
5. **검사:** helper의 74/74 및 독립 검토, 원래 소비자 검사 중간본의 요구 RED는 인계서의 이전 근거다. 새 소비자 구현·검증은 진행 중이며 이 문서 PR의 성공으로 대체하지 않는다.
6. **독립 검토·CI:** 문서 준비 검토와 최종 제품 검토·정확한 최종 CI는 구분한다. 최종 제품 검토와 CI는 대기다.
7. **DB·production·권한:** DB·RLS·Edge·실자료·Cloudflare·운영 workflow 실행·승인 없음. 실제 `document-actions` 원본 보호 배포와 현재 운영 소스·복구 기준·전체 schema는 별도 확인이 남는다.
8. **사용자 확인:** 정해진 내부 준비·구현·검사·독립 검토·일반 반영을 다시 허락받지 않는다. 실제 운영 적용과 새 자료 등록은 기존 승인 경계를 유지한다.
9. **남은 위험:** 구현·전체 검토·정확한 CI·병합·Pages 미완료다. 합성 runtime 검사는 실제 서버나 Drive 원본 보호의 증거가 아니다.
10. **범위 밖:** 기존 Drive ID 자료 등록, runtime/Auth/server/schema 변경, 사진 기능 활성화, Worker 운영 적용은 포함하지 않는다.
11. **원장:** 기존 `BASKET-4b-1`과 CC 현황의 자료실 후속 범위를 이어간다. 최종 소스 PR에서 새 PR 번호·검사·상태를 함께 기록한다.
12. **병합:** 문서 준비 Draft이며 바로 병합할 대상이 아니다. 동일 PR에 승인된 소비자 소스와 실제 최신 사진 main을 정상 통합하고 전체 검토·최종 CI 뒤 일반 반영한다.
