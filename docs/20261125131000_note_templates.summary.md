무엇이 바뀌나: 노트 '서식'(회의록 같은 틀에 이름을 붙여 저장해 두고 새 노트를 만들 때 고르는 것)을 담는 새 표 1개가 생깁니다. 서식 주인만 읽고 쓰며, 기존 노트·표·권한은 한 줄도 바뀌지 않습니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 새 표만 만들므로 노트·다른 화면에는 영향이 없고, 표가 없으면 서식 저장·고르기만 되지 않습니다.
되돌리는 법: (서식 화면을 배포했다면 먼저 이전 판으로 되돌린 뒤) 짝 rollback을 SQL Editor 새 창에서 실행해 새 표와 기록 1행만 지웁니다. 저장해 둔 서식도 함께 사라지고, 서식으로 만든 노트는 그대로입니다.
