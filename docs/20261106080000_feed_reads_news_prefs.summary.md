무엇이 바뀌나: News에서 어떤 글을 읽었는지 담아 둘 새 표 하나가 생기고(글마다 한 줄, 읽은 시각만), 내 프로필 "화면 선택 기억" 값 검사에 News 마지막 탭(news_tab)·글자 크기(news_font) 두 칸을 더합니다. 본인 작업공간 사람만 읽음 표시를 넣고 보고 지울 수 있고, 다른 사람 글에는 표시할 수 없습니다. 옛 Now 탭 기억·다른 칸·권한은 그대로입니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다(사회운동 글·뉴스 기사 DB나 담당조직 판 org_order 20261105131500이 없거나, 화면 기억 검사가 그 판이 아니면 멈춤). 적용 뒤 문제가 생겨도 지금 화면에는 영향이 없습니다(아직 이 표·두 칸을 쓰는 화면이 없음).
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 새 표·검사 함수·기록 1행을 지우고 화면 기억 검사를 org_order 판 글자 그대로 되돌립니다. 읽음 표에 줄이 있거나 누군가 두 칸을 저장했으면 멈춥니다(화면을 먼저 되돌린 뒤 판단).
