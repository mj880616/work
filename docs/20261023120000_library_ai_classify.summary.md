무엇이 바뀌나: 자료실 AI가 파일 안 글자를 보고 비어 있는 프로젝트·담당조직 연결도 채울 수 있게, 자료 칸 기록과 백업 표가 두 칸(프로젝트·담당조직)을 더 받고, 분류 시도 기록 표 1개와 함수 3개(백업하면서 바꾸기, 묶음 되돌리기, 정리 전체 한 번에 되돌리기)가 생깁니다. 적용하면 그때부터(화면·서버 배포 뒤) 자료실을 열 때 기존 자료를 한 번씩 다시 보고, 손으로 넣지 않은 빈 칸과 비어 있는 연결만 채웁니다. 손으로 넣거나 고친 칸, 이미 붙어 있는 연결은 바꾸지 않고 연결을 지우지도 않습니다. 로그인한 명진 본인만 읽고 쓸 수 있고, 적용 순간에는 기존 자료 값이 하나도 바뀌지 않습니다.
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 적용 뒤 AI가 잘못 넣은 칸·연결은 원래 값이 백업되어 있어 시작 시각 하나로 전체를 되돌릴 수 있습니다. 표·함수가 없거나 서버가 아직 배포 전이면 화면은 조용히 아무것도 하지 않고, 새로 올리는 자료는 예전처럼 글 칸 4개만 채워집니다.
되돌리는 법: 값만 되돌릴 때는 SQL Editor에서 전체 되돌리기 함수에 정리 시작 시각을 넣어 한 번 실행합니다(지금 값이 AI 값 그대로인 칸만 원래대로, 그 사이 고친 칸은 건너뜀). 표·함수까지 없앨 때는 화면·서버를 먼저 이전으로 돌린 뒤 짝 rollback을 SQL Editor에서 실행합니다. 연결 기록이나 연결 백업이 한 줄이라도 있으면 rollback은 지우지 않고 멈춥니다.
