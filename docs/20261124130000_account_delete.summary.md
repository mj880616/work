무엇이 바뀌나: 내 프로필 [계정 삭제]가 부를 서버 함수 3개와 빈 실행 표 1개가 더해집니다. 적용만으로는 아무 기록도 지워지지 않고, 본인이 확인 글자를 넣고 눌러야 자기 작업공간 기록만 지워집니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면(지우지 못하고 남는 표가 있으면 포함) 멈추고 아무것도 바뀌지 않습니다. 버튼으로 지우다 막히면 그 사람 기록은 한 줄도 지워지지 않고 그대로입니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 새 함수·표만 사라집니다(기존 표·자료 무변경). 이미 삭제한 사람의 기록은 복구용 사본이 없어 되돌릴 수 없습니다.
