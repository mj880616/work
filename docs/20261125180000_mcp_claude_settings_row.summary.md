무엇이 바뀌나: Claude 읽기 연결의 설정 한 줄을 운영자(명진) 작업공간에 넣습니다. 허용할 연결 앱은 미리 등록한 'Claude' 하나로 정해지고, 스위치는 꺼진 채라 본인이 화면에서 켜기 전에는 Claude가 아무것도 못 읽습니다. 표·권한·정책·기능은 그대로입니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면(운영자 작업공간이나 Claude 연결 앱이 하나가 아님, 설정 줄이 이미 있음) 멈추고 아무것도 바뀌지 않습니다. 적용 뒤 값이 틀려도 스위치가 꺼져 있어 읽기는 열리지 않습니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 설정 한 줄과 기록 1행을 지웁니다(그러면 Claude 호출은 모두 거절, 연결 전과 같음). 호출 기록·다른 자료는 그대로입니다.
