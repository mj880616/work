무엇이 바뀌나: 연결마다 승인한 요약을 저장하고 나중에 고칠 서버 기능을 준비합니다. 화면은 그대로입니다.
잘못되면: 연결 확정이나 요약 수정이 거절될 수 있습니다. 새 기능을 쓰지 않는 기존 화면은 유지합니다.
되돌리는 법: 비공개 보존 파일 검증 후 잠금 뒤 현재 전체 행·요약과 정확히 대조합니다. 같을 때만 같은 transaction에서 요약 비우기·기존 4a 함수 복원·새 함수/칸 제거를 실행하며, 다르거나 복원 실패 시 전부 취소합니다. rollback 버튼은 기존 정책상 불가하므로 사용자 SQL Editor 복구 대안을 CC가 검토합니다.
