무엇이 바뀌나: 내 프로필 표의 "자료실 보기 기억" 값 검사 하나만 바꿔, 묶기 값으로 프로젝트·담당조직·종류·월별에 더해 "폴더"도 저장할 수 있게 합니다. 새 칸은 없고 다른 규칙(꺼 둔 종류 개수·길이, 전체 4000바이트 상한)은 그대로입니다. 적용 뒤 자료실에서 묶기를 폴더로 고르면 PC·폰 어느 기기에서나 다음에 폴더 묶기로 열립니다. 기존 자료·권한·정책은 바꾸지 않습니다.
