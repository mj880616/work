무엇이 바뀌나: 뉴스 수집기가 옛 표에 새로 넣은 기사·읽음·자세히·반응을 공용 기사 번호 지도와 사람별 새 표로 옮겨 채우는 서버 전용 함수를 더하고, 적용 때 한 번 돌려 그동안 빠진 줄을 채웁니다. 옛 표·정책·화면은 그대로입니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 같은 작업공간·같은 주소가 아닌 지도가 생기거나 빠진 줄이 남으면 사후 확인에서 전체 취소되고, 표를 잠그지 않아 수집은 멈추지 않습니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 함수와 기록만 지워지고, 채워 넣은 줄은 옛 표의 사본이라 그대로 두며 옛 뉴스 표는 손대지 않았으므로 그대로입니다.
