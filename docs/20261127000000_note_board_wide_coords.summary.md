무엇이 바뀌나: 노트 보드에서 상자·글자·도형 자리와 선 끝 점이 저장될 수 있는 범위를 넓힙니다(0~10만 → -100만~100만). 판을 왼쪽·위로도, 아주 멀리까지 뻗을 수 있게 하는 것이고, 칸·권한·정책은 그대로입니다.
잘못되면: 사전 확인이나 적용 안 확인이 어긋나면 전체가 취소되어 아무것도 바뀌지 않습니다. 기존 상자·선은 한 줄도 바뀌지 않습니다. 적용 전에는 새 화면에서 왼쪽·위 바깥(음수 자리)에 둔 상자·선 끝 저장만 거절되고(알림 뒤 서버 값으로 다시 불러옴), 나머지는 그대로 됩니다.
되돌리는 법: (새 화면을 배포했다면 먼저 이전 판으로) 짝 rollback을 SQL Editor 새 창에서 실행합니다. 이미 옛 범위 밖에 놓인 자리가 있으면 바꾸지 않고 멈추므로, 화면에서 옮긴 뒤 다시 실행합니다.
