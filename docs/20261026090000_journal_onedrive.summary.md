무엇이 바뀌나: 원드라이브 사진 일기를 받치는 새 표 3개가 생깁니다. 연결 정보(서버만 읽고 씀, 화면에서는 볼 수 없음)·사진 목록 색인(사진 파일은 복사하지 않음, 서버만)·사진 별표(로그인한 명진 본인만 읽고 씀)입니다. 기존 표·자료·권한은 그대로입니다.
잘못되면: 사전·시험 적용·사후 확인 중 하나라도 어긋나면 멈추고 아무것도 바뀌지 않습니다. 적용 뒤에도 서버 함수와 화면이 아직 새 표를 쓰지 않으므로 지금 일기·일정·로그인에는 영향이 없습니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행해 새 표 3개와 기록 1행을 지웁니다. 별표가 하나라도 쌓인 뒤면 자료를 잃지 않도록 멈춥니다.
