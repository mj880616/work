무엇이 바뀌나: 맨 위 알림 줄의 '연결 끊김'(Google·원드라이브) 안내에서 ✕를 누르면 그날 하루 숨긴 것을 서버에 기억합니다(폰·컴퓨터 같음, 다음 날 아직 끊겨 있으면 다시 뜸). 바뀌는 것은 내 프로필의 "화면 선택 기억" 값 검사 하나에 '연결 끊김 숨김 날짜'(link_hidden_on, YYYY-MM-DD) 칸을 더하는 것뿐이고, 새 열·권한·정책은 없으며 기존 자료와 다른 화면 기억 규칙은 그대로입니다.
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 검사식이 틀리면 다른 화면 선택 저장이 거절될 수 있어, 실제 PostgreSQL 시험으로 앞선 칸이 그대로 받아지는지 확인했습니다. 적용 전에는 연결 끊김 ✕ 저장만 거절될 뿐(이 탭에서만 닫힘) 다른 기능은 그대로입니다.
