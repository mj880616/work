무엇이 바뀌나: 'Now' 메뉴(사회운동·뉴스·보관·문장 찾기 탭)에서 마지막으로 연 탭과, PC·폴드 펼침의 두 칸(목록 | 글 상세) 나눔 폭을 서버에 기억합니다(폰·컴퓨터 같음). 바뀌는 것은 내 프로필의 "화면 선택 기억" 값 검사 하나에 'Now 마지막 탭'(now_tab, outside·news·saved·search 넷 중 하나)과 칸 비율 화면 이름 'now'를 더하는 것뿐이고, 새 열·권한·정책은 없으며 기존 자료와 다른 화면 기억 규칙은 그대로입니다.
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 검사식이 틀리면 다른 화면 선택 저장이 거절될 수 있어, 실제 PostgreSQL 시험으로 앞선 칸이 그대로 받아지는지 확인했습니다. 적용 전에는 Now 탭·칸 폭 저장만 거절될 뿐(이번 접속 동안만 기억) 다른 기능은 그대로입니다.
