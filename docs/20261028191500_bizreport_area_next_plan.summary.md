무엇이 바뀌나: 사업 보고 표에 '사업영역 꼬리표'(지금 프로젝트 목록의 한 줄을 가리킴)와 '다음 할 일'(1000자 이하) 칸 두 개를 더하고, 꼬리표가 다른 업무공간의 프로젝트를 가리키지 못하게 막는 확인 하나를 더합니다. 기존 사업 보고·프로젝트·진행 기록은 그대로이고 새 칸은 모두 빈 채로 시작하며, 권한은 넓히지 않습니다.
잘못되면: 사전·사후 확인에서 멈추면 아무것도 바뀌지 않습니다. 적용 뒤 문제가 나도 지금 화면은 새 칸을 쓰지 않으므로(화면은 다음 PR) 사업 보고 쓰기·목록·주간보고는 그대로 동작하고, 남에게 보이는 범위도 바뀌지 않습니다.
되돌리는 법: 짝 rollback을 SQL Editor 새 창에서 실행하면 확인·칸 두 개와 기록 1행만 지웁니다. 화면이 꼬리표나 다음 할 일을 이미 저장했다면 지우지 않고 멈추며, 먼저 preserve SQL로 보관한 뒤 별도 승인으로 다시 계획합니다.
