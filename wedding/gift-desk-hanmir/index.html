WEDDING GIFT DESK GUIDE

미르야~ 축의대 관련해서 몇 가지 안내!

핵심은 분류하지 말고 한 방향으로 넘기는 것이야. 한 명이 받고 번호·식권 처리 → 한 명이 금액·장부 확인 → 바로 가방에 넣기.

1역할은 딱 둘로

노조·학교·극단 구분은 안 해도 돼. 현장에서 사람 구분하려다 흐름 끊기거나 헷갈리는 게 더 위험할 것 같아.

  • 앞쪽: 봉투 받기 → 번호 적기 → 식권 수 확인·전달 → 뒤쪽으로 넘기기
  • 뒤쪽: 봉투 열기 → 금액 확인 → 장부 기록 → 현금 다시 넣기 → 가방에 바로 넣기

둘이 각자 한 줄씩 받기보다 컨베이어벨트처럼 한 방향으로 처리해줘. 사람이 몰려도 이 흐름은 유지하는 게 제일 중요해.

2하객이 오면

방명록에 이름 작성
앞쪽 사람이 축의금 봉투 받기
봉투 오른쪽 위에 순번 적기. 이름이 없으면 이름도 확인해서 적기
필요한 식권 수 확인해서 식권 전달. 가능하면 봉투에 식권 수도 작게 표시
봉투를 뒤쪽 사람에게 바로 넘기기
뒤쪽 사람이 봉투를 열어 금액 확인
장부에 번호 / 이름 / 금액 / 식권 수 기록
현금을 다시 같은 봉투에 넣고 즉시 보관 가방에 넣기

3받은 봉투를 다시 달라고 하면

일단 돌려주지 말아줘. “접수한 봉투는 바로 정리해서 다시 드리기 어렵다. 필요한 내용은 신랑에게 전달해서 나중에 확인하겠다”고 안내하면 돼.
  • “잠깐 확인만 할게요”, “돈을 더 넣을게요”, “봉투를 바꿀게요” 같은 경우도 동일
  • 계속 요구하면 이름과 사유만 기억하거나 메모해두고 나한테 전달
  • 현장에서 실랑이하거나 봉투를 꺼내 보여주지 않기

4쓸이꾼·분실 대비

  • 보관 가방은 항상 축의대 안쪽, 두 사람 손이 닿는 곳에 두고 지퍼 닫아두기
  • 둘 다 동시에 자리를 비우지 않기. 한 명이 움직여야 하면 한 명은 가방 옆에 남기
  • 하객이나 제3자가 축의대 안쪽으로 들어오거나 봉투·가방에 손대지 않게 하기
  • 접수된 봉투는 책상 위에 쌓아두지 말고 장부 기록이 끝나는 즉시 가방에 넣기
  • 가방은 마지막까지 두 사람이 관리하고, 지정한 사람 외에는 넘기지 않기

5마지막 인계

끝나면 축의금 봉투가 든 가방과 장부를 내 매제 김요한한테 직접 전달해줘. 다른 사람이 대신 받겠다고 해도 넘기지 말고, 요한이한테만 직접 부탁할게.
