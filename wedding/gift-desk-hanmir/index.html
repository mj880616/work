WEDDING GIFT DESK GUIDE

미르야~ 축의대 관련해서 몇 가지 안내!

극단에서 같이 활동했던 영민이형이 식날 너랑 같이 축의대를 맡을 예정이야. 영민이형은 극단 사람들을 거의 다 알고 있고, 너는 노조랑 단국대 사람들을 많이 아니까 둘이 같이 보면 서로 보완이 잘 될 것 같아.

핵심은 봉투와 장부에 같은 번호·구분을 남기고, 장부에는 금액과 식권 수까지 적는 것이야.

1분류 표시

내가 나중에 축의금 내역을 노조 / 단국대 / 멍석 / 그외로 구분해서 정리하려고 해.

노노조
단단국대
멍멍석
?미확인

노조·단국대 쪽은 네가 주로 확인해주고, 멍석 쪽은 영민이형이 확인해주면 돼. 둘 다 애매하면 그 자리에서 오래 확인하지 말고 ?로 해둬. 나중에 내가 정리할게.

2사람이 오면

방명록에 이름 작성
축의금 봉투 받기
봉투 오른쪽 위에 번호 + 구분 적기
봉투 열어서 금액 확인
장부에 번호 / 이름 / 구분 / 금액 / 식권 수 기록
현금은 다시 해당 봉투에 넣기
식권 전달
봉투에는 023 노, 024 멍 이런 식으로 적으면 돼.
금액은 봉투에 안 적고 장부에만 적어줘.

3장부는 이렇게

번호이름구분금액식권
001홍길동노100,0002
002김철수멍50,0001

봉투 번호랑 장부 번호만 꼭 같게 맞춰줘. 나중에 이름이나 금액 다시 확인할 때 바로 찾으려고 하는 거야.

4둘이 역할은

평소엔 둘이 같이 받고, 사람 몰리면 각자 한 줄씩 받으면 될 것 같아.

  • 미르: 노조·단국대 사람 위주로 확인
  • 영민이형: 멍석 사람 위주로 확인
  • 서로 아는 사람 오면 “노”, “단”, “멍” 이렇게 바로 알려주기

봉투 하나는 번호·금액·장부 기록까지 다 끝내고 다음 봉투로 넘어가줘. 여러 개 동시에 열면 사람하고 금액이 섞일 수 있어서 이것만 특히 부탁!

5끝나고 정리

봉투는 가능하면 노 / 단 / 멍 / ? 이렇게 4묶음으로 나눠줘.

  • 장부 마지막 번호와 실제 봉투 개수 맞는지 확인
  • 배부한 식권 수 확인

6마지막 인계

다 끝나면 축의금 봉투가 든 가방이랑 장부를 내 매제 김요한한테 전달해줘. 요한이한테도 미리 얘기해둘게.

7준비물

□ 축의금 장부
□ 방명록
□ 볼펜 여러 자루
□ 식권
□ 분류용 고무줄 또는 지퍼백
□ 축의금 봉투 보관 가방
