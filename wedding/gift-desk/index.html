WEDDING GIFT DESK GUIDE

결혼식 축의대 운영 안내

핵심은 분류하지 않고 한 방향으로 넘기는 것입니다. 한 분이 접수·번호·식권 처리 → 한 분이 금액·장부 확인 → 바로 가방 보관.

1역할은 두 단계로 단순하게

노조·학교·극단 구분은 현장에서 하지 않으려고 합니다. 사람을 구분하다가 흐름이 끊기거나 봉투가 섞이는 것보다 접수 자체를 단순하게 하는 게 안전할 것 같습니다.

  • 앞쪽: 봉투 받기 → 번호 적기 → 식권 수 확인·전달 → 뒤쪽으로 넘기기
  • 뒤쪽: 봉투 열기 → 금액 확인 → 장부 기록 → 현금 다시 넣기 → 가방에 바로 넣기

두 분이 각자 한 줄씩 받기보다는 컨베이어벨트처럼 한 방향으로 처리해주세요. 사람이 몰려도 이 흐름만 유지하면 될 것 같습니다.

2하객이 오면

하객이 방명록에 이름 작성
앞쪽에서 축의금 봉투 받기
봉투 오른쪽 위에 순번 적기. 이름이 없으면 이름도 확인해서 적기
필요한 식권 수 확인 후 식권 전달. 가능하면 봉투에 식권 수도 작게 표시
봉투를 뒤쪽 사람에게 바로 넘기기
뒤쪽에서 봉투를 열어 금액 확인
장부에 번호 / 이름 / 금액 / 식권 수 기록
현금을 다시 같은 봉투에 넣고 즉시 보관 가방에 넣기

3접수한 봉투를 다시 달라고 하면

일단 돌려주지 말아주세요. “접수한 봉투는 바로 정리하고 있어서 다시 드리기 어렵습니다. 필요한 내용은 신랑에게 전달해서 이후 확인하겠습니다” 정도로 안내해주시면 됩니다.
  • “잠깐 확인하겠다”, “돈을 더 넣겠다”, “봉투를 바꾸겠다”는 요청도 동일하게 처리
  • 계속 요청하면 이름과 사유만 메모해서 저에게 전달
  • 현장에서 봉투를 다시 꺼내 보여주거나 실랑이하지 않기

4쓸이꾼·분실 대비

  • 보관 가방은 항상 축의대 안쪽, 두 분 손이 닿는 곳에 두고 지퍼를 닫아두기
  • 두 분이 동시에 자리를 비우지 않기. 한 분이 움직이면 한 분은 가방 옆에 남기
  • 하객이나 제3자가 축의대 안쪽으로 들어오거나 봉투·가방에 손대지 않게 하기
  • 접수된 봉투를 책상 위에 쌓아두지 말고 장부 기록이 끝나는 즉시 가방에 넣기
  • 가방은 마지막까지 두 분이 관리하고 지정한 사람 외에는 넘기지 않기

5마지막 인계

모든 확인이 끝나면 축의금 봉투가 들어 있는 가방과 장부를 제 매제 김요한에게 직접 전달해주세요. 다른 사람이 대신 받겠다고 하더라도 넘기지 말고 요한이에게만 직접 부탁드립니다.
