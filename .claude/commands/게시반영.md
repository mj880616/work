# /게시반영

입력:

$ARGUMENTS

규칙은 `AGENTS.md`(보안·작업 흐름·보고)와 `docs/sec-publication-auto-merge.md`(허용 목록·관문)를 따른다. 여기에는 이 명령의 순서만 적는다.

## 0. 모드와 세션

- 입력에 "연습"이 있으면 **연습 모드**다. 브랜치·커밋·push·PR을 만들지 않는다. 1~3단계만 하고 아래 "연습 모드 끝내기"로 간다.
- 실제 게시는 `gh`가 동작하는 세션에서만 한다(`gh auth status`). 안 되면 파일만 만들어 보여 주고 중단·보고한다.

## 1. 입력 분류

- 새 성명·보도자료·취재요청은 이 명령으로 만들지 않는다(PRESS-자료실편입). Web2 자료실에 한글·PDF 파일로 올리고 종류를 '성명·보도자료'로 둔다. 이런 입력이면 파일을 만들지 말고 그렇게 안내한 뒤 멈춘다.
- 기존 Web1 페이지의 내용 추가·수정(예: 민자철도 사업현황에 영상 추가) → **기존 페이지 갱신**. 대상 파일을 찾아 사용자에게 경로를 보여 준다.
- 어떤 페이지인지 판단이 안 되면 **한 번** 묻는다.

## 2. 원문 불변과 빠진 정보

- 사용자가 준 제목·본문·날짜·발신 기관·담당자 정보는 글자 그대로 쓴다. 문장·띄어쓰기·문장부호를 고치지 않는다. 문단 나눔만 `<p>`로 옮긴다.
- 오탈자로 보이는 곳은 바꾸지 않고 보고의 "원문 확인 필요"에 적는다.
- 날짜·제목이 없으면 지어내지 않는다. 빠진 정보는 **한 번에** 확인받는다. 연습 모드에서는 보고에 적고 진행한다.

## 3. 파일 작성

### 기존 페이지 갱신

- 요청한 부분만 바꾼다. 페이지의 기존 구조·스타일을 따르고 다른 곳은 손대지 않는다.
- `?v=`는 손으로 쓰지 않는다. 배포 빌드가 붙인다(`AGENTS.md` 캐시 버전).

### 로컬 확인

- 링크한 첨부 파일이 디렉터리에 실제로 있는지 확인한다. 복사가 안 됐으면 게시하지 않고 묻는다.
- 변경 경로 분류: `git -c core.quotepath=false status --porcelain`(연습) 또는 `git -c core.quotepath=false diff --name-only origin/main...HEAD`(실제)의 경로를 `scripts/publication-pr-policy.mjs`의 `classifyPublicationPaths`로 판정해 `publication`과 `outside`를 보고에 쓴다.

## 연습 모드 끝내기

- 만든 파일 목록과 diff 요약, 테스트 결과, 분류 결과를 보여 준다.
- 커밋하지 않는다. 보여 준 뒤 만든 디렉터리를 지우고 고친 파일을 `git restore`로 되돌린다. 사용자가 남기라고 하면 남긴다.

## 4. 브랜치·PR (실제 게시)

1. `git fetch origin` 후 원격 `main` 최신에서 새 브랜치 `publish/<페이지>-<날짜>`를 만든다. 사용자의 미커밋 변경은 건드리지 않는다.
2. 이 게시에 필요한 파일만 커밋한다(`git add <경로>`; `git add -A` 금지). push하고 `gh pr create --base main`으로 PR을 연다. draft로 만들지 않는다.
3. `gh pr checks <번호> --watch`로 모든 검사가 끝날 때까지 본다.
4. 실패하면 로그를 읽고 **형식 문제만** 고쳐 새 커밋으로 다시 올린다. 원문은 고치지 않는다. 원문을 바꿔야만 통과한다면 멈추고 보고한다.

## 5. 끝내기

기존 페이지 갱신은 허용 목록 밖 파일을 바꾸므로 PR 생성과 검사 통과까지만 한다. "커맨드센터 확인 후 merge 필요"라고 보고하고 멈춘다. 같은 내용을 PR 댓글로도 남긴다.

## 금지

- 수동 merge, `gh pr merge`, `--admin`, auto-merge 직접 예약·해제
- `.github/**`·`app/**`·`supabase/**`·`cloudflare/**` 변경
- DB 쓰기, supabase CLI 배포·db 명령, wrangler
- 갱신 PR에 그 페이지에 필요하지 않은 파일 섞기
- 할 일·메모 내용을 저장소·원장에 기록하기
